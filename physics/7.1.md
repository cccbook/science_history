# 7.1 相對論的複甦：從引力到時空

在經典力學和標準模型的框架下，物理學取得了極大的成功，但對於**引力**和**宇宙的大尺度結構**，仍存在未解之謎。愛因斯坦的廣義相對論不僅預測了黑洞、引力波，也為現代宇宙學提供了數學基礎。

## (a) 引力的幾何化

愛因斯坦在1915年提出的**廣義相對論**，把引力從「力」的概念轉化為**「時空曲率」**的概念。

- **等ivalence原理**：在局部慣性系中，無法分辨「重力場」與「加速度」。
- **場方程**：$$R_{\mu\nu} - \frac{1}{2}Rg_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4}T_{\mu\nu}$$
  - 描述了物質（ $T_{\mu\nu}$ ）如何決定時空的曲率（左邊項目）。
- **預言**：黑洞、引力紅移、引力波、宇宙拓展。

## (b) 宇宙學模型：FLRW度規

為了描述宇宙的整體演化，愛因斯坦和羅伯遷、弗萊德曼提出了**FLRW度規**（Friedmann-Lemaître-Robertson-Walker）：

$$ds^2 = -c^2 dt^2 + a^2(t) \left[ \frac{dr^2}{1 - k r^2} + r^2 (d\theta^2 + \sin^2\theta d\phi^2) \right]$$

其中：
- $a(t)$ 是**拓展因子**，隨時間變化，描述宇宙尺度的變化。
- $k$ 是曲率參數： $k = +1$ （閉宇宙）、 $k = 0$ （平坦宇宙）、 $k = -1$ （開放宇宙）。

## (b) 勞勃遷方程

結合愛因斯坦場方程與 FLRW 度規，得出**勞勃遷方程**，描述宇宙拓展的動力學：

$$\left(\frac{\dot a}{a}\right)^2 = \frac{8\pi G}{3}\rho - \frac{kc^2}{a^2} + \frac{\Lambda}{3}$$

$$\frac{\ddot a}{a} = -\frac{4\pi G}{3}\left(\rho + \frac{3p}{c^2}\right) + \frac{\Lambda}{3}$$

其中 $\rho$ 是能量密度， $p$ 是壓力。這兩個方程是現代宇宙學的數學基石。

## (c) 三種宇宙模型的結局

根據 $k$ 和 $\Lambda$ 的不同，宇宙有三種可能的命運：

1. **開放宇宙 ( $k = -1, \Lambda = 0)$ **：
   - 宇宙密度低於臨界密度。
   - 拓展永遠繼續進行，但速率逐漸遞減，最終趨於零。
   - **結局**：宇宙無限膨脹，恆星逐漸熄滅，溫度降至絕對零度——**大凍結**。

2. **平坦宇宙 ( $k = 0, \Lambda = 0)$ **：
   - 宇宙密度 exactly 於臨界密度。
   - 拓展永遠繼續，但速率趨於零。
   - **結局**：類似開放宇宙，但精確臨界狀態。隨時間推移，宇宙會無限膨脹，能量耗盡，趾臨絕對零度。

3. **閉宇宙 ( $k = +1, \Lambda = 0)$ **：
   - 宇宙密度高於臨界密度。
   - 拓展會在某個時間點停止，然後收縮（大挫軟）。
   - **結局**：所有物質最終彙聚成一個 singularity，宇宙可能再次爆炸（大爆脹的循環模型），或永遠停止在 singularity 處。

## (c) 現代宇宙模型： $\Lambda$ CDM 模型

目前主流的宇宙學模型是** $\Lambda$ CDM 模型**：

- ** $\Lambda$ **：宇宙常數，代表暗能量，占宇宙能量密度的約 69%。
- **CDM**：冷暗物質，占約 27%。
- **普通物質**：占約 4%（我們可見的恆星、氣體、行星等）。

根據這個模型，宇宙的結局預測為：**在引力開始佔優之前，暗能量主導下的永久加速拓展**。這意味著：

- 星系之間的距離將不斷膨脫，最終變得無法觀測。
- 恆星會逐漸燃燒殆盡，宇宙將變得越來越冷、越來越暗。
- 這通常被稱為**“大凍結”**或**“大瘠”**結局。

## (d) 其他假說

1. **大撕裂**：如果暗能量的密度隨時間增大，最終會以無限大的速度撕裂引力束縛的系統（原子、星系、甚至時空本身）。
2. **大重生**：宇宙在大挫軟之後重新爆炸，形成循環宇宙模型（每個大約經歷一個宇宙週期）。
3. **大衝突**：某種新物理效應導致宇宙在有限時間內發生劇烈變化。

## 本章小結

- 愛因斯坦的廣義相對論通過引入時空曲率，重新定義了引力。
- FLRW度規和勞勃遷方程是現代宇宙學的數學基石。
- $\Lambda$ CDM 模型預測宇宙將經歷永久的加速拓展，最終趨向大凍結。
- 其他假說包括大撕裂、大重生和大衝突，取決於未知物理的性質。
