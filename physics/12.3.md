# 12.3 推導：含時薛丁格方程

薛丁格方程的推導過程，實則是一個從經典力學到量子力學的逐步轉型。我們從經典描述出發，一步步引入量子化的觀念，最終證出薛丁格方程的形式。

第一步，回顧經典相對論能量-動量四維量。在非相對論極限下，一個自由粒子的能量與動量關係由下式給出：

$$E = \frac{p^2}{2m}$$

這是牛頓力學中的動能公式。對於處於位置 $x$ 的粒子，我們可以將能量算子化，將動量 $p$ 替換為 $-\mathrm{i}\hbar \frac{\partial}{\partial x}$。這一步至關重要，因為它引入了普朗克常數 $\hbar$，將經典變數轉變為量子算符。

第二步，將位能 $V(x)$ 考慮進去。對於受外場影響的粒子，總能量方程變為：

$$E = \frac{p^2}{2m} + V(x)$$

將算符代入後，我們得到：

$$E \psi = -\frac{\hbar^2}{2m}\frac{\partial^2 \psi}{\partial x^2} + V(x)\psi$$

這是一個站在半路的結果，它還沒有包含時間演化的信息。為了完整描述系統，我們需要考慮波函數 $\psi$ 如何隨時間變化。

第三步，引入時間依賴。根據歐拉公式 $e^{-\mathrm{i}Et/\hbar}$，我們可以將波函數表示為空間部分和時間部分的乘積：

$$\psi(x,t) = \phi(x) e^{-\mathrm{i}Et/\hbar}$$

將這個表示代入前面的方程，並整理後，我們得到薛丁格方程的時間獨立形式。但薛丁格並不滿足於此，他希望得到一個直接包含時間變數的方程。

第四步，薛丁格通過觀察愛因斯坦光電效應公式 $E = h\nu$ 與薛丁格方程之間的類比，意識到時間演化應該包含一個「頻率」項。他引入時間導數，最終推導出含時薛丁格方程：

$$i\hbar \frac{\partial \psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi + V\psi$$

這個方程的每一項都有明確的物理意義：
- 左邊 $i\hbar \partial\psi/\partial t$ 描述波函數隨時間的變化率，類似於經典力學中的哈密頓方程
- 右邊 $-\frac{\hbar^2}{2m}\nabla^2\psi$ 是動能項，對應自由粒子的運動
- $V\psi$ 是位能項，描述粒子受到的外場影響

這個方程不僅能夠描述電子在原子中的穩態，更能夠預測系統隨時間如何演化，例如電子躍遷、光的吸收與發射等過程。

## 本章小結

- 從經典動能 $p^2/2m$ 開始，引入算符 $-\mathrm{i}\hbar \partial/\partial x$
- 考慮位能 $V(x)$，得到半成品方程
- 引入時間演化，推導出含時薛丁格方程
- 方程結構：$i\hbar \partial\psi/\partial t = -\frac{\hbar^2}{2m}\nabla^2\psi + V\psi$
