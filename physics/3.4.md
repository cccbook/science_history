# 3.4 卡諾循環：理想熱機的藍圖

在1824年，法國軍事工程家 Sadi Carnot 發表了里程碑式的論文《熱機的反思》，其中他提出了**卡諾循環**，這是一個理想熱機的循環過程，揭示了熱機效率的極限。

## (a) 卡諾循環的四個步驟

卡諾循環由以下四個可逆過程組成，形成一個閉合循環：

1. **等溫膨脹（A→B）**：
   - 系統與高溫爐（溫度 $T_H$ ）接觸，處於恆定溫度下膨脹，吸收熱量 $Q_H$ 。
   - 由於溫度恆定，內能不變，吸收的熱量全部轉化為功： $Q_H = W_{AB}$ 。

2. **等壓冷卻（B→C）**：
   - 系統與高溫爐隔開，開始膨脹（或壓縮，視情況而定），溫度從 $T_H$ 降至 $T_C$ 。
   - 此過程中，系統做功，並釋放少量熱量。

3. **等溫壓縮（C→D）**：
   - 系統與低溫爐（溫度 $T_C$ ）接觸，受外力壓縮，熱量 $Q_C$ 傳遞給低溫爐。
   - 由於溫度恆定，內能不變，釋放的熱量等於所做負功： $Q_C = |W_{CD}|$ 。

4. **等壓加熱（D→A）**：
   - 系統與低溫爐隔開，壓縮過程結束，溫度從 $T_C$ 升回 $T_H$ 。
   - 此過程中，功作用於系統，系統吸收少量熱量以恢復原狀。

## (b) 卡諾效率的推導

由於卡諾循環全部由可逆過程組成，根據蒙斯定理，它是可能實現效率最高的熱機。其效率 $\eta_C$ 可以推導如下：

1. **第一段（等溫膨脹）**：
   $$W_{AB} = Q_H$$

2. **第三段（等溫壓縮）**：
   $$W_{CD} = -Q_C$$
   （負號表示此階段對系統做功，即系統吸收熱量）

3. **根據蒙斯定理**：
   $$Q_C / T_C = Q_H / T_H$$

4. **效率公式**：
   $$\eta_C = \frac{W_{net}}{Q_H} = \frac{Q_H - Q_C}{Q_H} = 1 - \frac{Q_C}{Q_H} = 1 - \frac{T_C}{T_H}$$

其中 $\eta_C$ 稱為**卡諾效率**， $T_H$ 和 $T_C$ 均為絕對溫度（開爾文尺度）。

## (b) 物理意義

- **極限**：卡諾效率是任何熱機能夠達到的理論最大效率。實際熱機的效率永遠低於 $\eta_C$ 。
- **溫度差**：效率只取決於高溫爐和低溫爐的溫度差。溫差越大，理論效率越高。
- **物理本質**：卡諾循環證明了，**溫度差**是驅動熱機的根本動力，而非熱量本身的數量。

## (c) 實際意意義

雖然卡諾循環是一個理想模型，無法在實際設備中完全實現（因為所有實際過程都存在不可逆性），但它為評估實際熱機的性能提供了基準。現代的蒸汽輪機、內燃機和燃氣渦輪機都在努力接近這一理論極限。

## 本章小結

- Sadi Carnot 提出的卡諾循環是理想熱機的標準模型。
- 卡諾效率 $\eta_C = 1 - T_C/T_H$ 代表了熱機的理論上限。
- 這一理論不僅奠定了熱力學的基礎，也為現代能源轉換技術的優化提供了指針。
