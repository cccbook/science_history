# 1.1 航海表裡的致命錯字：巴貝奇與他的差分機

## 1822 年的英國劍橋，一個帶著齒輪夢想的年輕人

查爾斯·巴貝奇（Charles Babbage, 1791–1871）出生在伦敦的一个富裕家庭，父亲是银行家，母亲是名门闺秀。他小时候就展现出非凡的数学天赋，十岁就读剑桥吉士斯学院，随后进入剑桥大学 Trinity College。巴貝奇不仅是数学家，更是一位极具远见的发明家，他一生都在追求一個偉大的目標：建造一台**自動計算機**。

1822 年，年僅 31 歲的巴貝奇向皇家學會提出了他的**差分機**構想。他的目標是消除航海表計算中的人為錯誤，那個時代的航海家依賴手算的乘冪表來決定航線，一旦表中出現誤差，可能導致船隻搁淤或迷航。巴貝奇聲稱，他的機器可以**自動生成多項式數值表，且絕無誤差**。

## 齒輪之夢：差分機的機械原理

差分機的核心思想基於**差分運算**。對於一個次數為 $n$ 的多項式 $f(x)$ ，其 $n$ 次差分是常數：

$$\Delta^n f(x) = \sum_{i=0}^{n} (-1)^{n-i} \binom{n}{i} f(x+i)$$

對於二次多項式 $f(x) = ax^2 + bx + c$ ，我們有：

$$\Delta f(x) = f(x+1) - f(x) = a(2x+1) + b$$
$$\Delta^2 f(x) = \Delta f(x+1) - \Delta f(x) = 2a$$

這意味著，如果我們知道一個多項式的前若干個數值，以及它的**最高階差分**，就可以遞推計算出後面的所有數值，而無需進行昂貴的乘法運算。

巴貝奇的機器設計利用了這個原理。機器由一系列**車輪與齒輪**組成，每個車輪代表一個數值位，通過齒輪的啮合來實現加法和差分運算。當機器運轉時，車輪會自動推進，下一個數值會自動顯示。

讓我們通過一個具體的例子來理解。假設我們要生成平方數表 $0^2, 1^2, 2^2, 3^2, \dots$ ，對應多項式 $f(x) = x^2$ 。

- $f(0) = 0$
- $f(1) = 1$
- $f(2) = 4$
- $f(3) = 9$

我們計算差分：
- 一階差分： $\Delta f(0) = f(1) - f(0) = 1 - 0 = 1$
- 二階差分： $\Delta^2 f(0) = \Delta f(1) - \Delta f(0) = (f(2)-f(1)) - (f(1)-f(0)) = (4-1) - (1-0) = 3$

注意到二階差分是常數 $3$ 。這是差分機的關鍵：只要知道最開始的幾個數值和常數差分，機器就可以遞推生成所有後續數值。

運作流程如下：
1. 設置初始數值： $0, 1, 3$ （代表 $f(0)=0, \Delta f(0)=1, \Delta^2 f(0)=3$ ）
2. 每轉一格，機器通過齒輪運算：
   - 新的一階差分 = 旧的一階差分 + 常數二階差分
   - 新的多項式值 = 旧的多项式值 + 旧的一階差分
3. 顯示新的多項式值

例如，開始時顯示 $0$ ：
- 更新一階差分： $1 + 3 = 4$
- 更新多項式值： $0 + 1 = 1$
顯示 $1$ （即 $1^2$ ）：

- 更新一階差分： $4 + 3 = 7$
- 更新多項式值： $1 + 4 = 5$ ... 不對，讓我們重新計算。

實際上，正確的遞推應該是：
- 設當前顯示 $v$ ，一階差分 $d$ ，二階差分 $c$ （常數）。
- 下一步：新的顯示值 $v' = v + d$ ，新的差分 $d' = d + c$ 。

開始時： $v=0, d=1, c=3$ 。

第 1 步： $v' = 0 + 1 = 1$ ， $d' = 1 + 3 = 4$ 。顯示 $1$ 。
第 2 步： $v' = 1 + 4 = 5$ ， $d' = 4 + 3 = 7$ 。顯示 $5$ ... 但 $2^2 = 4$ ，這裡有問題。

讓我們重新檢視。也許初始設定需要 $f(0), \Delta f(0), \Delta^2 f(0)$ 以及 $\Delta^3 f(0)$ 等。對於二次多項式，只需要二階差分即可，但我的遞推公式可能有誤。

實際上，差分機的運作方式是：機器有三個注冤環（代表數值、一階差分、二階差分）。每轉一次，每個環都會根據規則推進。

也許更簡單的方式是：差分機生成的數值序列正是多項式的值。對於 $f(x) = x^2$ ，序列是 $0, 1, 4, 9, 16, 25, \dots$ 。

讓我們直接查驗差分：
- 數列： $0, 1, 4, 9, 16, 25$
- 一階差分： $1-0=1, 4-1=3, 9-4=5, 16-9=7, 25-16=9$ → $1, 3, 5, 7, 9$
- 二階差分： $3-1=2, 5-3=2, 7-5=2, 9-7=2$ → 常數 $2$

所以，如果機器開始時顯示 $0$ ，一階差分設為 $1$ ，二階差分設為 $2$ ，那麼每轉一格：
- 多項式值 += 一階差分
- 一階差分 += 二階差分

開始：值 $0, d=1, c=2$ 。
轉 1：值 $= 0+1 = 1, d = 1+2 = 3$ 。顯示 $1$ （ $1^2$ ）。
轉 2：值 $= 1+3 = 4, d = 3+2 = 5$ 。顯示 $4$ （ $2^2$ ）。
轉 3：值 $= 4+5 = 9, d = 5+2 = 7$ 。顯示 $9$ （ $3^2$ ）。
轉 4：值 $= 9+7 = 16, d = 7+2 = 9$ 。顯示 $16$ （ $4^2$ ）。

這證實了差分機的運作原理：只需要最開始的數值和常數差分，就能無限遞生成多項式數值表，而無需進行乘法運算。這對於 19 世紀的航海家和科學家而言，是一個革命性的突破。

## 穿孔卡片的靈感：雅卡爾的織布機

雖然差分機是巴貝奇的原創，但他從雅卡爾的織布機那裡獲得了關鍵的靈感。雅卡爾（Joseph Marie Jacquard, 1752–1834）發明了一種使用**穿孔卡片**來控制織布圖案的方法。

在雅卡爾的機器中，一張卡片上鉆有無數個小孔。當卡片通過閥門時，穿孔處允許針線通過，而未穿孔處則阻擋針線。這種「有無」的模式可以編碼任意圖案。

巴貝奇意識到，這種編碼方式可以應用於他的差分機。如果用穿孔卡片來記錄運算步驟或輸入數值，機器就可以被「編程」來執行不同的計算任務。這是計算機史上第一次出現**可程式化**的概念。

雖然巴貝奇在他的後續設計（如分析機）中大量使用了穿孔卡片，但他的差分機最終只使用了機械齒輪，沒有完全實現穿孔卡片的程式化潛力。這也是他後來分析機才真正實現了可程式化的原因。

## 愛達·勒芙蕾絲：世上第一個程式設計師

1830 年代，巴貝奇在伦敦舉辦了一場演示，吸引了許多貴賓，包括**愛達·勒芙蕾絲**（Ada Lovelace, 1815–1852）。勒芙蕾絲是拜倫勳爵的女兒，一位極具天賦的數學家和詩人。

勒芙蕾絲對差分機和後來的分析機著迷。她看到了機器不僅僅是計算工具，更是一種創造東西的媒介。1843 年，她在一篇關於巴貝奇分析機的文章中，發布了世上第一個**為機器編寫的算法**。

她的算法的目的是計算貝努利數，一個在數論中極其重要的序列。她的過程可以簡化描述為：

1. 設置初始條件和差分。
2. 通過遞推公式計算後續的貝努利數。
3. 將結果輸出到打孔卡片或列印紙上。

勒芙蕾絲最偉大的貢獻不僅僅是算法本身，更是她對機器潛力的遠見。她寫道：

> 這台機器的任何作用，究竟是什麼，我們都只能從她能夠做什麼，而不能從她不能做什麼來推斷。她能夠進行任何我們知道如何指揮她進行的操作。她能夀約寫出任何邏輯或數學問題的符號， provided those symbols are capable of being expressed in those particular and definite terms.

這意味著，機器有能力成為一台**普遍機器**，能夠進行我們能用明確步驟指揮它的任何運算。這是現代電腦所謂的**圖靈完備**的概念先驅。

雖然巴貝奇一生都在試圖建造他的機器，但始終受限於 19 世紀的工業技術精度，最終未能建成可運作的全尺差分機或分析機。然而，他的思想和設計圖紙流傳後世，為現代計算機的誕生奠定了基石。

## 為什麼十九世紀的精密機械無法承載二十世紀的夢想

巴貝奇的差分機之所以失敗，主要有幾個原因：

1. **精密加工技術的限制**： 19 世紀的機械加工無法製造出足夠精密的齒輪和軸承，機器在運行一段時間後，齒輪磨損導致誤差累積，最終結果偏差巨大。
2. **資金與支持不足**： 巴貝奇花費了巨大的資金和精力，但缺乏持續的政府與工業界支持。皇家學會最初給予支持，但隨著項目成本飆升，興趣逐漸減退。
3. **機械結構的複雜度**： 差分機的結構極其複雜，數千個零件需要精密配合，對於當時的工匠而言難以實現可靠性。
4. **時代先行**： 巴貝奇的構想太過先進，社會尚未準備好接受一台自動計算機的概念。大多數人仍依賴人工計算和印刷表格。

儘管失敗，巴貝奇留下了驚人的遺產。他的差分機設計圖、穿孔卡片概念以及對可程式化機器的遠見，直接啟發了後來的計算機先驅，包括赫尔曼·霍勒斯（Herman Hollerith），他利用穿孔卡片進行人口普查統計，最終創立了國際商業機器公司（IBM）。

## 本章小結

- **差分機**利用多項式差分運算，可以自動生成數值表，避免手工計算的誤差。
- **二階差分**對於二次多項式是常數，這是遞推計算的關鍵。
- **穿孔卡片**源自雅卡爾的織布機，為機器提供了程式化的可能性。
- **愛達·勒芙蕾絲**寫出世上第一個機器算法，並意識到機器作為「普遍機器」的潛力。
- 巴貝奇的失敗源於技術局限而非構想錯誤，他的遺甕為現代計算機奠定了基礎。
