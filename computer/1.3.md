# 1.3 推導：從多項式差分法到分析機的機械邏輯

## 多項式差分的數學基石

在深入探討巴貝奇的分析機之前，我們需要先建立**多項式差分**的數學基石。這是差分機運作的核心邏輯，也是連接手工計算與機械自動化的橋梁。

對於一個次數為 $n$ 的多項式 $f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$，我們定義**一階差分**為：

$$\Delta f(x) = f(x+1) - f(x)$$

對於二次多項式 $f(x) = x^2$，我們有：

$$\Delta f(x) = (x+1)^2 - x^2 = 2x + 1$$

進一步計算**二階差分**：

$$\Delta^2 f(x) = \Delta f(x+1) - \Delta f(x) = [2(x+1) + 1] - [2x + 1] = 2$$

可以看出，對於二次多項式，其二階差分是常數 $2$。這個性質推廣到次數為 $n$ 的多項式：其 **$n$ 階差分** 是常數，而 **$n+1$ 階差分** 則為 $0$。

更一般地，我們可以定義遞推公式：

$$\Delta^k f(x) = \sum_{i=0}^{k} (-1)^{k-i} \binom{k}{i} f(x+i)$$

這個公式告訴我們，如何從函數的若干個值出發，計算出其 $k$ 階差分。對於 $k = n$（多項式的次數），結果總是常數；當 $k > n$ 時，結果永遠是 $0$。

## 差分機的機械實現：輪與桿的邏輯

巴貝奇的差分機之所以能運作，在於他巧妙地將這個數學概念轉化為機械結構。機器的每一個部件都對應著數學運算的一個特定方面。

### 車輪的排列

差分機的核心硬體是一系列同心**車輪**（gears）。每個車輪的外圍刻有數字 $0$ 到 $9$，轉動一圈代表該位數值增加 $1$。車輪之間通过**齒輪傳動**相連。

設我們有三個車輪，代表百位、十位、個位。他們的傳動比設計如下：

- 個位車輪：每轉一次，百位車輪不動。
- 十位車輪：每轉十次，百位車輪前進一次。
- 百位車輪：每轉百次，記錄器（printer）打印當前數值。

這種設計確保了當個位和十位車輪聯合轉動達到一定閾值時，百位車輪會自動前進，從而實現**進位**運算。

### 差分桿與摆錘

除了車輪，差分機還使用**差分桿**（rocking lever）和**摆錘**（pendulum）來計算差值。這是巴貝奇最創新的機械設計之一。

每一組差分桿的一端連接對應的車輪，另一端連接下一組的摆錘。當車輪轉動時，差分桿會擺動，摆錘的位置取決於當前車輪的數值與前一組差分的關係。

具體運作流程如下：

1. **初始設定**：操作員首先輸入多項式的起始值 $f(0)$、一階差分 $\Delta f(0)$ 以及二階差分 $\Delta^2 f(0)$（對於二次多項式）。

2. **第一步運算**：
   - 車輪根據起始值 $f(0)$ 設置當前顯示數值。
   - 一階差分桿的擺動角度決定下一個一階差分的增量。
   - 二階差分桿的擺動角度決定一階差分每步的變化率。

3. **第二步運算**：
   - 車輪根據公式 $f(1) = f(0) + \Delta f(0)$ 更新顯示數值。
   - 一階差分更新：$\Delta f(1) = \Delta f(0) + \Delta^2 f(0)$。
   - 二階差分保持不動，因為它是常數。

4. **後續步驟**：
   - 重複上述過程，每一步都通過車輪的旋轉和差分桿的擺動，自動計算下一個多項式數值。

這個機制確保了機器無需人工干預，即可無限遞推生成多項式數值表。

## 分析機的構想：超越差分

雖然差分機只能處理多項式，但巴貝奇並未止步於此。他意識到，如果機器能夠接受**任意函數**的描述，並且能夠進行**條件跳轉**與**迴圈**，那麼它就不再受限於多項式了。

於是，他在 1837 年提出了**分析機**的構想。這台機器的目標是成為一台**普遍計算機**，能夠處理任何可計算的運算。

分析機的核心創新在於以下幾個方面：

1. **可程式化**：透過穿孔卡片輸入任意運算步驟，而非固定的差分序列。
2. **儲存記憶**：機器內部設有**「儲藏室」**，可以儲存多個變數的數值，並在需要時調用。
3. **條件判斷**：機器能夠根據運算結果的正負號，自動決定是否跳到程式的另一部分。這是現代電腦的**分支指令**雛形。
4. **迴圈重複**：機器可以被指令重複執行同一段程式碼，這是現代電腦的**迴圈**概念。

## 推導：如何用機械元件實現條件判斷

讓我們嘗試理解巴貝奇是如何設計機械條件判斷的。這是他最難的挑戰，因為機械系統本質上是線性的，而條件判斷需要非線性的決策。

巴貝奇設計了一個**閾值開關**（threshold switch）。其邏輯如下：

1. 設機器正在計算一個項目 $X$。
2. 運算結果會驅動一個**指示盤**，顯示 $X$ 的大小。
3. 當 $X$ 超過預設的**閾值** $T$ 時，指示盤上的指針會觸發一個**機械鎖扣**。
4. 這個鎖扣的一端連接到程式計數器，另一端連接到**跳轉桿**。
5. 當鎖扣觸發時，跳轉桿會推動計數器，使其跳過原本的下一條指令，轉而執行標記為「如果 $X > T$」的下一條指令。

更有趣的是，巴貝奇還設計了**負數表示**的機制。在他的系統中，負數不是使用現代的「負號」，而是使用**十補碼**。例如，數字 $-5$ 不直接表示為 $-5$，而是表示為一個巨大的正數（例如 $9995$），並在運算結束時，由機器的邏輯單元自動轉換回負數表示。

這種設計雖然複雜，但它確保了機器可以使用單一的加法器來處理 both positive 和 negative 數值，無需額外的減法單元。

## 分析機與差分機的關係

我們可以把差分機看作是分析機的**子集**。差分機只能做一次事：生成多項式數值表。而分析機則試圖成為一台**萬能機器**，能夠執行任何我們能用明確步驟指揮它的運算。

兩者之間的關鍵差異在於**程式化的層次**：

| 特性 | 差分機 | 分析機 |
|---|---|---|
| 輸入方式 | 手動設置起始值和差分 | 穿孔卡片輸入任意運算步驟 |
| 運算範圍 | 僅限多項式 | 任何可計算的運算 |
| 程式化程度 | 固定的差分序列 | 完全可程式化 |
| 硬體複雜度 | 較簡單（幾百個零件） | 極其複雜（數萬個零件） |

## 為什麼分析機未能成型

雖然分析機的構想極其偉大，但它終究未能在巴貝奇有生之年建成。原因有三：

1. **工業技術的極限**： 19 世紀的機械加工精度不足，難以製造出足夠可靠的齒輪、摆錘和閾值開關。每一個零件的誤差都會累積，最終導致計算結果偏差巨大。

2. **資金與支持的不足**： 巴貝奇一生都在爭取政府與工業界的資金，但他的項目永遠超支，最終失去了贊助者的耐心。

3. **社會的認知落差**： 當時的社會仍深深依賴人工計算和印刷表格，人們難以接受一台「可以自己思考的機器」的概念。更多人認為，計算是人腦的專長，機器只是輔助工具。

儘管失敗，巴貝奇留下了驚人的遺產。他的設計圖紙、關於可程式化機器的論文，以及對穿孔卡片的遠見，直接啟發了後來的計算機先驅。

## 本章小結

- **多項式差分**的核心性質：次數為 $n$ 的多項式，$n$ 階差分是常數，$n+1$ 階差分為 $0$。
- **差分機**利用車輪、齒輪、差分桿與摆錘，將數學差分運算轉化為機械旋轉，實現自動生成數值表。
- **分析機**是巴貝奇對差分機的擴充，引入了**穿孔卡片**、**儲藏室**、**條件判斷**與**迴圈**概念，試圖建造一台**萬能計算機**。
- **條件判斷**的機械實現通過閾值開關實現，負數則使用十補碼表示。
- 分析機未能成型的原因在於技術局限、資金不足與社會認知的落差，但其思想直接啟發了現代電腦的誕生。
