# 7.5 推導：進程 Scheduling、虛擬記憶體與分頁機制（Paging）

## 進程調度的基本原則

在多使用者作業系統時代，最核心的挑戰在於如何分配有限的硬體資源。當多位使用者同時與系統互動時，必須有一套機制，決定哪個程式現在該執行、何時該切換、以及如何確保每個使用者都能獲得公平的執行時間。

這就是**進程調度**的問題。作業系統必須在眾多就緒進程中，選出下一個該執行的進程。調度演算法多種多元，但最經典的包含：

- **先來先服務（FCFS）**：最簡單的調度方式，按照進程請求的順序依次執行。優點在於實作簡單，缺點是短作業若排在最後，可能需要等待很久才能執行
- **短作業優先（SJF）**：優先執行預估執行時間短的進程。這能顯著降低平均等待時間，但需要預先知道每個進程的執行時長，在實務中難以達成
- **輪轉時間片（Round Robin）**：將 CPU 時間切割成極小的片段，每個進程輪流執行一個時間片。這是時分共享系統中最常用的調度方式，能夠確保所有使用者都能獲得公平的執行時間
- **優先級調度**：給予不同優先級的進程不同的執行優先權。常見於作業系統的內部任務（如記錄磁碟寫入、處理中斷）優先於使用者程式

湯普森和里奇在 Unix 的 early 版本中，採用了輪轉時間片調度。這個決定，直接支撐了 Unix 作為時分共享系統的地位。因為輪轉調度簡單、可預測，且能夠良好支撐互動式使用者的需求。

## 虛擬記憶體的必要性

隨著程式規模的擴大，物理記憶體（RAM）瞬間成為了瓶頸。1970 年代初期，PDP-11 的物理記憶體僅為 64KB 或 128KB，卻需要運行複雜的 Unix 系統與多個使用者的程式。

若只能依賴物理記憶體，任何一個大型程式的載入，都可能將整個系統撐爆。更糟糕的是，多個使用者同時執行的程式，記憶體佔用會發生衝突。

這就是**虛擬記憶體**出現的原因。它的核心思想極其巧妙：給每個使用者一種「幻覺」，好像擁有極大的連續記憶體空間，而實則由作業系統在背後，將記憶體分割成塊、暫時存儲在磁碟上，必要時再調入物理記憶體。

虛擬記憶體不僅解決了記憶體不足的問題，還提供了記憶體保護機制。因為每個進程都有自己獨立的虛擬地址空間，一個進程無法觸及其他進程的記憶體區域。這極大地提高了系統的穩定性與安全性。

## 分頁機制：虛擬記憶體的實作核心

若要實作虛擬記憶體，必須有一種機制來管理「虛擬地址」與「物理地址」之間的對應。最廣為人知的，就是**分頁機制**。

分頁機制的基本原理如下：

1. **頁表**：作業系統為每個進程維護一個頁表，記錄虛擬頁面對應的物理頁框位置
2. **頁分頁**：將虛擬記憶體切割成固定大小的「頁」（通常為 4KB），將物理記憶體切割成對應大小的「頁框」
3. **快取轉譯旁路（TLB）**：為了避免每次記憶體存取都查詢慢速的頁表，硬體提供 TLB，快速緩存最近使用的虛擬頁到物理頁的映射關係

舉例來說，當程式試圖存取位址 0x1000 時：
- MMU（記憶體管理單元）先檢查 TLB
- 如果 TLB 中有對應條目，直接將虛擬位址轉換成物理位址
- 如果 TLB 沒有，則查詢頁表，找到對應的物理頁框，並更新 TLB
- 最終，CPU 可以存取實體記憶體

如果目標物理頁框目前不在記憶體中（即「頁錯」），則會觸發頁錯中斷。作業系統會捕獲這個中斷，從磁碟讀取所需的頁入入物理記憶體，並更新頁表。對程式來說，整個過程對透明，好像記憶體是無限的。

## 分段 vs 分頁

在作業系統的發展歷程中，另一種記憶體管理方案是**分段**。分段將虛擬記憶體切割成不同大小的段，每段對應一個邏輯單位（如主程式、資料段、堆疊段等）。

分段與分頁各有優劣：
- **分段**：更符合人類直覺，程式員可以清楚地看到程式結構；但 segment 大小不固定，管理開銷大，且可能產生外部碎片
- **分頁**：頁大小固定，管理相對簡單，且能夠有效對抗內部碎片。現代作業系統（如 Linux、Windows）多採用分頁機制，部分系統（如 Intel 64 和 ARM64）則支援分頁和分段的結合（如 x86 的 PAE、長模式下的 4-level 頁表）

值得一提，Linux 的記憶體管理雖然主要基於分頁，但仍保留了分段的某些概念（如 GDT/LDT 選項），作為向後相容與特定用途的支援。

## 本章小結

- 進程調度決定了 CPU 時間的分配方式，常見演算法包括 FCFS、SJF、輪轉時間片與優先級調度
- 虛擬記憶體透過「幻覺」技術，給每個進程一種擁有大記憶體的錯覺，實則由作業系統在背後管理
- 分頁機制是虛擬記憶體的核心實作，通過頁表將虛擬頁面對應到物理頁框，並利用 TLB 加速地址轉換
- 分頁相較於分段，具有固定頁大小、管理簡單、抗碎片性佳的優點
- 現代作業系統結合了分頁與分段的優點，提供靈活且高效的記憶體管理
