# 14.3 推導：RSA 非對稱加密——質數分解與歐拉單射函數

## 公鑰密碼學的里程碑

在 14.2 節中，我們探討了 Diffie-Hellman 密鑰交換協議，它讓雙方能夠在不事前共享密鑰的情況下協商出共同密鑰。然而，Diffie-Hellman 僅提供「金鑰協商」功能，並不支援「數位簽章」與「數據機密性」的雙向需求。於是，1977年，羅尼·李斯特（Ron Rivest）、阿提夫·沙米爾（Adi Shamir）與萊納德·阿德曼（Leonard Adman）在麻省理工學院，提出了 **RSA** 演算法。這是第一個實用的「非對稱加密」系統。

RSA 的名字縮寫即為其三位創辦人的姓氏首字母。其核心創新在於：將加密與解密的鑰匙分開。公鑰公開給所有人用於加密或驗證簽章，私鑰則由持有者保密用於解密或產生簽章。這種「公開與私有」的分離，標誌著公鑰密碼學的正式開業。

## RSA 的數學基礎：歐拉定理與單射函數

RSA 的安全性完全建立在 **數論** 的兩個核心概念之上： **歐拉函數** 与 **質數分解**。

### 1. 歐拉函數 φ(n)

對於一個正整數 n，φ(n) 表示小於 n 且與 n 互質的正整數計數。例如：
- φ(7) = 6（因為 1,2,3,4,5,6 皆與 7 互質）
- φ(8) = 4（因為 1,3,5,7 皆與 8 互質，而 2,4,6 非互質）

關鍵性質：若 p 为质数，則 φ(p) = p - 1。若 p 与 q 均为质数，則 φ(pq) = (p-1)(q-1)。

### 2. 質數分解的困難性

RSA 的核心在於：給定大整數 n = p × q（其中 p 与 q 均為大質數），極難逆推出 p 与 q。這就是 **質數分解問題** 的難點。若能夠輕易分解出 p 与 q，就能夠計算 φ(n) = (p-1)(q-1)，進而破解私鑰。

為什麼質數分解此麼困難？對於 1024 位以上的大質數，即使使用現在最強大的超級電腦，也需要數億年才能穷舉分解。這就是 RSA 安全性的根基。

### 3. 欧拉定理

歐拉定理指出：若 a 与 n 互質，則 a^φ(n) ≡ 1 (mod n)。這個定理成為了 RSA 運算的數學保證。

## RSA 密鑰生成流程

RSA 的密鑰生成流程極其規範，包含以下幾步驟：

1. **選取兩個大質數**：
   甲方隨機選取兩個大質數 p 与 q（通常為 512 位或 1024 位以上），以確保 n = p × q 具有足夠的位數（如 1024 位或 2048 位）。

2. **計算模數與歐拉函數**：
   計算 n = p × q 与 φ(n) = (p-1)(q-1)。

3. **選擇公鑰指數 e**：
   選擇一個整數 e，使得 1 < e < φ(n) 与 gcd(e, φ(n)) = 1（即 e 与 φ(n) 互質）。常見的選擇有 e = 65537（即 2^16 + 1），這是一個費馬費數，在運算效能與安全性之間取得了極好的平衡。

4. **計算私鑰指數 d**：
   計算 d，使得 e × d ≡ 1 (mod φ(n))。換句話說，d 是 e 在模 φ(n) 下的 modular inverse（模逆元）。這一步通常透過 **延伸歐幾里得演算法** 來實現。

5. **公鑰與私鑰的形成**：
   - **公鑰**：(n, e)
   - **私鑰**：(n, d)

## RSA 的運作流程

RSA 的運作分為「加密/解密」與「簽章/驗證」兩個方向：

### 1. 加密與解密

- **加密**：明文 M 經過加密後，得到密文 C = M^e mod n。僅擁有公鑰 (n, e) 的任何人，皆可執行此操作。
- **解密**：密文 C 經過解密後，得到明文 M = C^d mod n = (M^e)^d mod M = M^{ed} mod n。因為 ed ≡ 1 (mod φ(n))，根據歐拉定理，可還原出原始明文 M。

### 2. 簽章與驗證

- **簽章**：持有私鑰 (n, d) 的主體，對訊息或雜雜雜記 M 進行簽章，得到簽章 S = M^d mod n。這證明了訊息確實出自該主體之手，因為只有擁有私鑰的人才能產生此簽章。
- **驗證**：任何人皆可使用公鑰 (n, e) 驗證簽章：M = S^e mod n = (M^d)^e mod n = M^{de} mod n = M。若驗證通過，即證明訊息未被竄改，且確實出自持有私鑰的主體。

## RSA 的永續挑戰與演進

RSA 的問世，標誌著非對稱加密的正式登場。然而，隨著計算能力的指數級成長，RSA 的金鑰長度需求也隨之增加：

- **1024 位金鑰**：已被視為已過時，因為現代計算能力足以在相對短時間內破解
- **2048 位金鑰**：目前的工業標準，提供足夠的安全縱深
- **3072 位或 4096 位金鑰**：在需要極高安全性的場景（如金融、政府）中使用

更有趣的是，RSA 面臨著 **量子計算** 的威脅。肅射算法（Shor's Algorithm）能夠在多項式時間內解質數分解問題，這意味著若大規模量子電腦問世，現在的 RSA 密鑰將不再安全。這就是為什麼業界正致力於 **後量子密碼學** 的研究，試圖尋找抗量子的數學基礎（如基於格的加密、多變量二次型方程式問題）。

更有趣的是，RSA 的運算開銷遠大於對稱加密（如 AES）。因此，在實務應用中，通常採取「雙重方案」：使用 RSA（或 Diffie-Hellman）進行金鑰交換與簽章，然後使用 AES（或 ChaCha20）進行大量數據的加密。這正是 TLS/SSL 協議的標準運作模式。

## 本章小結

- RSA 是第一個實用的非對稱加密系統，其安全性建立在質數分解問題的困難性之上
- RSA 的密鑰生成流程依賴於歐拉函數 φ(n) 與 modular inverse（模逆元）的計算
- RSA 支援「加密與解密」與「簽章與驗證」兩大功能，公鑰公開、私鑰保密
- RSA 的金鑰長度需隨計算能力成長而增加，面臨著量子計算的潛在威脅，激發了後量子密碼學的研究
- 實務應用中，通常採用「RSA/AES 組合」：RSA 用於金鑰交換與簽章，AES 用於大量數據加密
