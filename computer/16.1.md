# 16.1 卷積神經網路（CNN）與遞歸神經網路（RNN）的局限

## 圖像與序列的兩條主線

在 15.5 節中，我們探討了 AlexNet 與深度學習的爆發。然而，在 AlexNet 之前，兩條技術路線已長期佔據主導地位：**卷積神經網路** 与 **遞歸神經網路**。它們分別擅長處理圖像與序列資料，但在深度學習興起前，均面臨著極大的設計與效能挑戰。

### 卷積神經網路：圖像處理的霸主

CNN 的核心在於 **卷積層**，它透過掃換濾波器（Kernel）在圖像上滑動，提取局部特徵（如邊緣、紋理、形狀）。隨著網絡深度的遞增，高層層次能夠捕捉更抽象的概念（如眼睛、輪廓、物體）。

CNN 的優勢在於**「平移不變性」**：無論物體在圖像中的位置如何，濾波器的檢測效果大體不變。這使得 CNN 成為圖像分類、目標偵測與圖像分割的不二選擇。然而，CNN 的缺點在於：對於序列資料（如語言、時間序列）的處理極為吃力，因為它們假設輸入資料具有固定的空間結構，對於可變長度的序列缺乏適應性。

### 遞歸神經網路：序列的專長

RNN 的核心在於 **隱藏狀態**（Hidden State），它透過遞迴方式，將上一個時刻的資訊傳遞到下一個時刻。這使得 RNN 能夠處理可變長度的序列，如語言文字、音訊波形、股價時序。

RNN 的數學表達極其簡潔：
$$h_t = \sigma(W_{hh} h_{t-1} + W_{xh} x_t + b)$$
其中 $h_t$ 為當時刻的隱藏狀態，$x_t$ 為當時刻的輸入，$W$ 為權重矩陣，$\sigma$ 為激活函數。

RNN 的優勢在於**「記憶機制」**：它能夠「記住」先前的上下文信息，適合處理時間依賴性極強的資料。然而，其缺點顯而易見：在長序列中，由於梯度在反向傳播過程中會指數級衰減（稱為「梯度消失」），RNN 难以捕捉遠距離的時序依賴。這就是為什麼，即便 RNN 結構再完善，在處理極長序列（如整本小說、多分鐘的音訊）時，效能仍屈指可數。

## 兩者的交錯與局限

在深度學習興起前，CNN 与 RNN 共同佔據了視覺與語音領域。然而，它們各有短板：

- **CNN**：難以處理可變長度的序列，除非人工設計特徵提取管道
- **RNN**：難以捕捉長距離依賴，訓練不穩定，難以並行化（因為必須依賴前一個時刻的狀態）

這兩種局限，最終為了尋找「更強大的架構」而備受矚目。於是，2017 年，Google 的研究人員提出了一個名為 **Transformer** 的全新架構，它徹底改寫了自然語言處理的規則，並逐漸擴展至圖像處理與其他領域。這就是我們將在後續章節探討的焦點。

## 本章小結

- CNN 擅長處理圖像資料，憑藉卷積層與平移不變性，成為視覺任務的霸主
- RNN 擅長處理序列資料，憑藉隱藏狀態與遞迴機制，但受困於梯度消失與難以並行化
- 兩者局限性凸顯了對「更高效、更具擴展性」架構的迫切需求，為 Transformer 的誕生鋪平了道路
- CNN 与 RNN 的交錯與局限，實質上是一次對「空間模型」与「時間模型」的深刻反思，為範式轉移鋪平了道路
