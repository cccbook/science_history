# 11.1 1989 年 CERN：伯納斯-李（Tim Berners-Lee）的「混亂但精彩」提案

## 從粒子物理到資訊網絡

1989年，蒂姆·伯納斯-李（Tim Berners-Lee）是歐洲核子研究 organisation（CERN）的資訊工程師。他每天都在處理來自全球各地的科學家，他們需要共享、協作與交換大量的研究數據。然而，當時的互聯網雖然存在，但卻極其分散：不同的研究機構使用不同的檔案格式、不同的存取協定，甚至不同的電腦架構。要在兩個系統間傳輸文件，往往需要經由繁瑣的手動轉換、壓縮與協調，效率極低。

伯納斯-李觀察到，科學家們浪費了大量時間在「技術壁壘」上，而非於「科學探索」上。他構思了一個大膽的想法：建立一個「全域性的超文本系統」，讓任何人都能透過簡單的連結，存取任何一項資訊，無論其藏身於何處、以何種格式儲存。

他的提案標題極具風格：**"Information Management: A Proposal"**（資訊管理：提案）。這份提案只有九頁，卻包含了改變世界的核心概念。他的老闆在評審時留下了字樣：「看起來有點太遠大了，但確實值得一試。」這句話，成為了伯納斯-李繼續前進的動力。

## 三大基石：URL、HTTP 與 HTML

伯納斯-李在提案中，提出了三大讓互聯網成為可能的基石技術，這三者緊密相依，共同構成了萬維網的基石：

### 1. 統一資源定位符（Uniform Resource Locator，URL）

URL 是對資源位置的標識符。它的格式極其簡潔：`scheme://host/path`。例如，`http://www.example.com/index.html` 中，`http` 代表協議、`www.example.com` 是主機名稱、`/index.html` 是資源路徑。

URL 的設計極其巧妙：它不僅僅是一個位址，更是一種「導航指南」。它告訴瀏覽器「我們要如何連線」（方案）、「去往何方」（主機）、「尋找什麼資源」（路徑）。這種抽象，讓資源的移動與重新編址變得極其靈活，無需通知所有使用者。

### 2. 超文本傳輸協議（HyperText Transfer Protocol，HTTP）

HTTP 定義了客戶端與伺服器之間的溝通規範。它是一個無狀態的、基於文本的協議，使用請求-回應模型。常見的請求方法包括 `GET`（取得資源）、`POST`（提交資料）、`PUT`（更新資源）與 `DELETE`（刪除資源）。

HTTP 的無狀態特性，意味著每一次請求之間互不記憶。這既是優點（擴展性好、易於實作），也是劣勢（需要額外機制如 Cookie 維持會話狀態）。伯納斯-李故意將狀態管理留給了上層應用，以保持 HTTP 的精簡與靈活。

### 3. 超文本標記語言（HyperText Markup Language，HTML）

HTML 是用於構建網頁結構的標記語言。它使用一系列的標籤（如 `<html>、<head>、<body>、<a>、<img>`）來定義網頁的標題、段落、圖片、超連結等元素。

HTML 的設計哲學極其樸素：它不關心視覺呈現的細節（如配色、排版），只關注內容的語意結構。這種「內容與呈現分離」的概念，為後來的 CSS（層疊式樣式表）與 JavaScript 的興起奠定了基礎。更有趣的是，HTML 的標籤與 URL、HTTP 同時問世，形成了不可分割的三角關係：URL 指向資源，HTTP 取得資源，HTML 解讀資源內容。

## 提案的影響力與實作

1990年，伯納斯-李不僅止步於提案，他親自在 CERN 的一台 NeXT 電腦上，實作了首個網頁瀏覽器與伺服器程式。他命名為 **WorldWideWeb**（後來改名為 Nexus），這是世界上第一個瀏覽器與編輯器兼具的軟體。

隨後，伯納斯-李做出了一個關鍵的決定：他將核心技術（URL、HTTP、HTML）免費公開，不申請專利、不收取版稅。這句話極其重要：他聲言「萬維網屬於每個人」。這種開放原碼、免費使用的態度，直接啟動了互聯網的爆發式成長。如果伯納斯-李選擇專利化或收費，互聯網的普及速度將劇烈受阻。

更有趣的是，1993年，CERN 宣布將萬維網技術完全免費釋出給公眾。這意味著，任何人都可以無礙地實作瀏覽器、伺服器或工具，進一步加速了生態系統的建構。

## 本章小結

- 1989年，蒂姆·伯納斯-李在 CERN 提出了「資訊管理」提案，構想了全域性的超文本系統
- 他設計了三大基石技術：URL（定位資源）、HTTP（傳輸協定）與 HTML（標記語言），這三者緊密相依，共同構成了萬維網的基石
- 伯納斯-李將核心技術免費公開的決定，是互聯網爆發式成長的關鍵因素
- 1993年 CERN 釋放技術專利，進一步加速了全球生態系統的建構
- 伯納斯-李的提案不僅是技術創新，更是一種社會願景：讓資訊無阻礙地自由流動、易於分享與協作

## 想一想

1. 伯納斯-李將核心技術免費公開的決定，對今天的開源運動與開放網路有何啟示？在現在的專利戰與商業利益交織的環境下，是否仍有空間為這種「無私奉獻」的模式？

2. URL、HTTP 與 HTML 三者緊密相依，若其中任意一項技術的設計哲學不同（例如 URL 若變得極度複雜），萬維網的發展路徑是否會發生根本性的改變？或者適者生存，技術棄用、替換？

3. 如果讓你設計一種後續於萬維網之上的下一代資訊系統，考慮到今天的語意網路、知識圖譜與 AI 搜尋需求，你會保留 URL、HTTP、HTML 三大基石，還是進行徹底的重設計？新系統的核心概念會是什麼？
