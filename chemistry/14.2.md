# 14.3 同核與異核雙原子分子的 MO 能階圖（例如 $O_2$ 的順磁性解釋）

## (a) 同核雙原子分子

對於同核雙原子分子（如 $H_2, He_2, Li_2, O_2, N_2$ ），由於原子組成相同，MO理論的應用相對直接。

### 氣態填充順序

對於第二週期元素，MO理論的填充順序為：

$$\sigma_{1s} < \sigma_{1s}^* < \sigma_{2s} < \sigma_{2s}^* < \pi_{2px} = \pi_{2py} < \pi_{2px}^* = \pi_{2py}^* < \sigma_{2pz} < \sigma_{2pz}^*$$

### 例子： $N_2$ 分子

- 電子總數：7 × 2 = 14個。
- 填充順序： $\sigma_{1s}^2 \sigma_{1s}^{*2} \sigma_{2s}^2 \sigma_{2s}^{*2} \pi_{2px}^2 \pi_{2py}^2 \sigma_{2pz}^2$
- 所有電子成對，**順磁性**： diamagnetic（無參雜電子）。
- 鍵級： $( bonding electrons - antibonding electrons ) / 2 = (8 - 2) / 2 = 3$ 。

### 例子： $O_2$ 分子

- 電子總數：8 × 2 = 16個。
- 填充順序： $\sigma_{1s}^2 \sigma_{1s}^{*2} \sigma_{2s}^2 \sigma_{2s}^{*2} \sigma_{2pz}^2 \pi_{2px}^2 \pi_{2py}^2 \pi_{2px}^{*1} \pi_{2py}^{*1}$
- **關鍵點**：最後兩個電子分別佔據 $\pi_{2px}^*$ 与 $\pi_{2py}^*$ 軌道，且**每個軌道只有一個電子**。
- 結果： $O_2$ 擁有**兩個未成對電子**，表現出**順磁性**。

### (b) 異核雙原子分子

對於異核雙原子分子（如 $CO, NO, NO^+$ ），由於原子核電荷不同，MO理論需要考慮**有效核電荷**的差異。

- **能量位置**：不同原子的軌道能量不相同，MO能階圖需經調整。
- **極化效應**：電子雲傾向於更接近電負度較高的原子。
- **例子**： $CO$ 分子，碳與氧的電子總數相同於 $N_2$ ，但由於極化效應，其性質接近 $N_2$ ，呈現**順磁性**且鍵級為3。

## 本章小結

- **同核雙原子**：填充順序固定，易於預測性質。
- ** $N_2$ **：14個電子，全部成對，順磁性，鍵級3。
- ** $O_2$ **：16個電子，最後兩個電子分別佔據 $\pi^*$ 軌道，產生**兩個未成對電子**，表現出**順磁性**。
- **異核雙原子**：考慮有效核電荷與極化效應，調整MO能階圖。
- **關鍵現象**：順磁性是MO理論預測的重要現象，解釋了為什麼 $O_2$ 具有磁性。
