# 12.1 玻爾模型在多電子原子上的潰敗

## 玻爾模型的核心主張

**尼爾斯·玻爾**（Niels Bohr，1885–1962）在1913年提出了他的**原子模型**，這被視為量子理論的里程碑。他的模型主要適用於**單電子原子**，特別是**氫原子**。玻爾的核心觀點如下：

1. 電子在特定的**軌道**上繞行原子核，而不是任意位置。
2. 這些軌道只能容納特定能量的電子，能量是**量子化**的。
3. 當電子在軌道間躍遷時，會釋放或吸收特定波長的光：$h\nu = E_{\text{high}} - E_{\text{low}}$。

### (a) 氫原子的成功

對於氫原子（只有一個電子），玻爾模型極其成功。它可以精確預測：

- **能量級別**：$E_n = -\frac{13.6\ \text{eV}}{n^2}$，其中 $n = 1, 2, 3, \dots$ 是主量子數。
- **光譜線**：里德伯公式 $\frac{1}{\lambda} = R_H \left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)$，精確匹配實驗觀測到的氫光譜。

### (b) 多電子原子的潰敗

然而，當我們嘗試將玻爾模型應用到**多電子原子**（如helium、リ튬Li等）時，理論立即出現問題：

1. **電子之間的相互作用**：在氫原子中，只有核與電子之間的靜電吸引。但在多電子原子中，存在**電子-電子排斥**。每個額外的電子都會擾亂其他電子的運動，導致能量級別不再單純依賴 $n$。

2. **屏蔽效應**：內層電子對外層電子產生**屏蔽**，使得有效核電荷 $Z_{\text{eff}}$ 小於實際核電荷 $Z$。這意味著，外層電子感受到的核吸引力比理論預測的要弱。

3. **能量級別的複雜重排**：在氫原子中，能量只取決於 $n$。但在多電子原子中，同一個 $n$ 值下，不同形狀的軌道（$s, p, d, f$）具有不同的能量。例如，$2s$ 的能量通常低於 $2p$。

### (c) 經驗證據的缺失

玻爾自己也意識到了這個局限。他承認，他的模型在多電子情況下的失效，是因為他**忽略了電子之間的相互作用**。事後，量子力學（薛丁諤方程式）的出現，才完整解釋了這些問題。

## 本章小結

- **玻爾模型**在**單電子原子**（氫）上極其成功，能夠預測能量級別與光譜線。
- **多電子原子**的情況下，玻爾模型**失效**，因為忽略了電子-電子排斥與屏蔽效應。
- **三大問題**：電子排斥、屏蔽效應、能级重排（$s, p, d, f$ 的能量差異）。
- **結局**：玻爾模型是近似模型，量子力學（薛丁諤方程式）才是多電子原子的正確描述。
