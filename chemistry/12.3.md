# 12.3 $s, p, d, f$ 軌域的角度分布與機率雲形貌

## 軌域的概率密度

根據薛丁諤方程式的解，我們可以計算出電子在空間中的**機率密度** $|\psi|^2$。這代表了「找到電子在某個位置的機率」。不同的軌域（$s, p, d, f$）有著極其不同的空間分佈。

### (a) $s$ 軌域（球對稱）

- **$l = 0$**：唯一的形狀。
- **機率密度**：$|\psi_{ns}|^2$ 在**球座標**下僅與半徑 $r$ 有關，與角度 $\theta, \phi$ 無關。
- **形貌**：電子周圍形成一個**球對稱的機率雲**。最外殼的 $1s, 2s, 3s$ 軌域都呈現同心球殼的形式。
- **節面**：$2s$ 與 $3s$ 軌域存在**節面**（Node），即機率密度為零的 spherical殼殻。

### (b) $p$ 軌域（雙筒形）

- **$l = 1$**：對應三種磁量子取值 $m_l = -1, 0, +1$。
- **機率密度**：沒有球對稱，而是有兩個**主要 lobes**（極區），中間有一個較弱的節面。
- **形貌**：三個互相垂直的 $p$ 軌域（$p_x, p_y, p_z$），每個都沿著對應的座標軸正負方向延伸。
- **實例**：氫原子的 $2p$ 軌域，機率雲呈現「兩個蘑菇狀」相連的形貌。

### (c) $d$ 軌域（雙曲殼形與花瓶形）

- **$l = 2$**：對應五種磁量子取值 $m_l = -2, -1, 0, +1, +2$。
- **機率密度**：更為複雜，存在兩種常見形貌：
  - **$d_{z^2}$ 軌域**：呈�雙 lobe（極區）加上一個環形帶。
  - **其他 $d$ 軌域**（$d_{xy}, d_{xz}, d_{yz}, d_{x^2-y^2}$）：呈現雙 lobe，位於座標平面之間（如 $d_{xy}$ 位於 $xy$ 平面之間）。
- **形貌**：類似於**花瓶**或**雙端開口的雕塑**，電子雲環繞在特定的座標平面上。

### (d) $f$ 軌域（極其複雜）

- **$l = 3$**：對應七種磁量子取值 $m_l = -3, -2, -1, 0, +1, +2, +3$。
- **機率密度**：極其複雜的形貌，難以用簡單的幾何詞彙描述。通常呈現出**八面體**或**更高次對稱**的分佈。
- **應用**：$f$ 軌域主要出現在**鑊過渡金屬**與**鑭系元素**中，決定了許多顏色與磁性性質。

### (e) 橡果雲 vs 機率雲

需要特別注意，$|\psi|^2$ 並非實體「電子雲」，而是**機率分佈**。我們常在教學中稱為「機率雲」，表示在無數次測量中，電子出現的空間分佈規律。

## 本章小結

- **$s$ 軌域**：球對稱，$|\psi|^2$ 僅隨半徑 $r$ 變化。
- **$p$ 軌域**：雙筒形，三種取向 ($p_x, p_y, p_z$)。
- **$d$ 軌域**：雙曲殼形或花瓶形，五種取向。
- **$f$ 軌域**：極其複雜，七種取向，主要於鑽金屬出現。
- **機率雲** $|\psi|^2$：表示電子出現的機率分佈，非實體。
- **節面**：$s$ 軌域的節面是 spherical殼殻，$p, d, f$ 軌域則有更複雜的節面結構。
