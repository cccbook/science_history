# 13.5 鮑林的電負度標度（Electronegativity）與鍵的極性

## 電負度的概念

**電負度**是化學家用來量化「原子吸引電子能力」的重要概念。鮑林（Linus Pauling）在1932年提出了最早的、至今仍 widely 使用的電負度標度。

### (a) 電負度的定義

電負度 $\chi$（Electronegativity）定義為：原子在化學鍵中吸引電子對的能力。數值越大，表示原子對電子的拉力越強。

鮑林的電負度尺度是以**氫設為2.1**為基準，其他元素相對數值如下：

| 元素 | 電負度 $\chi$ |
|---|---|
| 氟 | 3.98 |
| 氯 | 3.16 |
| 氧 | 3.44 |
| 氫 | 2.20 |
| 鈣 | 0.96 |

### (b) 電負度差異與鍵極性

兩種元素A、B形成鍵時，其鍵極化程度與電負度差異 $\Delta \chi = \chi_A - \chi_B$ 直接相關。

- **$\Delta \chi < 1.7$**：鍵接近**共價鍵**，電子共享相對均等。
- **$\Delta \chi \approx 1.7$**：鍵呈**極性共價鍵**，電子向更電負度高的原子傾斜。
- **$\Delta \chi > 1.7$**：鍵接近**離子鍵**，電子基本全部轉移到更電負度高的原子。

### (c) 鍵極化能的計算

鮑林提出了一個定量公式，計算鍵極化能 $E_{polar}$：

$$E_{polar} = 23.1 \times 10^{-12} \Delta \chi^2 r$$

其中：
- $\Delta \chi$ 為電負度差異。
- $r$ 為鍵長（Å單位）。
- $23.1 \times 10^{-12}$ 為經驗常數，單位為焦耳。

**應用實例**：

以HF為例：
- $\Delta \chi = \chi_F - \chi_H = 3.98 - 2.20 = 1.78 > 1.7$
- 鍵接近離子鍵，但因鍵長 $r \approx 0.92$ Å，計算出的 $E_{polar}$ 約為 20 kcal/mol，顯示鍵具有顯著的極性。

### (c) 電負度的periodic 趨勢

1. **週期趨勢**：同一週期中，由左至右，電負度**增加**。因為核電荷增加，電子被更強地拉扯。
2. **族趨勢**：同一族中，由上至下，電負度**減小**。因為原子半徑增大，電子與核心的距離增大，有效核電荷感受降低。

**實例**：
- 週期2：$\text{Li}(0.98) < \text{Be}(1.57) < \text{B}(2.04) < \text{C}(2.55) < \text{N}(3.04) < \text{O}(3.44) < \text{F}(3.98)$
- 族1：$\text{Fr}(0.7) < \text{Cs}(0.79) < \text{K}(0.82) < \text{Na}(0.93) < \text{Li}(0.98)$

## 本章小結

- **電負度 $\chi$**：原子吸引電子能力的量化指標。
- **鮑林尺度**：$\text{H}=2.1$，$\text{F}=3.98$，$\text{O}=3.44$，$\text{N}=3.04$ 等。
- **極性判斷**：$\Delta \chi < 1.7$ 為共價，$\Delta \chi > 1.7$ 為離子。
- **極化能公式**：$E_{polar} = 23.1 \times 10^{-12} \Delta \chi^2 r$。
- **趨勢**：週期增大，族降低。
