# A.2 微分方程式速成：速率方程式與衰變曲線的解法

## 一階微分方程式

在化學動力學中，反應速率常以微分方程式的形式表示。最基礎的一階方程式為：

$$\frac{d[A]}{dt} = -k[A]$$

其中 $[A]$ 為反應物濃度，$k$ 為速率常數，$t$ 為時間。

### (a) 方程式的解法：變數分離

我們可以將方程式 rearrange 為：

$$\frac{d[A]}{[A]} = -k\,dt$$

兩邊同時積分，從 $t=0$ 時 $[A]=[A]_0$ 開始：

$$\int_{[A]_0}^{[A]_t} \frac{d[A]}{[A]} = -k \int_0^t dt$$

$$\ln \frac{[A]_t}{[A]_0} = -kt$$

$$\boxed{[A]_t = [A]_0 e^{-kt}}$$

這就是**一級反應**的濃度變化公式。

### (b) 半衰期的推導

**半衰期** $t_{1/2}$ 定義為濃度減半所需的時間，即 $[A]_{t_{1/2}} = \frac{1}{2}[A]_0$。代入上式：

$$\frac{1}{2}[A]_0 = [A]_0 e^{-k t_{1/2}}$$

$$\frac{1}{2} = e^{-k t_{1/2}}$$

兩邊取自然對數：

$$\ln \frac{1}{2} = -k t_{1/2}$$

$$-\ln 2 = -k t_{1/2}$$

$$\boxed{t_{1/2} = \frac{\ln 2}{k} \approx \frac{0.693}{k}}$$

**特點**：一級反應的半衰期與初始濃度無關，每過一個半衰期，濃度減半。

### (c) 零級與二階反應的半衰期

- **零級反應**：$\frac{d[A]}{dt} = -k$，整合後 $[A]_t = [A]_0 - kt$，半衰期 $t_{1/2} = \frac{[A]_0}{2k}$（與初始濃度成正比）。
- **二階反應**：$\frac{d[A]}{dt} = k[A]^2$，整合後 $\frac{1}{[A]_t} = \frac{1}{[A]_0} + kt$，半衰期 $t_{1/2} = \frac{1}{k[A]_0}$（與初始濃度成反比）。

## 本章小結

- **一階微分方程式**：$\frac{d[A]}{dt} = -k[A]$，解為 $[A]_t = [A]_0 e^{-kt}$。
- **半衰期**：一級反應 $t_{1/2} = \ln 2 / k$，獨立於初始濃度。
- **零級/二階反應**：半衰期分別與 $[A]_0$ 成正比或成反比。
- **應用**：放射性衰變、藥物代謝動力學、環境污染擴散模型。
