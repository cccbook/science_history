# B.4 1991–2010：理論計算化學、超分子與奈米材料

| 年份 | 事件 | 重要意義 |
|------|------|----------|
| 1991 | **W.D.科爾金斯**與**R.E.普萊斯**獲諾貝爾化學獎 | 電子繞射斷層重建與納米結構 |
| 1995 | **穆提亞**與**夏普萊**正式提出**點擊化學**概念 | 高轉化率、高選擇性的分子組裂反應 |
| 1996 | **克羅托**等人正式發現**碳奈米管** | 確認奈米材料的奇妙性質 |
| 1998 | **阿蘭·霍普克**與**唐納德**成功合成**維生素 B12** | 有機合成的巔峰成就（補認） |
| 2000 | **夏普萊**與**貝納**與**斯多賈**獲諾貝爾化學獎 | 點擊化學與分子機器的奠基者 |
| 2001 | **穆提亞**與**貝納**與**斯多賈**正式設立**分子機器**研究領域 | 設計具有機械功能的分子系統 |
| 2005 | **齊默曼**與**特羅斯**發展**質子交換膜燃料電池** | 氫能技術的關鍵組件 |
| 2006 | **夏普萊**提出**生物正交化學**概念 | 在生物系統中進行化學反應而不干擾生物體 |
| 2008 | **岡村**與**西村**發展**有機雷射材料** | 有機電子學的新視野 |
| 2009 | **維納**與**比爾曼**獲諾貝爾化學獎 | 立體控制的催化反應 |
| 2011 | **T.施瓦辛格**與**Z.蓋約**發展**冷凍電子鏡（Cryo-EM）** | 生物大分子結構的革命性成像技術 |
| 2013 | **Bernardino**與**McMillan**發展**手性催化**的新范式 | 鹼性與酸性催化劑的精確控制 |
| 2015 | **施瓦辛格**與**佩特羅維奇**發展**光化學**的新途徑 | 光能與化學反應的轉化效率提升 |
| 2016 | **S.贊恩**、**F.斯坦納與J.費瑞特**獲諾貝爾化學獎 | 分子機器的奠基者 |
| 2018 | **Arnold**與**Zick**發展**酶進化**人工設計 | 生物酵素的設計與製造 |
| 2019 | **Grills**與**Nuckolls**發展**單分子機器**的穩定性控制 | 納米機械系統的極限優化 |
| 2020 | **DeepMind's AlphaFold**發布 | 人工智慧預測蛋白質三維結構，精度媲實驗 |
| 2022 | **Berkowitz**與**Waterman**發展**綠色化學原則**的更新 | 永續化學的未來方向 |

## 本章小結

- 1991–2010 年間，化學史的**資訊時代與永續發展時期**。
- 重要事件：點擊化學、分子機器、納米材料、生物正交化學、Cryo-EM、手性催化、光化學、立體控制、AlphaFold、綠色化學更新。
- 該時期化學研究從「實驗觀測」邁向「預測建模、永續設計」的轉型。

## 想一想

1. 如果 AlphaFold 在 2010 年就發布，蛋白質工程與藥物發展的進度是否會提前十年？這是否也意味著傳統的實驗驗證成本將不復存在？
2. 點擊化學與生物正交化學的發展，是否意味傳統的有機合成步驟正被簡化？傳統合成與點擊化學的優勢與劣勢是如何比較的？
3. 綠色化學原則的更新（2022）是否意味傳統化學已走上歸路？永續化學的核心挑戰是什麼？
