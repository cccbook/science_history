# 物質的奇蹟：從煉金術到量子化學

> 一本化學史，也是一部物質探索的推理小說。
> 每章拋出一個時代的實驗謎題，再把解開它的化學原理、反應式與熱力學推導一步一步鋪陳出來。

全書共五篇十七章、三份附錄，約 100 個小節。

閱讀順序建議：從第 1 章順序讀到第 17 章；熱力學與量子化學卡關時隨時翻 **附錄 A**；想看誰是誰時翻 **附錄 C**。
