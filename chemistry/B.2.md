# B.2 1931–1960：化學鍵理論、高分子與同位素追蹤

| 年份 | 事件 | 重要意義 |
|------|------|----------|
| 1931 | **施陶丁格**獲諾貝爾化學獎 | 肯定**高分子化學**的貢獻，確立高分子為大分子結構 |
| 1933 | **希爾伯特**證明**群論**的基礎 | 為分子對稱性分析提供數學工具 |
| 1934 | **伊理所藏**的人工放射性 | 開啟同位素追蹤與核化學新領域 |
| 1935 | **維格納**獲諾貝爾化學獎 | 確立**配位化學**與配位理論的地位 |
| 1938 | **哈薩丁**與**漢弗萊**提出**自由基**概念 | 解釋氧化與聚合反應的中間體 |
| 1941 | **博塞**與**哈佛**提出**配位18電子則則** | 解釋遷移金屬配合物的穩定構型 |
| 1945 | **納粹德國**利用氨合成產生**炸藥** | 二戰期間的化學武器產業 |
| 1947 | **惠更斯**與**克勞斯**發展**核磁共振（NMR）** | 奠定分子結構分析的革命性工具 |
| 1951 | **Pauling**提出**電負度尺度** | 定量描述元素吸引電子的能力 |
| 1952 | **W.K.立德**與**E.L.赫希**發展**氣相色譜** | 革命性的分離分析技術 |
| 1956 | **林斯**與**庇理那**獲諾貝爾化學獎 | 反應動力學與分子軌域理論 |
| 1958 | **莫**提出**超分子化學**雛形 | 分子自我組裝的概念啟動 |
| 1959 | **威格納**發展**電子自旋共振（ESR）** | 偵測未成對電子的強大工具 |

## 本章小結

- 1931–1960 年間，化學史的**理論與工具擴充時期**。
- 重要事件：高分子確立、群論數學化、人工放射性、配位化學、自由基概念、18電子則則、二戰化學產業、NMR誕生、電負度尺度、氣相色譜、反應動力學、超分子概念、ESR技術。
- 該時期將化學從「經驗歸納」提昇為「理論預測」與「精密分析」的階段。
