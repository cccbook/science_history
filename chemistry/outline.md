# 《物質的奇蹟：從煉金術到量子化學》大綱

## 書籍定位

**化學史 × 數學推導的科普教科書**。

一句句定位：**這是一本「用數學說故事」的化學史**。每一章拋出一個時代的實驗謎題，再把解開它的化學原理、反應式與熱力學推導一步一步鋪陳出來。

## 目標讀者

- 高中畢業到大學二年級，**會一點化學**（知道原子、分子、化學反應基本概念就夠）
- 對「物質如何被探索與重組」有好奇心的科普讀者
- 不需要先修深厚化學背景，本書會從頭講起關鍵概念

## 與既有科普化學史的差異化

市面上多數「化學史話」是**編年體**：從古代講到現代，一路線性鋪陳。本書刻意不做這件事。

| 面向 | 編年體化學史話 | 本書 |
|---|---|---|
| 組織方式 | 時間順序 | **問題驅動**：每章一個謎題，歷史為解謎服務 |
| 數學 | 幾乎沒有，或只有結論 | **推導是主線**，逐步寫出中間每一步 |
| 人物 | 傳記式介紹 | 人物只在「他做錯了什麼 / 他為什麼不相信」時出現 |
| 收束 | 「化學很神奇」 | 每章給出**這個結論解決了什麼新問題**，以及留下了什麼 |
| 貫穿主題 | 無 | **「質量守恆 × 結構重組」**兩條暗線 |

### 本書的三條暗線

1. **質量的異常是化學的母親**：燒不盡的金屬灰燼、木炭燃燒後的質量消失、氣體的質量變化，都是驅動化學家突破既有觀點的實驗謎題。
2. **每一次革命都伴隨「不接受」**：從拉瓦節被圖爾閱視與囚禁、道耳頓被學界拒絕、哈伯的氨合成爭議——**科學的推進靠的是爭吐與修正**。
3. **結構最終重組**：從元素週期表、化學鍵結、分子結構，到量子軌域，化學史的主線是「先找結構，再讓物質重組」。

## 寫作風格規範

### 每節（每個 .md 檔）的結構

1. **標題**：`# N.M 節標題`
2. **開場白**：一到兩段具體的場景——某年某月某地，某個人做了某件事，或某個實驗長什麼樣。**不要**以「化學是人類最偉大的發明之一」這種概括句開場。
3. **正文**：敘事與概念交錯。抽象的化學規則要立刻用一個具體的比喻或數字落地。
4. **數學**：必須給出公式；推導要寫出中間步驟，不能跳。
5. **收尾**：這個結論對後來的什麼問題有用。
6. `## 本章小結`：5–7 條要點
7. `## 想一看`：3 題開放式問題

### 數學格式

- 行內數學：`$...$`，例如 `$\lambda = h/p$`
- 獨立成行的數學：`$$ ... $$`
- 推導過程用 `**推導**` 開頭的小節或段落，逐步列出
- 常數：普朗克常數 $h$、光速 $c$、阿伏伽德羅常數 $N_A$、氣體常數 $R$、法拉第常數 $F$
- 單位一律用 SI，並附上常用經驗值
- 首次出現的物理量給出符號 + 中文名 + 英文名 + SI 單位

### 長度

每個 .md 檔 5000–7000 bytes（約 1500–2500 字）。

### 表格與圖

- 用 Markdown 表格做「概念對照」「諾貝爾獎年表」「公式速查」
- 用 ```mermaid 程式碼塊畫時間線、概念圖、推導流程
- 物理量的關係適合用表格；空間分佈、傳播過程適合用 mermaid

### 語氣

- 用繁體中文
- 中英術語對照，首次出現即定義
- 數學家、物理學家都用人名直接稱呼，第一次出現加括號原文
- 可以有幽默，但要「化學家的幽默」——精準、乾淨、不油膩
- 避免評論性語氣；用事實和推導本身說話
- 引用名言要謹慎：除非有明確出處，否則用「大意是」而非引號
