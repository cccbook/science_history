# B.3 1961–1990：結構生物化學、反應動力學與有機合成

| 年份 | 事件 | 重要意義 |
|------|------|----------|
| 1961 | **赫歇爾與科臣**獲諾貝爾化學獎 | 核酸鹼基配對與遺傳資訊的轉譯 |
| 1962 | **Pauling**與**Corey**發展**逆合成分析法** | 有機合成的系統化路徑規劃 |
| 1965 | **C.R.希克**與**李澤爾**發展**PCR技術**的雛形 | 蛋白質互動網絡的早期形式 |
| 1969 | **阿蘭·霍普克**與**唐納德**成功合成**維生素 B12** | 有機合成的巔峰成就 |
| 1970 | **赫歇爾**與**歐文**發展**質譜兩極化** | 分子結構與構型的精確分析 |
| 1972 | **S.核桃**與**L.伯根**發展**點擊化學**概念 | 簡化分子組裝的化學手段 |
| 1973 | **沃茨與葛拉翰**成功合成**維生素 B12** | 確認有機合成的極限與可能性 |
| 1976 | **Noyori**與**Knowles**獲諾貝爾化學獎 | 極化氫化反應的發展 |
| 1979 | **伍德沃德**離世 | 有機合成藝術大師離世，遺留經典合成路徑 |
| 1980 | **Houk**與**Tsuruta**發展**計算化學**基礎 | 量子化學與計算方法的整合 |
| 1983 | **Formosah**與**Müllen**發展**碳納米管** | 開啟奈米材料時代 |
| 1985 | **克羅托**等人發現**富勒烯 C60** | 開啟碳奈米材料新視野 |
| 1988 | **Allan）**與**Wells**獲諾貝爾化學獎 | 電導聚合與導電高分子 |
| 1989 | **Pauling**離世 | 20世紀最偉大的化學家之一離世 |

## 本章小結

- 1961–1990 年間，化學史的**實驗突破與工具成熟時期**。
- 重要事件：逆合成分析法、維生素 B12 合成、質譜二極化、點擊化學概念、極化氫化、伍德沃德離世、計算化學、碳納米管、富勒烯、導電高分子。
- 該時期見證了有機合成的精密化、奈米材料的誕生、新儀器與新理論的層出不窮。
