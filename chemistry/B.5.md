# B.5 2011–至今：冷凍電鏡、幾何催化、點擊化學與 AI 預測

| 年份 | 事件 | 重要意義 |
|------|------|----------|
| 2011 | **Cheng**與**Zhu**發展**冷凍電子鏡（Cryo-EM）** | 生物大分子結構成像的革命性突破，橫掃勝出 |
| 2013 | **Bernardino**與**McMillan**發展**手性催化**的新范式 | 鹼性與酸性催化劑的精確控制 |
| 2015 | **施瓦辛格**與**佩特羅維奇**發展**光化學**的新途徑 | 光能與化學反應的轉化效率提升 |
| 2016 | **S.贊恩**、**F.斯坦納與J.費瑞特**獲諾貝爾化學獎 | 分子機器的奠基者 |
| 2017 | **Bernardino**與**Wa**發展**酶進化**人工設計 | 生物酵素的設計與製造 |
| 2018 | **Arnold**與**Zick**發展**酶進化**人工設計 | 酶進化的人工設計與製造 |
| 2019 | **Grills**與**Nuckolls**發展**單分子機器**的穩定性控制 | 納米機械系統的極限優化 |
| 2020 | **DeepMind's AlphaFold**發布 | 人工智慧預測蛋白質三維結構，精度媲實驗 |
| 2021 | **Microsoft**與**IBM**發展**量子化學雲端平台** | 量子化學計算的雲端化與大規模應用 |
| 2021 | **Berkowitz**與**Waterman**發展**綠色化學原則**的更新 | 永續化學的未來方向 |
| 2022 | **Bulk**與**Waterman**發展**單分子機器**的穩定性控制 | 納米機械系統的極限優化 |
| 2023 | **DeepMind**與**OpenAI**合作發展**AI-driven synthesis planning** | 算法輔助設計合成路徑，縮短週期 |
| 2024 | **綠色化學獎**設立 | 表彰對環境友善的化學研究貢獻 |

## 本章小結

- 2011–至今 年間，化學史的**資訊時代、永續發展與AI驅動時期**。
- 重要事件：冷凍電子鏡、手性催化、光化學、分子機器、酶進化、單分子穩定性、AlphaFold、量子化學雲端平台、AI合成規劃、綠色化學獎。
- 該時期化學研究正經歷從「經驗觀測」到「預測建模、永續設計、AI輔助」的根本轉型。
