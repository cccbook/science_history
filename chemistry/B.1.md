# B.1 1901–1930：元素發現、電化學與熱力學奠基

| 年份 | 事件 | 重要意義 |
|------|------|----------|
| 1901 | 第首屆諾貝爾化學獎頒獎 | 簡森（Svante Arrhenius）獲獎，表彰電離理論的貢獻 |
| 1910 | 發現**氦**元素 | 在太陽日冕光譜中識別， later 在地球上發現 |
| 1913 | 莫斯利發表**莫斯利方程式** | 用 X 射線光譜確定**原子序** $Z$ ，重新排列週期表 |
| 1918 | **弗里茨·哈伯**合成**氨** | $N_2 + 3H_2 \rightleftharpoons 2NH_3$ ，奠定工業肥料基礎 |
| 1921 | **弗雷德里克·桑贊**獲諾貝爾獎 | 以酵素研究成就獲獎 |
| 1923 | **瓊斯·布忍斯特**與**馬丁·勞里**提出**酸鹼理論** | 以質子轉移定義酸鹼 |
| 1926 | **薛丁諤**與**海森堡**獨立發表**量子力學** | 薛丁諤方程式、不確定性原理 |
| 1928 | **安德森**發現**正電子** | 反物質的首次實驗證據 |
| 1930 | **波利尼克**預測**中微子** | 伴隨 $\beta$ 衰變，保守能量定律 |
| 1932 | **查德威克**發現**中子** | 完成原子核三大基本粒子（質子、中子、電子） |
| 1934 | **伊理所藏**放射人工合成 | 製備放射性元素，開啟核化學時代 |
| 1935 | **雅各布·馮·休厄爾**獲諾貝爾獎 | 離子鍵與配位化學的奠基者 |
| 1938 | **斐斯**發展**離子換換膜** | 氣體分離與淨化技術 |
| 1939 | **哈佛大學化學系**躲戰 | 二戰前的學術遷徙與研究方向轉向 |

## 本章小結

- 1901–1930 年間，化學史的**奠基時期**。
- 重要事件：電離理論、氦的發現、莫斯利方程式、氨合成、酸鹼理論、量子力學的誕生、正電子、中子、人工放射性元素。
- 該時期確立了現代化學的核心概念：電子結構、化學鍵、熱力學定律、工業化學流程。

## 想一想

1. 如果莫斯利在 1913 年之前去世，原子序與原子量的爭議是否會持續更久？化學家是否會繼續試圖以原子量重新排列週期表？
2. 哈伯的氨合成技術在第一次世界大戰期間的應用，是否真的是轉折點？戰前的肥料來源是否已經不足以養活不斷增長的人口？
3. 1930–1940 年代的核化學突發，是否可以視為化學與物理的分界線？核化學的發展是否改變了化學家對原子結構的認知？
