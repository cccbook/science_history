# 3.3 推導：質量守恆定律與化學反應方程式的平衡

## 質量守恆定律的邏輯基石

在拉瓦節的實驗之後，化學界對**質量守恆定律**有了無可置疑的實驗基礎。這個定律聲明：**在一個封閉系統內，化學反應發生前後，總質量保持不變**。這不僅是一條觀察規律，更是現代化學的基石。

我們可以透過一個簡單的化學反應，來推導為什麼質量必須守恆，以及如何用化學方程式來表達。

### (a) 反應前的質量記錄

設我們有一個封閉的反應爐，裡面放有 2 原子的氫氣（$H_2$）與 1 原子的氧氣（$O_2$）。實驗前，我們精密稱量：

- 氫氣質量：$m_{H_2} = 2.016\ \mathrm{g}$
- 氧氣質量：$m_{O_2} = 15.999\ \mathrm{g}$
- **總質量**：$m_{\text{total, before}} = 2.016 + 15.999 = 18.015\ \mathrm{g}$

### (b) 反應發生：化學變化

當氫氣與氧氣混合並點燃時，發生下面的反應：

$$2H_2 + O_2 \to 2H_2O$$

反應過程中，氫原子與氧原子重新排列，形成水分子。這是一個**放熱反應**，同時釋放出光與熱能。但是，根據**質能守恆**（愛因斯坦的 $E=mc^2$），即使能量釋放出來，質量總量在封閉系統中也是守恆的——釋放出來的能量對應的質量極其微小，在化學實驗誤差範圍內可以忽略不計。

### (c) 反應後的質量記錄

反應結束後，我們收集產生的水（$H_2O$），並精密稱量：

- 水的質量：$m_{H_2O} = 18.015\ \mathrm{g}$

驚人的事實是：**$m_{\text{total, after}} = 18.015\ \mathrm{g} = m_{\text{total, before}}$**。

### (d) 推導過程：為什麼會守恆？

這歸因於兩個基本原則：

1. **原子守恆**：反應前後，氫原子數量與氧原子數量完全相同，只是重新排列了化學鍵。
2. **質量守恆**：每個原子的質量不變，也不會消失或創造。所以，反應前後的總質量必須相等。

數學上，我們可以寫成：

$$\sum m_{\text{reactants}} = \sum m_{\text{products}}$$

其中 $\sum$ 代表「全部反應物」與「全部產物」的質量總和。

## 化學反應方程式的平衡

質量守恆定律的直接後果，是我們必須**平衡化學反應方程式**。這意味著，方程式兩邊的原子數必須相同。

### 步驟 1：寫出非平衡方程式

以燃燒甲烷為例：

$$\text{CH}_4 + O_2 \to \text{CO}_2 + \text{H}_2\text{O}$$

### 步驟 2：計算每一邊的原子數

- **左邊（反應物）**：
  - C：1 個
  - H：4 個
  - O：2 個

- **右邊（產物）**：
  - C：1 個（CO₂ 中）
  - H：2 個（H₂O 中）
  - O：2 + 1 = 3 個（CO₂ 有 2 個，H₂O 有 1 個）

### 步驟 3：調整係數以達到平衡

我們需要讓每一種原子的數量兩邊都相同。觀察發現：

- H：左邊 4 個，右邊只有 2 個。所以我們需要把 H₂O 的係數改為 2。
- O：調整後，右邊變成 CO₂ (2個) + 2×H₂O (2個) = 4個。左邊 O₂ 需要 2個才能給 4個。

調整後的方程式：

$$\text{CH}_4 + 2O_2 \to \text{CO}_2 + 2\text{H}_2\text{O}$$

驗證：
- **左邊**：C=1, H=4, O=4
- **右邊**：C=1, H=4, O=1+2=3...等等，讓我們重新計算：

右邊：
- CO₂ 中有 O=2
- 2 × H₂O 有 H=4, O=2
- 總計：O = 2 + 2 = 4

是的！現在兩邊都一致。

### 步驟 4：最終平衡方程式

$$\boxed{\text{CH}_4 + 2O_2 \to \text{CO}_2 + 2\text{H}_2\text{O}}$$

這個方程式不僅表示反應發生的化學意義，也完美體現了**質量守恆定律**。

## 本章小結

- **質量守恆定律**在封閉系統中實驗證明：反應前後總質量不變。
- **原子守恆**是守恆的微觀基礎：原子不消失，只重新排列。
- **化學反應方程式的平衡**是質量守恆的數學表達：兩邊原子數相同。
- **甲烷燃燒例題**：$\text{CH}_4 + 2O_2 \to \text{CO}_2 + 2\text{H}_2O$。
- **平衡步驟**：計算每種原子數 → 調整係數 → 驗證兩邊一致。
