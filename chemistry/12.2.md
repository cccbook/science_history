# 12.2 推導：氫原子薛丁諤方程式的波函數解與量子數（$n, l, m_l, m_s$）

## 薛丁諤方程式的形式

在1926年，**埃尔温·薛丁諤**（Erwin Schrödinger，1887–1961）提出了具有里程碑意義的**薛丁諤方程式**：

$$i\hbar \frac{\partial \psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi + V\psi$$

其中：
- $\psi$ 為**波函數**，描述電子的量子狀態。
- $\hbar$ 為**約化普朗克常數** $\hbar = h / 2\pi$。
- $m$ 為電子質量。
- $\nabla^2$ 為拉普拉斯算子，描述空間上的變化。
- $V$ 為**位勢能**，對於氫原子，$V = -\frac{e^2}{4\pi\varepsilon_0 r}$。

## 靜止狀態的解

對於**氫原子**，我們可以解出薛丁諤方程式的**時間獨立形式**，得到波函數的精確解。這個解是將三個**量子數**引入，完全決定了電子的量子狀態。

### (a) 主量子數 $n$

- 決定電子的**能量級別**與**平均距離原子核的距離**。
- $n = 1, 2, 3, \dots$（正整數）。
- $n$ 越大，電子越遠離原子核，能量越高（接近歸零）。

### (b) 角動量量子數 $l$

- 決定**軌道的形狀**。
- $l$ 的取值範圍：$l = 0, 1, 2, \dots, n-1$。
- 對應的軌道形狀命名為 **$s, p, d, f$**：
  - $l = 0$ → **$s$軌道**（球形）
  - $l = 1$ → **$p$軌道**（雙筒形）
  - $l = 2$ → **$d$軌道**（雙曲殼形）
  - $l = 3$ → **$f$軌道**（複雜形狀）

### (c) 磁量子數 $m_l$

- 決定**軌道在空間中的取向**。
- $m_l$ 的取值範圍：$-l \le m_l \le +l$，總共有 $2l + 1$ 個可能值。
- 例如：$l = 1$（$p$軌道）時，$m_l = -1, 0, +1$ 三種取向（$p_x, p_y, p_z$）。

### (d) 自轉量子數 $m_s$（或自旋量子數 $s$）

- 描述電子的**自轉屬性**。
- $m_s$ 的取值僅有兩個：$+\frac{1}{2}$（稱作「自旋向上」）與 $-\frac{1}{2}$（稱作「自旋向下」）。
- 這是泡利不相容原理的基礎：同一個軌道內，最多只能容納兩個電子，且它們的 $m_s$ 必須相反。

## 本章小結

- **薛丁諤方程式** $i\hbar \frac{\partial \psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi + V\psi$：量子力學的核心方程。
- **四個量子數**：
  - $n$（主量子數）：能量級與平均距離。
  - $l$（角動量量子數）：軌道形狀 ($s, p, d, f$)。
  - $m_l$（磁量子數）：空間取向。
  - $m_s$（自轉量子數）：自旋 $+\frac{1}{2}$ 或 $-\frac{1}{2}$。
- **氫原子能量公式**：$E_n = -\frac{13.6\ \text{eV}}{n^2}$。
- **意義**：完整描述了電子的量子狀態，取代了玻爾模型。
