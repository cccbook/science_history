# 3.3 塞麥爾維斯（Semmelweis）的悲劇：洗手如何降低產褥熱死亡率？

1847年，匈牙利醫生伊格納茲·塞麥爾維斯（Ignaz Semmelweis，1818–1867）在維也納產科醫院發現一個驚人的規律：由醫學學生協助產婦的產褥熱死亡率，遠高於由助產士（midwives）協助的死亡率。他觀察到，醫學學生在進入產房前，先進行屍體解剖，接觸了感染了細菌的組織。

塞麥爾維斯要求學生在接觸產婦前，必須用氯化石灰溶液洗手。這個簡單的措施產生了驚人效果：短短數週內，產褥熱死亡率從每100例約13例，驟降至每100例約2例。這種降低幅度在當時震驚全場，證明了傳染的實質存在與傳播途徑。

然而，塞麥爾維斯的發現遭到了當時醫學界的猛烈抨擊。醫生們認為自己的手是乾淨的，拒絕接受「自己可能傳播疾病」這種恥辱性的觀點。此外，當時主流的「腐敗氣體說」認為疾病是由空氣中的惡臭氣體造成，洗手被視為多餘的儀式。

1850年，塞麥爾維斯被維也納大學免職，並試圖在布達佩斯繼續他的研究，但他的理論仍被排斥。最終，他在1867年因為一場手術後的創口感染而死亡，享年僅47歲。事後證實，產褥熱是由鏈球菌等細菌引起的，而塞麥爾維斯早在15年前就預見了這一事實。

塞麥爾維斯的一生是一個悲劇：他的觀察正確，證據確鑿，卻因為醫學界的保守與傲慢而被扼殺。事後他被譽為「洗手之父」，他的理論直接為了後來的細菌學說確立、李斯特的無菌手術技術鋪平了道路。這一章節提醒我們：優秀的臨床觀察若無法被社群接受，可能會付出巨大的代價。
