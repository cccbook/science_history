# C.3 臨床與藥物狂人：塞麥爾維斯、弗萊明、穆利斯、卡里科

- 伊格納茲·塞麥爾維斯（Ignaz Semmelweis，1818–1867）：匈牙利產科醫生，他在1847年發現洗手可以降低產褥熱死亡率，卻遭到當時醫學界的猛烈抨擊與排斥。事後證明他正確，他被視為「洗手之父」，其悲劇提醒著科學界對新觀點的態度。

- 亞歷山大·弗萊明（Alexander Fleming，1881–1955）：蘇格蘭病理學家，1928年在實驗室中意外發現了青黴素的抗菌活性。雖然他未能大量生產，但他的觀察為後來霍華德·弗洛里與恩諾克斯·張士的工業化奠定了基礎。他因此榮獲1945年諾貝爾生理學或醫學獎。

- 卡羅琳·穆利斯（Kary Mullis，1944–2019）：美國生物化學家，1983年發明了聚合酶鏈式反應（PCR）技術。這一突破讓我們能夠從微量的DNA樣本中放大特定區段，成為了現代分子診斷、法醫鑑定與疫苗開發的基石。他因此與共同研究者共享1993年諾貝爾化學獎。

- 卡汀·卡里科（Katalin Karikó，1955–）：匈牙利裔美國生物化學家，她在1990年代致力於mRNA 作為治療藥物的研究，期間長期面臨資助削職與職位降低。2005年，她與同事發現將嘌呤核苷修飾為類似物可以降低mRNA的免疫原性。她的堅持直接啟動了mRNA 疫苗技術的成熟，2023年她與Drew Weissman共同榮獲諾貝爾生理學或醫學獎，證實了mRNA 作為藥物平台的合法性。

這四位「狂人」或「被遺忘的英雄」，無論是因為時代先見、實驗失敗還是理論先行，都在醫學的道路上留下了不可磨滅的印記。
