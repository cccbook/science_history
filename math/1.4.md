# 1.4 泰勒斯（Thales）：第一個把證明引進幾何學的人

**背景場景：公元前 624 年，希臘的 Miletus（米利都）。**

泰勒斯出生於富商家庭，年少時曾遊學埃及，學成後返回希臘。相傳他曾用幾何知識預測了一場大風暴，並成功安排商船避風，這讓人們開始將他視為懂得「看天識地」的聖人。

**核心貢獻：把證明引進幾何學**

泰勒斯最偉大的成就在於他不再滿足於測量、畫圖這種實務技能，而是試圖用邏輯推論證明幾何事實。他留下了幾個至今仍被教導的定理：

1. **徑在直徑上的角是右角**：在一個圓內，以直徑為一邊的三角形，頂點在圓上的角度永遠是直角。這在今天的寫法是：若 $AB$ 是直徑， $C$ 是圓上任意點，則 $\angle ACB = 90^\circ$ 。

2. **垂直平分線定理**：過圓心的垂直線會將弦平分。

3. **三角形相似定理**：若兩個角分別相等，則三角形相似。

**推導過程（簡化版）**

證明「徑在直徑上的角是右角」：

- 設圓心為 $O$ ，直徑為 $AB$ ，圓上點為 $C$ 。
- 連接 $OA, OB, OC$ 。因為 $OA = OB = OC$ （半徑相等）， $\triangle OAC$ 与 $\triangle OBC$ 為等腰三角形。
- 設 $\angle OAC = \alpha$ ， $\angle OBC = \beta$ 。因為三角形內角和為 180°，可得 $\angle AOC = 180^\circ - 2\alpha$ ， $\angle BOC = 180^\circ - 2\beta$ 。
- 因為 $A, O, B$ 共線， $\angle AOC + \angle BOC = 180^\circ$ ，即 $(180^\circ - 2\alpha) + (180^\circ - 2\beta) = 180^\circ$ 。
- 整理得 $2\alpha + 2\beta = 180^\circ$ ，即 $\alpha + \beta = 90^\circ$ 。
- 也就是說 $\angle ACB = \alpha + \beta = 90^\circ$ 。

**本章小結**

1. 泰勒斯是第一個將幾何事實「證明」而非單純「測量」的 Greek 數學家。
2. 他發現的「徑在直徑上的角是右角」是幾何學的第一定理。
3. 這標誌著從實務幾何向理論邏輯幾何的轉變的開始。
