# 2.5 歐多克索斯（Eudoxus）的比例論：拯救第一次數學危機

## 時代背景：第一次數學危機的深水區

在西元前 5世紀，希帕索斯對 √2 作為無理數的發現，對畢達哥拉斯學派造成了震盪。他們的核心信條「萬物皆數」（一切皆可用整數比例表示）瞬間崩塌。如果 √2 無法表示為分數，那麼什麼東西可以？這不僅僅是一個數學問題，更是一場哲學危機：如果數字無法精確描述幾何實體，那麼人類對宇宙的理解是否也會動搖？

**危機的核心**：
- 畢達哥拉斯學派依賴可約數（分數）來測量長度。
- 勾股定理 $a^2 + b^2 = c^2$ 隨處顯現，當 $a$ 和 $b$ 為整數時，$c$ 常常變成 √（某個整數），這往往是無理數。
- 這意味著大多數「好看」的三角形斜邊都是「無法捕捉」的數字。

**局勢轉折的人物**：
**歐多克索斯**（Eudoxus of Cnidus，約西元前 408–約西元前 355 年），古希臘的偉大數學家和哲學家。他不是試圖否定 √2 的無理，而是試圖**重新定義「數」與「比例」的概念**，從而構建一個能夠容納無理數的完備數體系。他的貢獻被視為**西方數學史上最偉大的成就之一**，也是歐幾里得《幾何原本》第五卷的理論基礎。

## 歐多克索斯的革命性思維

### 1. 問題的本質：不可通約的比例

在歐多克索斯之前，人們對比例的理解主要有兩種：

- **大小比較**：$a > b$，$a = b$，$a < b$。這是一種單純的順序關係。
- **可約數比例**：$a/b$ 是一個整數或分數。這是當時主流的觀點。

問題在於當 $a/b$ 是無理數時，這兩種說法都失效了。比如說，$\sqrt{2}/1$ 無法簡化，但我們仍然能夠說 $\sqrt{2} > 1$，$\sqrt{2} < 2$，$\sqrt{2} > 1.4$ 等。但這些都無法精確表示比例的「相等」或「大小」。

### 2. 歐多克索斯的定義：超越數值的比例

歐多克索斯在其著作中（現多見於歐幾里得《幾何原本》第五卷中）提出了極為精確的定義，我們可以現代化如下：

**定義（歐多克索斯比例定理）**  
對於四個正實數 $a, b, c, d$，我們說 $a : b = c : d$（$a$ 與 $b$ 的比例等於 $c$ 與 $d$ 的比例），如果：

> 對於任意正整數 $m$ 和 $n$：
> - 當 $m < n$ 時，$m \times a < m \times b$ 的情況，等同於 $m \times c < n \times d$ 的情況。
> - 當 $m = n$ 時，$m \times a = n \times b$ 的情況，等同於 $m \times c = n \times d$ 的情況。
> - 當 $m > n$ 時，$m \times a > n \times b$ 的情況，等同於 $m \times c > n \times d$ 的情況。

**直觀意義**：
這個定義完全**避免**了使用分數來表示比例。它透過「整數乘法」來比較兩個比例的大小，而不需要知道比例的精確數值。

**舉例說明**  
假設我們想比較 $\sqrt{2} : 1$ 與 $141 : 100$（即 1.41）：
- 根據歐多克索斯的定義，我們不需要計算 $\sqrt{2}$ 的小數值。
- 我們只需要檢查：對於任意 $m, n$，$m \times \sqrt{2}$ 与 $n \times 1$ 的大小關系，是否與 $m \times 141$ 与 $n \times 100$ 一致。
- 因為 $(\sqrt{2})^2 = 2$，我們可以透過平方來比較：$2 \times 100^2 = 20,000$ 与 $141^2 = 19,881$。由於 $20,000 > 19,881$，所以 $\sqrt{2} > 141/100$。

**這個定義的偉大之處在於**：
它證明了即使我們無法寫出 $\sqrt{2}$ 的精確分數，我們仍然可以**精確地**比較它與任意分數的大小。這意味著無理數不再是「數學禁區」，而是可以被邏輯操作的對象。

## 如何拯救第一次數學危機？

### 1. 理論層面的重構

歐多克索斯的比例論實質上構建了一個**有序域**（ordered field）的雛形。在這個體系中：
- 所有的數（包括無理數）都可以進行加減乘除運算。
- 任意兩個數都可以比較大小（大於、等於、小於）。
- 雖然無理數無法表示為分數，但它們位於可約數之之間，構成了實數線上的「缺口」。

**關鍵突破**：
不再需要把「數」等同於「分數」。**任何可比較、可運算的量都是數**。這為後來第欧根尼德斯（ratio theory）與實數系統的構建鋪平了道路。

### 2. 幾何層面的應用

在《幾何原本》第五卷中，歐幾里得使用了歐多克索斯的理論來處理**相似三角形**與**面積比例**的問題。例如：

**題目**：已知兩個直角三角形的直角邊比例相同，證明斜邊的比例也相同。

**傳統困境**：
如果直角邊是 $\sqrt{2}$ 和 1，我們無法用分數表示它們的比例，傳統方法無法處理。

**歐多克索斯方案**：
透過比例定理，我們可以證明：無論直角邊的具體長度是多少，只要它們的比例相同，對應的斜邊的比例也相同。這不需要具體的數值，只需要遵循整數乘法的比較規則。

## 歐多克索斯對後世的深遠影響

### 1. 為歐幾里得《幾何原本》鋪平道路

歐幾里得在第五卷特別致敬歐多克索斯，所有關於比例的定理和證明皆基於歐多克索斯的定義。這使得《幾何原本》成為了人類歷史上第一本系統化處理無理數與連續量的書籍。

**教科書級別的影響**：
從西元前 300 年至今，幾百代的數學學生在學習勾股定理、相似三角形、面積比例時，皆是在使用歐多克索斯/Euclid 系統。這個系統之所以能延續兩千年，正是因為它**既嚴謹又實用**。

### 2. 為實數系統的現代構建鋪平道路

雖然現代我們通過戴德金割（Dedekind Cut）或柯西序列正式構建了實數系統，但其核心思想歸根於歐多克索斯：

- **戴德金割**（Dedekind Cut）：將實數線切分為兩個集合，左邊的所有數都小於右邊的所有數。這本質上就是在 utilisation of Eudoxus 的比例概念實現了「填充」無理數的缺口。
- **柯西序列**：通過極限過程來定義無理數的近似值。

**歷史迴圈**：
歐多克索斯嘗試用「整數比較」來處理無理數，最終演變成了現代實數的正式定義。這證明了直覺與邏輯之間永遠存在著微妙的對話。

### 3. 哲學意義：數的本體論轉向

歐多克索斯的貢獻不僅僅是數學技術，更是一場**本體論的轉向**：

- **以往觀點**：數 = 整數或分數。如果無法表示，就不是「真正的數」。
- **歐多克索斯觀點**：數是任何可以進行比較與運算的量。無理數雖然無法寫成分數，但它們是數系統中不可或缺的一部分。

這一轉向為後來哥白尼、開普勒、牛頓等天文家與物理家在處理連續運動、軌道計算時提供了堅實的數學基石。
