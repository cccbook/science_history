# 2.1 印度數字與「零（Zero）」的誕生：概念上的無與數值的零

**背景場景：公元前 5世紀，印度恆河流域。**

在公元前 5 世紀的印度，數學不再僅僅是祭司們計算祭祀日期的工具。在恆河流域的王國裡，沙門與國王都開始關注更基礎的問題：如何精確地測量田界？如何計算天文週期？如何描述「無」？

**核心概念：零的雙重性**

在印度文明中，"zero"（零）並非單一概念，而是兩種截然不同的思想結合而成：

1. **概念上的無（Shunya）**：佛教與耆那教哲學中關於「空性」、「無所屬」的思想。這是一種形而上的狀態，描述事物消逝或歸於虛無。

2. **數值上的零（Bindu）**：實際上的數位符號，用於位值制系統中表示「無任何數值的位置」。這使得 10、100 等大數字能夠用少量符號表示。

**發展過程**

早在吠陀經時期（公元前 1500 年），印度已開始使用空白符號表示「沒有這個數值」。至於公元前 4世紀的薄伽梵歌註釋中，出現了 "shunya" 一詞，專指完全歸零的狀態。

公元前 5世紀，印度數學家開始正式將 "shunya" 導入算術運算。他們定義了零參與加減乘除的規則：

- $0 + n = n$
- $0 \times n = 0$
- $n / 0 = \text{未定義}$

這些規則在當時極具突破性，因為其他古代文明（如巴比倫、埃及）都沒有將零視為一個可以運算的數值。

**本章小結**

1. 零的概念在印度同時誕生於哲學（shunya）與數學（bindu）。
2. 印度數學家是最早將零作為一個可以運算的數值而非單純占位符的文明。
3. 零的引入讓位值制系統（十進位制）成為可能，這是現代數學的基石。
