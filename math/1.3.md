# 1.3 推導：巴比倫人的平方根迭代法（開方演算法）

## 時代背景：無數值記號的時代

在西元前幾千年的美索不達米亞，數家使用60進位制，但他們並沒有我們今天熟悉的「小數點」概念。這意味著一個數的大小完全取決於上下文，記號本身只表示數值的位置。因此，精確計算平方根對他們來說極為重要——不僅是學理探索，更直接關聯土地面積、金屬比例和建築設計。

## 平方根演算法的歷史傳承

雖然現代人將這個演算法歸功於艾薩克·牛頓（17世紀），但證據顯示巴比倫人早在西元前 2000 年就已經掌握了類似的遞迭思維。我們的了解主要來自兩個來源：

1. **Plimpton 322 泥板**：如前所述，其中的數字組暗示了對勾股數的系統化了解，這本質上是平方根問題的變體。

2. **泥板計算痕跡**：考古學家在多個美索不達米亞遺址發現了計算過程的痕跡，顯示人們實際上使用了一種類似試錯後緬釐的方式，漸漸遞迭到目標值。

## 演算法的現代表述

我們今天稱為「巴比倫平方根演算法」或「牛頓法的特別形式」，其核心公式為：

**遞迭公式**
$$x_{n+1} = \frac{1}{2}\left(x_n + \frac{S}{x_n}\right)$$

其中：
- $S$ 為我們想求平方根的數
- $x_n$ 為第 $n$ 步的近似值
- $x_{n+1}$ 為下一步的改進值

**為什麼這個公式有效？**

這其實是透過**切線逼近**導出的。我們想尋找點 $(x_n, S/x_n)$ 的平均值，這等價於在曲線 $y = S/x$ 點 $(x_n, S/x_n)$ 處切線的 x-axis 截距。幾何觀點如下：

1. 從猜測值 $x_n$ 開始，畫出曲線 $y = S/x$ 。
2. 在點 $(x_n, S/x_n)$ 處畫出切線。
3. 切線與 x 軸的交點即為更好的近似值 $x_{n+1}$ 。
4. 數學證明，這個交點座標為 $\frac{1}{2}(x_n + S/x_n)$ 。

## 收斂速度：平方化誤差

這個演算法最驚人的特性是**二次收斂**：每次迭代後，正確的有效數字約會翻倍。

**誤差分析**
令真值為 $\sqrt{S}$ ，定義誤差 $e_n = x_n - \sqrt{S}$ 。則有：

$$e_{n+1} \approx \frac{e_n^2}{2\sqrt{S}}$$

這意味著：
- 如果 $e_n$ 很小（比如誤差 0.1），那麼 $e_{n+1}$ 會變成約 $0.1^2 / (2\sqrt{S}) = 0.005 / \sqrt{S}$ ，誤差平方化。
- 這是為什麼這個演算法收斂極快的原因。

## 實例演練：求 $\sqrt{10}$

讓我們逐步演算，求 $\sqrt{10} \approx 3.16227766...$

**步驟 0：初始猜測**
我們可以選擇一個合理的初值。常見策略包括：
- 猜 $x_0 = S$ （即 10）
- 猜 $x_0 = S/2$ （即 5）
- 猜 $x_0 =$ 最近的完全平方根（對 10 而言，是 9，即 $x_0 = 3$ ）

**選擇 $x_0 = 3$ 作為起點**（因為 $3^2 = 9$ 接近 10）

**步驟 1：第一次迭代**
$$x_1 = \frac{1}{2}\left(3 + \frac{10}{3}\right) = \frac{1}{2}\left(3 + 3.333...\right) = \frac{1}{2}(6.333...) = 3.1666...$$

誤差： $e_1 = 3.1666... - 3.16227766... = 0.0044$

**步驟 2：第二次迭代**
$$x_2 = \frac{1}{2}\left(3.1666... + \frac{10}{3.1666...}\right) = \frac{1}{2}\left(3.1666... + 3.15789...\right) = \frac{1}{2}(6.3245...) = 3.16225...$$

誤差： $e_2 \approx 0.000027$ （已精確到小數點後 5 位）

**步驟 3：第三次迭代**
$$x_3 = \frac{1}{2}\left(3.16225... + \frac{10}{3.16225...}\right) \approx 3.16227766...$$

誤差： $e_3$ 已小於 $10^{-8}$ ，基本上達到浮點數的極限精度。

## 巴比倫人是如何實踐的？

雖然我們無法確定他們是否使用了我們今天的公式記號，但他們的泥板計算痕跡顯示一種**「不斷緬釐」**的思維模式：

1. **先猜一個近似值**：比如說想求 $\sqrt{2}$ ，先猜 1。
2. **檢查平方**： $1^2 = 1$ ，誤差為 1（太小了）。
3. **調整猜測**： maybe try 1.5，平方得 2.25，誤差變為 -0.25（超過了）。
4. **取平均**：(1 + 2/1)/2 = 1.5，這就是遞迭公式的第一步！
5. **繼續緬釐**：用新值 repeat step 2-4，直到滿意精度。

這種「猜-檢-調-平均」的迭代思維，與現代的數值分析方法有著本質的相通性。

## 推導過程的幾何詮釋

我們可以透過幾何方式理解這個公式：

**構建一個長方形**
已知面積為 $S$ ，想求邊長 $x$ 使得 $x^2 = S$ 。

畫一個邊長為 $x$ 的正方形，面積為 $S$ 。如果 $x$ 不正確，我們可以透過下面的方式修正：

1. 假設目前的邊長為 $x_n$ ，面積為 $x_n^2$ 。
2. 如果 $x_n^2 < S$ ，缺少的面積為 $S - x_n^2$ 。
3. 我們嘗試在邊長上增加 $\Delta x$ ，使得 $(x_n + \Delta x)^2 = S$ 。
4. 展開得 $x_n^2 + 2x_n\Delta x + (\Delta x)^2 = S$ 。
5. 忽略極小的 $(\Delta x)^2$ 後，得 $\Delta x \approx \frac{S - x_n^2}{2x_n}$ 。
6. 所以新的邊長 $x_{n+1} = x_n + \Delta x = x_n + \frac{S - x_n^2}{2x_n} = \frac{1}{2}\left(x_n + \frac{S}{x_n}\right)$ 。
