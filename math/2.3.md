# 2.3 推導： √2 為無理數的反證法（無窮遞降法）

## 時代背景：證明的邏輯結構

在西元前 5世紀，希帕索斯對 √2 的證明之所以震驚當代，是因為他使用了一種極具穿透力的邏輯結構——**無窮遞降法**。這不僅僅是一個普通的反證，更是一種能夠展示數體系深層邏輯的方法。

在數學史上，無窮遞降法後來被皮耶-杜馬維爾（Pierre de Fermat）於 17 世紀正式命名並廣為流傳，用於證明費馬大定理的特例。但其起源可以追溯到希帕索斯對 √2 的處理。

### 什麼是無窮遞降法？

**基本概念**  
無窮遞降法的邏輯結構如下：
1. 假設存在一個滿足某條件的「最小」正整數解。
2. 透過邏輯推導，證明從這個「最小」解可以構造出一個更小的、也滿足同一條件的解。
3. 這導致矛盾：我們同時擁有「存在最小解」和「能無限產生更小解」兩個命題。
4. 因此，原始假設必然錯誤。

**應用在 √2 的情況下**
這正是希帕索斯（或其學派）所使用的手法。我們可以重構上一章的反證過程，使其更貼近「無窮遞降」的思維模式。

## 詳細推導：使用無窮遞降法證明 √2 無理

### 第一步：假設存在一個「最小」分數表示

假設 √2 可以表示為一個最簡分數 p/q，其中：
- p 和 q 為正整數
- p 和 q 互質（即他們沒有共同的因數，只能同時被 1 整除）
- (p/q)² = 2

我們稱這個分數 p/q 為 √2 的「最簡形式」。之所以稱為「最簡」，是因為在正整數中，無論如何選擇，總存在一個具有最小分母 q（或者最小 p+q）的表示形式。

### 第二步：從「最簡形式」推導出「更小形式」

從已知條件：
$$\frac{p}{q} = \sqrt{2}$$
兩邊平方：
$$\frac{p^2}{q^2} = 2$$
$$\Rightarrow p^2 = 2q^2$$

**關鍵觀察 1**：因為右邊 $2q^2$ 能被 2 整除，左邊 $p^2$ 也必然能被 2 整除。根據數論基本定理（見 2.2 章），若 $p^2$ 能被 2 整除，則 $p$ 本身也是偶數。

所以我們可以寫成：
$$p = 2k \quad (k 為整數)$$

### 第三步：代入並消去公因數

將 $p = 2k$ 代入原方程 $p^2 = 2q^2$：
$$(2k)^2 = 2q^2$$
$$4k^2 = 2q^2$$
兩邊同時除以 2：
$$2k^2 = q^2$$

**關鍵觀察 2**：這個等式告訴我們，$q^2$ 能被 2 整除，因此 $q$ 本身也是偶數。

### 第四步：構造一個更小的分數

既然 $p$ 和 $q$ 都是偶數，我們可以同時將它們除以 2：
$$p' = \frac{p}{2}, \quad q' = \frac{q}{2}$$

這時我們得到一個新的分數：
$$\frac{p'}{q'} = \frac{p/2}{q/2} = \frac{p}{q} = \sqrt{2}$$

**這裡的關鍵在於**：
- $p'$ 和 $q'$ 仍然是整數（因為 $p$ 和 $q$ 是偶數）。
- $\frac{p'}{q'}$ 仍然等於 $\sqrt{2}$。
- 但 $p' < p$ 且 $q' < q$（因為我們將分子和分母各除以 2）。

### 第五步：矛盾與結論

我們剛才假設 p/q 是 √2 的「最簡形式」，意指不存在任何具有一個更小分子和分母的同值分數。然而，我們剛才證明：從 p/q 可以構造出一個更小的 p'/q'，其值完全相同，仍然等於 √2。

這構成了**無窮遞降**的核心邏輯：
- 如果存在一個最小解，那麼我們能從中構造出一個更小的解。
- 但如果有了更小的解，我們又能從中構造出更小的解。
- 這將導致一個無限的過程：存在一個「無窮递减（descending）鏈」的正整數分母 q, q', q'', ...。

**但這是不可能的**！因為正整數是良序集：任何非空集合都有一個最小元素。我們不可能有一個無限的、严格递减的正整數序列。

因此，我們的原始假設——“√2 可以表示為一個最簡分數”必然是錯誤的。

### 總結：無窮遞降法的力量

這個證明方式的優美之處在於：
1. **不需要引入額外的數論道具**：只使用基本的偶數性質和代數運算。
2. **突顯了正整數的well-ordering性質**（任何非空集合有最小元），這是數論的基石。
3. **成為後世數學家的標準模板**：從費馬對費馬大定理的部分證明，到現代代數數論中的各種定理，無窮遞降法無處不在。
