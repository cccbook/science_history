# 6.4 費拉利（Ferrari）的四次方程式求解：降次技巧的極致

## 時代背景：從三次到四次的跨越

在西元 16 世紀，代數已漸漸成為探索的前沿。三次方程式的解法（卡爾達諾公式）已問世，但數學家們並未止步。四次方程式 $x^4 + px^3 + qx^2 + rx + s = 0$ 的求解，被視為更大的挑戰。因為三次方程最多有三個根，而四次方程最多有四個根，理論上難度似乎更高。

**關鍵突破**  
究竟四次方程是否也能用根號表示解？這個問題在當時引發了激烈的爭論。最終，**洛多維科·費拉利**（Lodovico Ferrari，1522–1565），卡爾達諾的學生，給出了肯定的答案，並開發了一種**「降次技巧」**，將四次方程轉化為一個可以解的三次方程問題。

## 費拉利的巧妙變換

費拉利的方法並非直接套用公式，而是透過一個**引入輔助變數**的過程，將四次方程轉化為一個**「完全平方」**的形式。

### 1. 問題的重新包裝

考慮一般形式的四次方程：
$$x^4 + px^3 + qx^2 + rx + s = 0$$

為了簡化，我們先透過變換 $x = y - p/4$ ，消去三次項，得到**降冪四次方程**：
$$y^4 + ay^2 + by + c = 0$$
(此處 $a, b, c$ 為 $p, q, r, s$ 的特定函數)。

### 2. 費拉利的核心技巧：引入「未知項」

費拉利的關鍵在於：**在方程兩邊同時加入一個項 $2zy + z^2$ （其中 $z$ 為待定參數），使得左邊成為完全平方。**

原方程 rearranging:
$$y^4 + ay^2 + by + c = 0\]
$$\Rightarrow y^4 + ay^2 = -by - c$$

現在，在兩邊同時加入 $2zy + z^2$ ：
$$y^4 + ay^2 + 2zy + z^2 = -by - c + 2zy + z^2$$

**左邊變形**：
$$(y^2 + z)^2 + (a - 2z)y^2 + by + (c - z^2) = 0$$
等等，我們需要更精準的變形。正確的做法是：

$$y^4 + 2zy^2 + z^2 = (y^2 + z)^2$$

所以，我們在原方程兩邊加入 $2zy + z^2$ ，得到：
$$y^4 + ay^2 + 2zy + z^2 + by + c = 2zy + z^2$$
$$\Rightarrow (y^2 + z)^2 = (2z - a)y^2 - by + (z^2 - c)$$

### 3. 選擇 $z$ 使得右邊成為完全平方

為了利用開方，我們希望右邊的式子 $(2z - a)y^2 - by + (z^2 - c)$ 也是一個**完全平方**。一個二次多項式 $Ay^2 + By + C$ 成為完全平方的條件是其判別式為 0：
$$B^2 - 4AC = 0$$

此處 $A = (2z - a)$ ， $B = -b$ ， $C = (z^2 - c)$ 。代入條件：
$$(-b)^2 - 4(2z - a)(z^2 - c) = 0$$
$$\Rightarrow b^2 - 4(2z - a)(z^2 - c) = 0$$

這是一個關於 $z$ 的**三次方程**：
$$8z^3 - 4az^2 - 8cz + (4ac - b^2) = 0$$

### 4. 關鍵一步：解出三次方程 $z$

現在問題降級了！我們只需要解這個三次方程求出 $z$ 的值。因為我們已經知道如何解三次方程（卡爾達諾公式），所以這一步是可行的。

一旦我們找到一個 $z$ 滿足上述條件，右邊就確變成了一個完全平方： $(py + q)^2$ （其中 $p, q$ 由 $b, c, z$ 決定）。

### 5. 最後的開方步驟

現在方程變為：
$$(y^2 + z)^2 = (py + q)^2$$

這可以轉化為兩個二次方程：
$$\begin{cases} y^2 + z = py + q \\ y^2 + z = -py - q \end{cases}$$

每一個二次方程都可以用解平方公式解開，從而得到四個 $y$ 的值（即原方程的四個根）。

## 數學意義與歷史影響

### 1. 四次方程的根號可解性  
費拉利的方法證明了：**任何四次方程式都可以用根號（包含平方根與立方根）表示其四個根**。這標誌著代數達到了一個新的高峰，也證明了萬次方程（ $n \le 4$ ）在理論上都是可解的。

### 2. 代數方法的成熟  
費拉利的方法不僅是一個技巧，更是一種**系統化的變換思維**。他展示了如何透過引入輔助變數，降低問題的難度。這種思維後來影響了五次方程的研究，也為現代**格羅提安定理**（Abel-Ruffini theorem，證明五次及以上一般方程無根號解）奠定了基礎。

### 3. 費拉利與卡爾達諾的關係  
費拉利原本是卡爾達諾的學生，他在學習三次方程後，受託去解四次方程。他最終在卡爾達諾的資助下出版了自己的方法，這段關係既有師生之情，也有學術上的合作與競爭。
