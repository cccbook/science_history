# 10.2 巴塞爾問題（Basel Problem）：所有平方倒數之和等於 $\frac{\pi^2}{6}$ ？

## 時代背景：無窮級數的困境

在西元世紀初，數學家們早已注意到**自然數倒數平方和**這個級數：
$$S = \frac{1}{1^2} + \frac{1}{2^2} + \frac{1}{3^2} + \frac{1}{4^2} + \cdots$$

雖然級數的項目越來越小，但在數學界，人們一直無法確定這個無窮級數的**精確值**。大家普遍猜測它可能收斂於某個合理的數值，但無人能夠給出準確的答案。

**為什麼這個問題如此重要？**  
這個級數的收斂速度極慢，但它與** $\pi$ ** (圓周率) 有著莫名其妙的聯繫。事實上，這個問題後來被稱為**巴塞爾問題**，以其解決者**歐拉**的家鄉城市命名。

## 歐拉的突破：巧妙的級數比較

歐拉在1734年透過一個極其巧妙的數學技巧，成功解開了這個謎題。他的核心思路在於：**將級數問題轉化為多項式的根號問題**。

### 1. 利用多項式的根號性質

歐拉回憶起這個事實：對於任意多項式，其根號的乘積等於常數項係數的相反數（此處省略詳細證明）。

他考慮函數 $\frac{\sin x}{x}$ 的級數展開：
$$\frac{\sin x}{x} = 1 - \frac{x^2}{3!} + \frac{x^4}{5!} - \frac{x^6}{7!} + \cdots$$

同時，他利用**基本定理**，知道 $\sin x$ 的零點（根）位於 $x = \pm\pi, \pm 2\pi, \pm 3\pi, \cdots$ 。因此，他可以將 $\frac{\sin x}{x}$ 表示為一個「根號展開式」：

$$\frac{\sin x}{x} = \left(1 - \frac{x^2}{\pi^2}\right)\left(1 - \frac{x^2}{4\pi^2}\right)\left(1 - \frac{x^2}{9\pi^2}\right)\cdots$$

### 2. 兩種展開方式的比較

比較兩邊的 $x^2$ 係數：

- 從 $\frac{\sin x}{x}$ 的級數展開： $x^2$ 的係數為 $-\frac{1}{3!} = -\frac{1}{6}$ 。
- 從產品展開：展開後的 $x^2$ 係數為 $-\left(\frac{1}{\pi^2} + \frac{1}{4\pi^2} + \frac{1}{9\pi^2} + \cdots\right) = -\frac{1}{\pi^2}\left(1 + \frac{1}{4} + \frac{1}{9} + \cdots\right)$ 。

**關鍵方程**  
令這兩個係數相等：
$$-\frac{1}{6} = -\frac{1}{\pi^2}\left(1 + \frac{1}{4} + \frac{1}{9} + \cdots\right)$$

整理後得到：
$$1 + \frac{1}{4} + \frac{1}{9} + \cdots = \frac{\pi^2}{6}$$

**結論**  
這正是巴塞爾問題的解！歐拉透過巧妙的級數比較，證明了：
$$\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}$$

**意義**  
這不僅是一個級數的收斂值，更是** $\pi$ 与整數論**之間第一個深刻的聯繫證明。這個結果 later 成為了數論的基石，也啟發了黎曼 zeta 函數的研究。
