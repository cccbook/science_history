# 15.4 圖靈（Turing）與停機問題：不可計算性的邏輯邊界

**背景場景：1936 年，阿倫尼茅斯。**

艾倫·圖�ינג（Alan Turing，1912–1954）是一位英國數學家與密碼學家，他在 1936 年出版了一篇里程碑式的論文「可計算數與有效可判定性」，提出了 **圖靈機** 的概念。他的工目的是解決「決定問題」，即：給定一個邏輯公式，是否存在一個算法可以判斷其是否可證？

**圖靈機的概念**

圖靈機是一種抽象的計算模型，包括：
- 一條無限長的磁帶，作為輸入與輸出介面。
- 一個讀/寫頭，可以在磁帶上移動、寫入與讀取符號。
- 一組狀態與規則，決定根據當前狀態和讀取到的符號，下一步該怎麼做。

**停機問題**

圖靈提出了 **停機問題** 的概念：給定一個圖靈機 $M$ 与輸入 $w$，$M$ 在輸入 $w$ 下會 halt（停止運行）還是會 run forever（無限運行）？

**不可計算性的證明**

圖靈透過 **歸謬法** 證明了停機問題是 **不可計算** 的：

1. 假設存在一個圖靈機 $H$，能夠判斷任意輸入是否會 halt。
2. 建立一個新的圖靈機 $D$，其行為為：當 $H$ 說明機器 $M$ 在輸入 $w$ 下 halt 時，$D$ 進入無限循環；當 $H$ 說明機器 $M$ 運行無限時，$D$ 停止運行。
3. 問題：$D$ 對於自身的輸入會怎麼樣？
   - 如果 $H$ 說 $D$ 在自身輸入下 halt，那麼 $D$ 會 run forever。
   - 如果 $H$ 說 $D$ 在自身輸入下 run forever，那麼 $D$ 會 halt。

這導致矛盾，證明不存在任何圖靈機能夠判斷任意機器是否會 halt。

**本章小結**

1. 圖靁機是計算理論的基石，定義了「可計算」的概念。
2. 停機問題的不可計算性，展示了邏輯邊界的存在。
3. 圖靁的工程為現代計算機科學與程式語言理論奠定了基礎。
