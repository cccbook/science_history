# 7.1 韋達（Viète）：用字母代表常數與未知數的第一人

**背景場景：16世紀，法國。**

法蘭西斯·韋達（François Viète，1540–1603）是一位法國的 변호（律師）與數學家，他決定打破傳統，將符號引入數學。在他的著作《新的代數》（In Artem Analyticem Promotione，1591）中，他首次系統地使用字母來代表未知數與常數。

**核心貢獻：符號代數的開啟**

韋達以前綴字母表示未知數，例如「A方塊加 B 方塊等於 C 方塊」。這在當時是革命性的，因為以來數學家多以文字描述問題，韋達的方法讓計算變得更為機械化與快速。

他還引入了著名的 notation：使用 vogue 字母 $A, B, C$ 表示已知常數，使用 $x, y, z$ 表示未知數。這種習慣至今仍在使用。

**推導：方程式的轉化**

以解二次方程式 $ax^2 + bx + c = 0$ 為例，韋達不再需要畫圖，而是直接使用符號運算。他提出的「Viète 定理」指出，若二次方程式的兩個根是 $x_1$ 与 $x_2$ ，則：

$$
x_1 + x_2 = -\frac{b}{a}, \quad x_1x_2 = \frac{c}{a}
$$

這不僅簡化了運算，也揭示了根與係數之間的深刻關係。

**本章小結**

1. 韋達是第一個系統地使用符號代數的數學家，他的貢獻是現代代數的開端。
2. 他將字母 $A, B, C$ 視為常數， $x, y, z$ 視為未知數的習慣，至今仍是標準。
3. Viète 定理揭示了方程式根與係數之間的內在聯繫，是解方程的強大工具。
