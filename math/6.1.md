# 6.1 塔塔利亞與費羅：暗夜裡的代數決鬥比賽

**背景場景：16世紀，意大利波隆納。**

16世紀的意大利是代數的熱土，多位數學家在密室中進行著暗流競爭。塔塔利亞（Niccolò Tartaglia）是一位自學成才的數學家，他發現了解三次方程式的秘密方法。而費羅（Gerolamo Cardano）是一位博學的醫生與數學家，他雖然閉門造車，但對塔塔利亞的成就聞風喪膽。

**核心衝突：秘密的交換**

塔塔利亞將他的三次方程式解法視為家傳寶藏，並向費羅承諾，只要費羅不將此一秘密公開，他就將傳授給費羅。然而，命運的轉折發生在費羅遇到一位名為洛佩茲的數學家，後者聲稱他也有解三次方程式的方法。費羅開始懷疑塔塔利亞是否真的擁有獨家的解法。

相傳，費羅潛入塔塔利亞的講席，偷偷記下了他的運算過程。這場「暗夜裡的代數決鬥」自此展開，兩位數學家互相試探，試圖在不打破承諾的前提下，獲取對方的解法。

**推導：卡爾達諾公式——三次方程式 $x^3 + px + q = 0$ 的根式解法**

費羅最終在卡爾達諾（Girolamo Cardano）的著作《大術》中看到了塔塔利亞的解法。卡爾達諾雖然答應過塔塔利亞不公開，但因為塔塔利亞早在前幾年已死，卡爾達諾覺得可以公開這個成果。他還邀請費羅一起合作，兩人共同完善了這個公式。

解三次方程式的核心在於「 depressed cubic」（抑形式）的處理。對於方程 $x^3 + px + q = 0$，我們設 $x = u + v$，並利用恆等式 $(u+v)^3 = u^3 + v^3 + 3uv(u+v)$，整理後得到：

$$
u^3 + v^3 + (3uv + p)(u+v) + q = 0
$$

我們可以通過以下條件消去中項：

$$
3uv + p = 0 \quad \Rightarrow \quad uv = -\frac{p}{3}
$$

這時方程簡化為：

$$
u^3 + v^3 = -q
$$

已知 $uv = -\frac{p}{3}$，所以 $u^3v^3 = -\frac{p^3}{27}$。因此，$u^3$ 与 $v^3$ 是方程 $t^2 + qt - \frac{p^3}{27} = 0$ 的根。利用二次公式得：

$$
u^3 = -\frac{q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}, \quad v^3 = -\frac{q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}
$$

 finally，三次方程式的根為：

$$
x = \sqrt[3]{-\frac{q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}} + \sqrt[3]{-\frac{q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}}
$$

這就是我們今天所說的**卡爾達諾公式**。

**本章小結**

1. 塔塔利亞與費羅（ later 卡爾達諾）之間的代數決鬥，是現代代數得以成型的關鍵過程。
2. 卡爾達諾公式提供了解三次方程式的根式公式，這是解方程史上的里程碑。
3. 這場爭議也揭示了數學知識在優先權與歸屬上的複雜性。
