# 6.1 塔塔利亞與費羅：暗夜裡的代數決鬥比賽

## 時代背景：波隆納的角鬥場

西元 15世紀末至16世紀初，意大利的城市國家正處於文藝復興的黃金時代，同時也成為數學家爭奇鬥麗的角逐場。其中，**波隆納**（Ferrara）與**費羅納**（Ferrara）之間的競爭，特別是圍繞著三次與四次方程式的解法，成爲了當時的焦點。

**比賽背景**  
有一場實質上的「決鬥」在進行：誰能先解出三次方程式 $x^3 + px + q = 0$（三次方程）與四次方程式 $x^4 + px^3 + qx^2 + rx + s = 0$（四次方程）的根號解。這不僅是一種技藝的比拼，更關係到當時的榮譽、薪俸以及未來的學術地位。

**主要參賽者**  
- **塔塔利亞**（Tartaglia，1499–1557）：一位來自威尼斯的數學家，原本是一位普通的師範老師，但在方程式求解上展現出驚人的天賦。
- **費羅**（Ferro，1500–1526）：一位來自博洛尼亞的數學家，雖然生涯短暫，但他先驅了三次方程式的突破。

## 塔塔利亞的勝利

### 1. 三次方程式的突破

塔塔利亞最大的成就在於他獨立發現了**三次方程式的解公式**（後來被卡爾達諾收錄）。他的方法基於一種**「變數消去」**的技巧。

**題目形式**  
考慮一般形式的三次方程：
$$x^3 + px + q = 0$$
(注意：此處已消去二次項 $x^2$，這是透過變換 $x = y - b/3a$ 達成的）。

**塔塔利亞的解法**  
1. 他設法將方程轉化為一個聯立系統：
   $$\begin{cases} u + v = -q \\ uv = -\left(\frac{p}{3}\right)^3 \end{cases}$$
2. 然後令 $x = \sqrt[3]{u} + \sqrt[3]{v}$。
3. 透過此變換，原本的三次方程就被轉化為一個更易處理的形式。

**關鍵公式**  
最終得到的解為：
$$x = \sqrt[3]{-\frac{q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}} + \sqrt[3]{-\frac{q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}}$$

**驚人之處**：
即使 $p$ 與 $q$ 為整數，解的表達式可能涉及**$\sqrt{-1}$**（即 $i$），這在當時極具預見意義，因為它預示了**虛數**在代數運算中的必要性。

### 2. 費羅的貢獻與塔塔利亞的機密

根據史記載，費羅（Ferro）在生前也解出了三次方程，但他將自己的方法視為「職業機密」，死前將秘密傳給了他的助手**卡爾達諾**（Cardano）。塔塔利亞後來在旅途中偶然得知了卡爾達諾所掌握的方法，並意識到自己與費羅是同時期獨立發現的同一件事。這場「秘密傳承」的爭議，成為了後世學術界的熱門話題。
