# 10.1 萊昂哈德·歐拉（Leonhard Euler）：失明也無法阻擋的計算狂魔

## 時代背景：18世紀的數學巨匠

在西元 18 世紀，數學正經歷爆發式的成長，而**萊昂哈德·歐拉**（Leonhard Euler，1707–1783）是這個時代最具生產力的數學家之一。他一生貢獻極豐碩，出版的著作超過 80 卷，他的符號和公式至今仍是數學的基石。令人驚嘆的是，即使他在1766年失明，他們的工作速度並未減慢，甚至在失明後的最後幾年創作了許多最具遠見的作品。

**歐拉的生涯**  
- 年輕時在柏林皇家科學院任職，後轉往聖彼得堡聖皇家科學院。  
- 他不僅是數學家，也是天文家、物理家，甚至音樂理論的研究者。  
- 他將數學符號標準化的貢獻巨大，如使用 $\pi$ 表示圓周率， $e$ 表示自然對數的底數， $i$ 表示虛數單位，以及 $\sum$ 表示求和符號。

**失明後的奇蹟**  
歐拉在失明後，憑藉著驚人的記憶力和心算能力，繼續產出驚人的數學成果。他說：「失明對我而言是一種福氣，因為它迫使我專注於數學的本質，而非視覺的干擾。」他的失明並未阻礙他成為歷史上最偉大的數學家之一。

## 欧拉的數學貢獻

### 1. 二項定理的廣義化（重見光芒）

雖然二項定理最早由二項係數發現，但歐拉將其推廣到任意實數指數的情況，這與牛頓的研究互相呼應。他的公式為：
$$(1+x)^n = 1 + nx + \frac{n(n-1)}{2!}x^2 + \frac{n(n-1)(n-2)}{3!}x^3 + \cdots$$
這不僅適用於整數指數，也適用於分數、負數甚至是任意實數 $n$ 。這為後來泰勒級數的發展奠定了基礎。

### 2. 巴塞爾問題的解

**問題**  
求出自然數的倒數平方和：
$$\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{1}{1^2} + \frac{1}{2^2} + \frac{1}{3^2} + \cdots$$

**歐拉的解**  
歐拉巧妙地利用級數展開與三角函數的性質，證明了：
$$\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}$$

**意義**  
這不僅是一個計算結果，更是** $\pi$ 與整數論之間深刻聯繫**的首見之跡。這個結果 later 成了數論的基石，也啟發了黎曼 zeta 函數的研究。

### 3. 點、線與面的轉換——歐拉公式

**歐拉公式**是數學史上最美的公式之一：
$$e^{i\theta} = \cos\theta + i\sin\theta$$

當 $\theta = \pi$ 時，得到著名的**歐拉恆等式**：
$$e^{i\pi} + 1 = 0$$

這個公式將五個最基本的數學常數連在了一起： $0, 1, e, \pi, i$ 。費馬 himself 說過：「這是人類歷史上最美的數學定理。」

### 4. 柯尼斯堡七橋問題與圖論

**問題**  
柯尼斯堡城有七座橋，市民試圖找出一條路徑， traverse each bridge exactly once 返回原點。

**歐拉的突破**  
歐拉不嘗試列出所有可能的路徑，而是轉化為**圖論**問題：他將陸地抽象為「節點」，橋梁抽象為「邊」。他證明：若要存在一條「圖上歐拉回路」（遍歷所有邊一次且返回起點），每個節點的度必須是偶數。柯尼斯堡的七座橋情況中，所有節點的度皆為奇數，因此**不存在這條路徑**。

**意義**  
這是人類史上第一個**圖論**問題的解，開啟了整個網絡理論、運籌學的大門。
