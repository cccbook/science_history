# C.1 古典幾何與代數大師：歐幾里得、阿基米德、笛卡兒、卡爾達諾

**歐幾里得（Euclid，約前3世紀）**

古希臘的數學家，被譽為「幾何學之父」。他最偉大的貢獻是《幾何原本》，系統化地整理了已知的幾何知識，並以五條公理與五條公設作為基石。他的邏輯推導方式至今仍是教學的標準。他那句名言「非我不能透過幾何證明的事，則非科學所能證明」，體現了他對邏輯的執着。

**阿基米得（Archimedes，約前287–前212）**

希臘的數學家與工程師，以其在幾何、力學與天文上的突破而聞名。他發展了「窮竭法」，是積分學的雛形，並利用正96邊形將圓周率 $\pi$ 限制在 $3\frac{10}{71} < \pi < 3\frac{1}{7}$ 之間。相傳他在解決皇冠密度問題時，於沐浴時發現了「浮力原理」（阿基米得原理），躍出浴缑大喊「 euréka！」，奔跑進街頭。

**笛卡兒（René Descartes，1596–1650）**

法國哲學家與數學家，被認為是解析幾何的開創者。他有名的「床上遐想」，在牆角看見蒼蠅的腿，靈光一現，意識到可以用兩條垂直的線（坐標軸）來描述平面上點的位置。他的著作《方法論》中提出「我思故我在」，但他在數學上的貢獻——將幾何問題轉化為代數方程——對人類文明的影響更為深遠。

**卡爾達諾（Gerolamo Cardano，1501–1576）**

義大利數學家，醫生與賭博愛好者。他收集並整理了三次與四次方程式的解法，出版了《大術》。相傳他從塔塔利亞手中竊取了三次方程式的解法，這成為了他與塔塔利亞之間激烈的爭議焦點。雖然他在邏輯上可能「剽竊」了他人的成果，但他將代數系統atic地出版，讓後世得以繼承與發展。

**本章小結**

1. 歐幾里得確立了幾何的邏輯框架，阿基米得則在實務與理論之間架起橋樑。
2. 笛卡兒的坐標系統讓幾何與代數得以結合，是現代數學的基石。
3. 卡爾達諾雖因「剽竊」而備受爭議，但他確實將代數提昇為一門系統化的學問。

**想一想**

1. 如果歐幾里得選擇不公開他的五條公理，後世的幾何發展會受阻嗎？
2. 笛卡兒的「床上遐想」是一個典型的科學直覺時刻，你是否也有過類似的靈光一現經驗？
3. 卡爾達諾為什麼會選擇將三次方程式的解法視為「機密」？這與當時的數學家聲譽保護有關嗎？
