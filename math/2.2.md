# 2.2 花拉子米（Al-Khwarizmi）與《代數學》：「Algorithm」詞源的由來

**背景場景：820 年，巴格達的創新之家（House of Wisdom）。**

阿拔斯王朝哈倫拉シ德王朝統治下，巴格達成為世界知識的匯流點。來自印度、波斯、希臘的書籍被翻譯成阿拉伯文，學者們在「創新之家」聚會，討論天文、數學與醫學。

**核心貢獻：奠基現代代數**

在 820 年，花拉子米（Muhammad ibn Musa al-Khwarizmi）撰寫了《代數學》（al-Jabr wa-l-Muqabala）。這本書不僅是教科書，更是一場革命。書名中的 "al-Jabr"，意指「復原」、「補足」，指的是從方程式兩邊消去負項的運算過程，這也是我們今天所說的 "algebra" 的由來。

書中系統地介紹了解二次方程式的方法，並使用符號表達未知數。例如，他會將問題翻譯為：

> "一根 unknown 的線，其平方加上 10 根該線等於 39。"

在現代符號中，這是 $x^2 + 10x = 39$ 。

花拉子米不使用今天的符號 $x$ ，而是用 "shay"（事物）來表示未知數，並用圖形說明運算過程。他的方法屬於幾何代數，即將代數問題轉化為圖形面積的運算。

書中最著名的貢獻之一，是解決方程 $x^2 + 10x = 39$ 的過程：

1. 完成平方：在 10x 前加上 $(10/2)^2 = 25$ 。
2. 方程變為 $x^2 + 10x + 25 = 39 + 25$ 。
3. 化簡得 $(x + 5)^2 = 64$ 。
4. 開方得 $x + 5 = 8$ （負根在當時被視為無意義）。
5. 所以 $x = 3$ 。

**本章小結**

1. 花拉子米的《代數學》是現代代數的開端，奠定了解方程式的系統方法。
2. "algebra" 這個詞源自書名中的 "al-Jabr"，意指運算過程中的「復原」。
3. 他的幾何代數方法，將抽象的符號問題轉化為實在的圖形運算，極大降低了門檻。
