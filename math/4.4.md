# 4.4 四元數（Quaternions）與哈密頓（Hamilton）石橋上的刻痕

**背景場景：1843 年都柏林的皇家天文台。**

威廉·哈密頓 (William Rowan Hamilton) 是都柏林皇家天文台的局長，他致力於尋找一種「四元數」系統，能夠推廣複數到三維空間。

**核心靈感：複數的推廣**

複數 $z = a + bi$ 可以在二維平面上表示，其中 $i^2 = -1$。哈密頓試圖找到類似的數，能夠在三維空間中運算，特別是乘法運算。

他在一天的散步中，靈光一現。他需要兩個額外的單位，設為 $j$ 与 $k$，他們的乘法規則必須滿足：

$$
i^2 = j^2 = k^2 = ijk = -1
$$

**四元數的定義**

一個四元數 $q$ 可以表示為：

$$
q = a + bi + cj + dk
$$

其中 $a, b, c, d$ 為實數，$i, j, k$ 為基本單位。四元數的乘法**不交換律**——即 $ij = k$ 卻不等於 $ji = -k$。這使得四元數能夠精確描述三維空間中的旋轉。

**石橋上的刻痕**

相傳，哈密頓在都柏林的布routon石橋上，用鉛筆記下了這一突破性公式：

$$
i^2 = j^2 = k^2 = ijk = -1
$$

這座石橋至今仍屹立，上面刻著這段數學歷史。每經過一位數學家，都會停驻腳步，為此一刻默哀。

**本章小結**

1. 四元數是複數在四維空間的推廣，具有不交換律的乘法。
2. 它提供了一種極為高效的方式來描述三維旋轉，廣泛應用於計算機圖形與航空航天。
3. 哈密頓在石橋上刻下的公式，成為了數學美學的不朽見證。
