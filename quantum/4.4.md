# 4.4 推導：從離心力平衡到能階公式

## 第 1 步：機械平衡（純粹古典力學）

設電子質量 $m_e$、電荷 $-e$，繞著電荷 $+e$ 的原子核作半徑 $r_n$ 的圓周運動，速率 $v_n$。維持圓周所需的向心力必須等於庫侖吸引力：

$$\frac{m_e v_n^2}{r_n} = \frac{e^2}{4\pi\varepsilon_0 r_n^2}$$

（嚴格說應該用**約化質量** $\mu = \frac{m_em_p}{m_e+m_p}$ 取代 $m_e$，因為核也在動；波動力學給出的正是這個修正。因 $m_p \approx 1836\,m_e$，$\mu \approx m_e$，玻爾模型直接忽略了它。）

由上式解出速率：

$$v_n^2 = \frac{e^2}{4\pi\varepsilon_0 m_e r_n}$$

到目前為止，這一步**完全沒有量子**。

## 第 2 步：總能量（Virial 定理的殘留）

電子的總能量 = 動能 + 靜電位能。代入第 1 步，把 $m_ev^2$ 換成 $\frac{e^2}{4\pi\varepsilon_0 r_n}$：

$$E = \frac{1}{2}m_ev_n^2 - \frac{e^2}{4\pi\varepsilon_0 r_n} = \frac{1}{2}\cdot\frac{e^2}{4\pi\varepsilon_0 r_n} - \frac{e^2}{4\pi\varepsilon_0 r_n} = -\frac{1}{2}\frac{e^2}{4\pi\varepsilon_0 r_n}$$

那個 **$\tfrac{1}{2}$** 是整套推導最漂亮的地方之一：軌道的**平均動能只有平均位能的一半**。這是均分定理（virial theorem）的殘餘，日後波動力學在期望值層次完全證實了它。負號代表這是**束縛能**：要把它變成 0 得往外推，所以 $E<0$。

## 第 3 步：加上量子化條件

玻爾的第二假說要求角動量量子化：

$$L = m_ev_nr_n = n\hbar = n\frac{h}{2\pi},\qquad n = 1,2,3,\ldots$$

由此 $v_n = \dfrac{n\hbar}{m_er_n}$。平方後代回第 1 步：

$$\frac{m_e}{r_n}\cdot\frac{n^2\hbar^2}{m_e^2 r_n^2} = \frac{e^2}{4\pi\varepsilon_0 r_n^2}$$

左右同乘 $r_n^2$，消掉 $r_n$：

$$\frac{n^2\hbar^2}{m_e r_n} = \frac{e^2}{4\pi\varepsilon_0}\qquad\Longrightarrow\qquad \boxed{\;r_n = \frac{4\pi\varepsilon_0 n^2\hbar^2}{m_ee^2} = n^2 a_0\;}$$

其中 **玻爾半徑**

$$a_0 = \frac{4\pi\varepsilon_0\hbar^2}{m_ee^2} = \frac{\varepsilon_0 h^2}{\pi m_ee^2} = 5.2918\times10^{-11}\,\mathrm{m} = 0.529\ \text{Å}$$

$a_0$ 值得單獨說一句：它**完全由基本常數組成**（$h$、$c$、$m_e$、$e$、$\varepsilon_0$），沒有任何自由參數。這是 $h$ 的第一個乾淨後果——把第三章那個「湊出來的常數」放進角動量，原子的大小立刻被決定了。$c$ 在 SI 裡隱含在 $\varepsilon_0$ 之中。

## 第 4 步：能階公式

把 $r_n = n^2a_0$ 代回第 2 步的能量式：

$$E_n = -\frac{e^2}{8\pi\varepsilon_0 a_0 n^2} = -\frac{m_e e^4}{8\varepsilon_0^2 h^2}\cdot\frac{1}{n^2}$$

**確認它的數值。** 定義**里德伯常數（Rydberg constant）**

$$R_\infty = \frac{m_e e^4}{8\varepsilon_0^2 h^3 c} = 1.0974\times10^7\ \mathrm{m}^{-1}$$

於是能階可以寫成極乾淨的形式：

$$\boxed{\;E_n = -\frac{hcR_\infty}{n^2} = -\frac{13.6\ \mathrm{eV}}{n^2},\qquad E_1 = -2.18\times10^{-18}\,\mathrm{J}\;}$$

而 $E_1 = -13.6$ eV **恰好就是氫原子的游離能**——把電子從基態拉到無窮遠所需要的能量。這是一個可以完全獨立測量的量，玻爾的預測與實測相容到極高的一致度（若把約化質量與 $m_p/m_e$ 的修正算進去，可以對到 $10^{-7}$ 的量級）。

| $n$ | $E_n$（eV） | 對應的譜系 | 波長範圍 |
|---|---|---|---|
| 1 | $-13.6$ | Lyman（紫外） | $91.2\text{–}121.6$ nm |
| 2 | $-3.40$ | Balmer（可見） | $364.6\text{–}656.3$ nm |
| 3 | $-1.51$ | Paschen（紅外） | $820\text{–}1875$ nm |
| 4 | $-0.850$ | Brackett（深紅外） | $1.46\text{–}4.05$ μm |
| 5 | $-0.544$ | Pfund（遠紅外） | $2.28\text{–}7.46$ μm |
| 6 | $-0.378$ | Humphreys | 更長 |
| $n\to\infty$ | $\to 0^-$ | 游離連續譜 | 連續 |

## 能階圖

```
 E = 0 ───────────────────────────────── 游離極限（束縛能 → 0）
      │         ↑
 -0.38│────┐    │
 -0.85│────┼────┤  n=4
 -1.51│────┼────┤  n=3
 -3.40│────┤    │
      │  ──┼────┼────────────────  n=2  ← Balmer 系的終點
-13.60│  ──┼────┼────── ... ─────── n=1  ← 基態
```

能階**向上收斂到 0**，而且越來越密（$E_n\propto -1/n^2$）。因為 $n$ 無限多，能階圖本身就是無限密的。

## 收束：這解釋了什麼

能階收斂到 0 有直接的後果。當入射光子能量滿足 $h\nu \ge |E_n|$ 時，電子直接脫離束縛，剩下的能量全變成電子動能——動能可連續取值，所以**吸收光譜在這裡出現一條界線（edge）**，而不是繼續是線狀譜。Balmer 系的 $364.6$ nm、Lyman 系的 $91.2$ nm，就是這些「截止」的波長。

## 回扣第三章的 $h$

這一章裡，$h$ 是**外來**的。玻爾把它塞進角動量量子里，就像把 $\alpha = 1/137$ 塞進週期表一樣：結果全對，但**沒有人能說為什麼是這個值、為什麼是這個位置**。這是一條純粹的經驗事實——「用它就對了」。

這個「對了就行」的狀態維持了十二年。1925 年海森堡證明了 $h$ 與量子力學結構之間的內在關係後，$h$ 才不再是一個外來參數。為什麼對稱性能給它地位，是第 15 章的事。

## 本章小結

- 機械平衡 $m_ev^2/r = \frac{e^2}{4\pi\varepsilon_0r^2}$ 給出 $v_n^2 = \frac{e^2}{4\pi\varepsilon_0m_er_n}$，**這一步沒有量子**。
- 總能量 $E = -\frac{1}{2}\frac{e^2}{4\pi\varepsilon_0r}$，那個 **$\tfrac12$** 是均分定理的殘餘。
- 角動量量子化 $m_ev_nr_n = n\hbar$ 與平衡式聯立，消掉 $v_n$ 得 **$r_n = n^2a_0$**。
- **玻爾半徑 $a_0 = 0.529$ Å** 完全由基本常數組成，沒有自由參數——這是 $h$ 的第一個乾淨後果。
- **$E_n = -hcR_\infty/n^2 = -13.6/n^2$ eV**，$|E_1|$ 正是氫的**游離能**，與實驗高度相容。
- 能階向上收斂到 $0^-$，解釋了**游離連續譜**與吸收光譜的**截止波長**。
- $h$ 在此仍是外來常數：**能用，但還沒有地位**。

## 想一想

1. 推導裡那個 $\tfrac12$ 來自 $\frac{1}{2}m_ev^2 = \frac{1}{2}\frac{e^2}{4\pi\varepsilon_0r}$，本質是「動能 = 位能的一半」。請你想一個不靠數學的直覺解釋，為什麼尺度固定的圓軌道一定是這個比例。
2. $a_0$ 只由基本常數組成，這意味著「原子有多大」這件事是可以**不引用實驗**就算出來的。請你列出這個結論的全部假設（牛頓力學、庫侖定律、$h$ 的值已知、單電子），並挑一個最脆弱的說明它為什麼脆弱。
3. 這一節的所有步驟在今天的物理學裡都被推翻了（該用薛丁諤方程和約化質量），但公式 $E_n = -13.6/n^2$ 依然精確。為什麼一個「整體錯誤、答案正確」的模型能撐十二年？這種情況在科學史上還發生過什麼時候？
