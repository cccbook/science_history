# 7.2 從德布羅意波到薛丁諤方程：薛丁諤的兩個方程

## 德布羅意的啟示

Louis de Broglie（1892-1987）在他的博士論文中提出：每個粒子都對應一個波。他的關鍵洞察在於**相對論**與**量子論**的結合。

對於光子，能量 $E = h\nu$ 与 相對論 $E = pc$ （對光子， $m=0$ ）結合，得到頻率 $\nu = pc/h$ 。對於電子，能量-動量關係是 $E^2 = p^2c^2 + m^2c^4$ 。德布羅意因此提出：**給電子配上一個四維的「導波」，使得運動中的電子實際上是一個相速度與群速度不同的波包**。

## 薛丁諤的兩個方程

薛丁諤在 1926 年的論文中提出了兩個方程，分別對應量子力學的兩個面向。

### 1. 含時薛丁諤方程

$$i\hbar\,\frac{\partial \psi(\mathbf{r}, t)}{\partial t} = -\frac{\hbar^2}{2m}\,\nabla^2\psi(\mathbf{r}, t) + V(\mathbf{r})\,\psi(\mathbf{r}, t)$$

這是**最基本**的方程。它描述波函數隨時間的演化。

**物理意義**：

- 左側 $i\hbar\,\partial\psi/\partial t$ ：表示波函數隨時間演化的速率，對應能量 $E$ 。
- 右側 $-\hbar^2/(2m)\nabla^2\psi + V\psi$ ：空間上的拉普拉斯算子描述波的傳播， $V$ 是外勢位。

**求解方式**：

通常採用**變分法**或**分離變數**法。對於氫原子，我們使用球座標 $(r,\theta,\phi)$ ，將拉普拉斯算子分解為徑向與角向部分。

### 2. 定態薛丁諤方程

若波函數可以分離為空間部分與時間部分：

$$\psi(\mathbf{r}, t) = \phi(\mathbf{r})\,e^{-iEt/\hbar}$$

代入含時方程，消去時間依賴，得到：

$$-\frac{\hbar^2}{2m}\,\nabla^2\phi(\mathbf{r}) + V(\mathbf{r})\phi(\mathbf{r}) = E\phi(\mathbf{r})$$

這是** eigenvalue 方程**：尋找使得算子作用於 $\phi$ 時，結果僅縮放一個因子 $E$ 的函數 $\phi$ 。

**物理意義**：

- $\phi(\mathbf{r})$ 是**軌道**（orbital），表示電子在空間中的分佈機率。
- $E$ 是**能量本徵值**，表示該軌道對應的離散能階。
- 方程的解必須滿足**歸一化條件** $\int |\phi(\mathbf{r})|^2 d^3r = 1$ 。

## 推氫原子的解

薛丁諤很快就將方程應用於**氫原子**（一個核電荷 $+e$ 的質子，一個電荷 $-e$ 的電子）。

### (a) 潢位

勢位 $V(r) = -\frac{e^2}{4\pi\varepsilon_0 r}$ （庫供引力）。

### (b) 分離變數

使用**球座標** $(r,\theta,\phi)$ ，拉普拉斯算子展開為：

$$\nabla^2 = \frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\frac{\partial}{\partial\theta}\right) + \frac{1}{r^2\sin^2\theta}\frac{\partial^2}{\partial\phi^2}$$

### (c) 三個獨立方程

分離變數後，方程分裂為三個部分：

1. **徑向方程**：

   $$-\frac{\hbar^2}{2m}\,\frac{1}{r^2}\frac{d}{dr}\!\left(r^2\frac{dR}{dr}\right) + \left[-\frac{e^2}{4\pi\varepsilon_0 r} + \frac{\hbar^2 l(l+1)}{2mr^2}\right]R = E R$$

   其中 $l$ 是角動量量子數， $\frac{\hbar^2 l(l+1)}{2mr^2}$ 是**角量子項**，來自角動量的離心力。

2. **角向方程（極座標 $\theta$ ）**：勒让德微分方程，解是**球諧函數** $Y_l^m(\theta,\phi)$ 。

3. **角向方程（ azimuth $\phi$ ）**：簡單的三角函數，解是 $e^{im\phi}$ ，其中 $m$ 是磁量子數， $m = -l, -l+1, \dots, l$ 。

### (d) 能階公式

最後，徑向方程的解給出能階：

$$E_n = -\frac{m e^4}{8\varepsilon_0^2 h^2 n^2} = -\frac{13.6\ \text{eV}}{n^2}, \quad n = 1, 2, 3, \dots$$

其中 $n$ 是**主量子數**。這正是玻爾模型預測的公式，但這次是從**薛丁諤方程**完全推導出來的，無需假設定態軌道。

### (e) 球諧函數

角向解出來的函數叫**球諧函數**：

$$Y_l^m(\theta,\phi) = (-1)^m\, \sqrt{\frac{(2l+1)}{4\pi}\,\frac{(l-m)!}{(l+m)!}}\; P_l^m(\cos\theta)\; e^{im\phi}$$

其中 $P_l^m$ 是**相關勒让德多項式**。這些函數構成了希爾伯特空間的一個正交基底，決定了電子軌道的形狀（s、p、d、f 軌道）。

## 本章小結

- 薛丁諤提出了**含時**與**定態**兩個方程
- 含時方程描述波函數隨時間演化，定態方程是 eigenvalue 方程
- 對氫原子的推導完全使用了球座標與分離變數
- 能階 $E_n = -13.6/n^2$ eV 與玻爾模型完全一致，但理論基礎更扎實
- 球諧函數決定了電子軌道的形狀

## 想一想

1. 薛丁諤方程中的負號 $-\hbar^2/(2m)\nabla^2$ 是為什麼？這項項目在經典波動方程中通常是正號，這裡為什麼變號？
2. 球諧函數 $Y_l^m(\theta,\phi)$ 中的 $m$ （磁量子數）決定了軌道的取向，為什麼 $m$ 的範圍是 $-l$ 到 $+l$ ？
3. 薛丁諤方程對氫原子的解完全重現了玻爾模型的結果，但理論基礎不同。這說明了什麼？
