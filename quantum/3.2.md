# 3.2 推導：光子散射與康普頓波長偏移

## 1923 年，密蘇里州聖路易斯，一台彎晶體光譜儀

華盛頓大學的阿瑟·康普頓（Arthur Holly Compton, 1892–1962）自己組了一台儀器：整塊石板（graphite）當散射體，晶體當「彎曲的光柵」（curved crystal spectrometer），不同波長落在弧形底片的不同位置上。量測極限約為波長的百分之一。

入射光用鉬靶的 K$\alpha$ 線，$\lambda = 0.0708\,\mathrm{nm}$：

$$E = \frac{hc}{\lambda} = \frac{1240\ \mathrm{eV\cdot nm}}{0.0708\ \mathrm{nm}} \approx 1.75\times10^{4}\ \mathrm{eV} = 17.5\ \mathrm{keV}$$

他量的是散射到各個角度的 X 射線波長。三件事同時成立：

| 觀察 | 內容 | 波動說的預測 |
|---|---|---|
| (i) | 散射後波長 $\lambda'$ 比入射波長 $\lambda$ **長** | $\lambda'=\lambda$，不變 |
| (ii) | 偏移量 $\Delta\lambda=\lambda'-\lambda$ **與入射波長無關** | 隨 $\lambda$ 比例縮放 |
| (iii) | $\Delta\lambda$ **隨 $\theta$ 增大而增大**，$90^\circ$ 時最大 | 應為零 |

第二條最致命：偏移不隨入射波長縮放，說明來源不是波本身的性質，而是**一個固定的長度尺度**——電子自己。

## 推導：把光當成粒子

**推導**　記 $E$、$E'$ 為入射與散射光子能量，$E_e$ 為反衝電子的**總**能量，$m_e = 9.109\times10^{-31}\,\mathrm{kg}$、$m_ec^2 = 511\,\mathrm{keV}$。光子動量 $p = E/c$、$p'=E'/c$。散射角 $\theta$ 定為**入射方向與散射方向的夾角**。

**第一步，兩個守恆。** 能量：$E + m_ec^2 = E' + E_e$。動量：$\mathbf p = \mathbf p' + \mathbf p_e$，取 $\mathbf p_e=\mathbf p-\mathbf p'$ 的模平方（餘弦定理）得

$$p_e^2 = p^2 + p'^2 - 2pp'\cos\theta$$

**第二步，套用相對論質量殼層。** 對電子 $E_e^2 = p_e^2c^2+m_e^2c^4$，代入 $p=E/c$、$p'=E'/c$：

$$E_e^2 - m_e^2c^4 = (E-E')^2 + E^2 + E'^2 - 2EE'\cos\theta \tag{1}$$

**第三步，消掉 $E_e$。** 令 $\Delta \equiv E-E'$，即反衝電子動能。由能量守恆 $E_e = m_ec^2+\Delta$，故

$$E_e^2 - m_e^2c^4 = (m_ec^2+\Delta)^2 - m_e^2c^4 = 2m_ec^2\Delta + \Delta^2$$

代回 (1)，左邊的 $\Delta^2$ 與右邊 $(E-E')^2=\Delta^2$ 相消，得到 $2m_ec^2\Delta = E^2+E'^2-2EE'\cos\theta$。

**第四步，右邊改寫成 $\Delta$ 的函數。** 用恆等式

$$E^2+E'^2-2EE'\cos\theta = (E-E')^2 + 2EE'(1-\cos\theta) = \Delta^2 + 2EE'(1-\cos\theta)$$

於是 $\Delta^2$ 又回到左邊，得到關鍵的中間結果：

$$\boxed{\;\Delta\left[\Delta + 2m_ec^2\right] = 2EE'(1-\cos\theta)\;} \tag{2}$$

**自我檢查**：$\theta=0$ 時右邊為零，(2) 給出 $\Delta=0$——沒有反衝。✓ 這是整個推導的第一道保險扣，寫錯的版本會在這裡露餡。

**第五步，兩次近似。** 由 (2) 與 $E' = E-\Delta$ 整理得

$$\Delta\left[2m_ec^2 + 2E(1-\cos\theta)\right] = 2E^2(1-\cos\theta)\;\Longrightarrow\quad \Delta = \frac{E^2(1-\cos\theta)}{m_ec^2 + E(1-\cos\theta)}$$

這其實已是**精確解**。實驗條件下可做兩層近似：$\Delta \sim 0.6\,\mathrm{keV}$，遠小於 $E = 17.5\,\mathrm{keV}$ 與 $m_ec^2 = 511\,\mathrm{keV}$。因 $\Delta\ll E$ 取 $E'\approx E$；因 $\Delta^2\ll\Delta m_ec^2$ 丟掉 $\Delta^2$：

$$2m_ec^2\Delta \approx 2E^2(1-\cos\theta)\;\Longrightarrow\;E - E' \approx \frac{E^2}{m_ec^2}(1-\cos\theta)$$

**第六步，翻譯成波長。** 代入 $E = hc/\lambda$、$E'=hc/\lambda'$，兩邊乘 $\lambda\lambda'/(hc)$：

$$\frac{hc}{\lambda} - \frac{hc}{\lambda'} = \frac{h^2}{m_ec^2\lambda\lambda'}(1-\cos\theta)\;\Longrightarrow\;\boxed{\;\lambda' - \lambda = \frac{h}{m_ec}\left(1 - \cos\theta\right)\;} \tag{3}$$

用半角公式 $1-\cos\theta = 2\sin^2\frac{\theta}{2}$，教科書等價寫法是 $\lambda'-\lambda = \frac{2h}{m_ec}\sin^2\frac{\theta}{2}$。**本書以 (3) 為主式**，因為它對 $\theta$（入射與散射方向的夾角）的定義沒有歧義；歷史上正是 $\sin^2$ 與 $1-\cos$、以及角度定義混用，造成大量文獻差異。$90^\circ$ 時偏移最大，$\Delta\lambda = h/m_ec = \lambda_C$。

## 康普頓波長

式 (3) 右邊的係數本身就是一個物理長度：

$$\lambda_C \equiv \frac{h}{m_ec} = 2.4263\times10^{-12}\,\mathrm{m} = 0.02426\ \text{Å}$$

這是全原子核大小的尺度。整個效應一句話講完：**光子撞電子，等於把長度尺度 $\lambda_C$ 印在波長上。** 數值檢驗：石墨 $90^\circ$ 散射時

$$\Delta\lambda = 0.0024263\,\mathrm{nm},\qquad \frac{\Delta\lambda}{\lambda} = \frac{0.0024263}{0.0708} = 3.43\%$$

同一個公式配上可見光 $\lambda = 550\,\mathrm{nm}$：$\Delta\lambda/\lambda = 0.0024263/550 \approx 4.4\times10^{-6}$。

差了近一千倍。**康普頓效應在可見光下不可能觀測到**——不是效應不存在，而是相對偏移量落在任何光譜儀的雜訊底之下。光子能量必須接近 $m_ec^2 = 511\,\mathrm{keV}$ 才有可觀效應，於是這個效應在**最該看不到的地方被看到了**。

**束縛電子的修正（Compton–Pierce 效應）**：若被撞的是束縛較緊的電子，原子整體無法自由反衝，偏移量變大；對 $n$ 個可參與的電子，偏移量約為 $n\lambda_C$。石墨的碳有 6 個電子，但只有最外層接近自由，實測偏移落在 $1$ 到 $2$ 倍 $\lambda_C$ 之間。**電子束縛得越緊，偏移越大**——這個趨勢證明被散射的單位是電子，不是整個原子。康普頓用的是鋁、石英、石墨、水這些輕元素。

## 波動說為什麼必然失敗

| 場景 | 波動說（連續波場） | 光子說（一次碰撞） |
|---|---|---|
| 電子受場作用 | 受**連續的**波場散射 | 受**一次**碰撞 |
| 電子吸收的能量 | 波場平均值，只與頻率 $\nu$ 有關 | 恰為一個 $E = h\nu$ |
| 散射後波長 | 必須等於入射波長 | $\lambda' = \lambda + \lambda_C(1-\cos\theta)$ |
| 觀測 | 從未發生 | 三條觀察全部成立 |

波動說不是「算得不准」，是**連方程都列不出來**：一個連續波場沒有機制讓自己把能量一次性交出去。

## 反向應用

把精確解倒過來解：$\frac{1}{E'}=\frac{1}{E}+\frac{1-\cos\theta}{m_ec^2}$。今天拿已知能量的 $\gamma$ 射線撞電子，從散射光子的能量反推散射角；校準源是 Cs-137 的 662 keV、Bi-207 的 570/1064 keV、Co-60 的 1173/1332 keV。$\theta=180^\circ$ 時剩餘能量降到最低 $E'_{\mathrm{edge}} = m_ec^2/(m_ec^2+2E)$，這條台階叫**康普頓邊界**（Compton edge），位置只由 $E$ 與 $m_ec^2$ 決定。蛋白質晶體學裡，人們更利用散射強度的非對稱性反推**電子密度分布**，區別衍射因子相同但電子排布不同的分子。

## 本章小結

- 三條觀察：散射後波長變長、偏移與入射波長無關、偏移隨 $\theta$ 單調增加且在 $90^\circ$ 最大。
- 完整推導只用了兩條守恆加一條質量殼層，中間關鍵式為 $\Delta[\Delta+2m_ec^2] = 2EE'(1-\cos\theta)$，其中 $\Delta = E-E'$ 為反衝電子動能。
- 主結果 $\lambda'-\lambda = \frac{h}{m_ec}(1-\cos\theta)$；等價寫法為 $\frac{2h}{m_ec}\sin^2\frac{\theta}{2}$。
- **康普頓波長** $\lambda_C = h/(m_ec) = 2.4263\times10^{-12}\,\mathrm{m}$，是原子核尺度。
- 17.5 keV 的 X 射線相對偏移 3.43%，可見光只有 $4.4\times10^{-6}$——**效應必須在 X 射線波段才看得見**。
- 波動說的失敗是機制性的：連續波場無法一次性交出能量。
- 精確式 $\frac{1}{E'}=\frac{1}{E}+\frac{1-\cos\theta}{m_ec^2}$ 至今仍用於 $\gamma$ 能譜的**康普頓邊界**校正與電子密度成像。
