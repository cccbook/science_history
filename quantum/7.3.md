# 7.3 推導：定態薛丁諤方程的完整導出

這是全書第二個完整大推導。目標是從定態薛丁諤方程出發，一步步推導出氫原子的能階與軌道形式。

## (a) 方程與潢位

定態薛丁諤方程：

$$-\frac{\hbar^2}{2m}\,\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi$$

勢位 $V(x) = -\frac{e^2}{4\pi\varepsilon_0 |x|}$ （一維情況，或者使用球坐標的徑向部分）。

為了方便推導，引入**庫侖常數**：

$$k_e = \frac{1}{4\pi\varepsilon_0}, \quad \text{則勢位 } V(r) = -\frac{k_e e^2}{r}$$

## (b) 分離變數：球坐標

對於三維問題，我們使用**球坐標** $(r,\theta,\phi)$ 。拉普拉斯算子展開為：

$$\nabla^2 = \frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\frac{\partial}{\partial\theta}\right) + \frac{1}{r^2\sin^2\theta}\frac{\partial^2}{\partial\phi^2}$$

薛丁諤方程變為：

$$-\frac{\hbar^2}{2m}\left[\frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2\frac{\partial\psi}{\partial r}\right) + \frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\frac{\partial\psi}{\partial\theta}\right) + \frac{1}{r^2\sin^2\theta}\frac{\partial^2\psi}{\partial\phi^2}\right] - \frac{k_e e^2}{r}\psi = E\psi$$

## (b) 分離變數

假設解可以寫成**乘積形式**：

$$\psi(r,\theta,\phi) = R(r)\,Y(\theta,\phi)$$

其中 $R(r)$ 是**徑向函數**， $Y(\theta,\phi)$ 是**角函數**。

代入並除以 $\psi = R Y$ ，得到：

$$-\frac{\hbar^2}{2m}\!\left[\frac{1}{r}\frac{d^2(rR)}{dr^2} + \frac{1}{r^2}\!\left(\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac{1}{\sin^2\theta}\frac{\partial^2 Y}{\partial\phi^2}\right)\right] - \frac{k_e e^2}{r}E = 0$$

整理後，項分為**徑向部分**與**角向部分**：

### 徑向方程

$$-\frac{\hbar^2}{2m}\,\frac{1}{r^2}\frac{d}{dr}\!\left(r^2\frac{dR}{dr}\right) + \left(-\frac{k_e e^2}{r} + \frac{\hbar^2 l(l+1)}{2mr^2}\right)R = E R$$

其中 $l$ 是角動量量子數，項 $\frac{\hbar^2 l(l+1)}{2mr^2}$ 來自角運動量的離心力，使得電子不會直接墜落到核心。

### 角向方程

$$\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\!\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac{1}{\sin^2\theta}\frac{\partial^2 Y}{\partial\phi^2} + l(l+1)Y = 0$$

這是**勒让德微分方程**的標準形式。

## (c) 角向解：球諧函數

角向方程的正規化解是**球諧函數**：

$$Y_l^m(\theta,\phi) = N_{lm}\, P_l^m(\cos\theta)\, e^{im\phi}$$

其中：
- $l = 0, 1, 2, \dots$ 是**角動量量子數**
- $m = -l, -l+1, \dots, l$ 是**磁量子數**
- $P_l^m$ 是**相關勒让德多項式**
- $N_{lm}$ 是**歸一化常數**

球諧函數的物理意義：

- $|Y_l^m|^2$ 表示電子在某個角度上的機率分佈
- $l$ 決定了軌道的**形狀**（ $l=0$ 是 s 軌道， $l=1$ 是 p 軌道， $l=2$ 是 d 軌道…）
- $m$ 決定了軌道在 z 車軸上的**取向**

## (d) 徑向方程的變數變換

為了解徑向方程，我們引入新變數 $u(r) = rR(r)$ 。這個變換可以消除二階導數中的一階項：

$$\frac{d^2u}{dr^2} + \left[\frac{2m}{\hbar^2}\!\left(E + \frac{k_e e^2}{r}\right) - \frac{l(l+1)}{r^2}\right]u = 0$$

這是一個**シュ뢰迪ンガー方程的徑向部分**。

## (d) 變數： $\rho = \frac{2r}{n a_0}$

引入無量綱變數 $\rho$ ：

$$\rho = \frac{2r}{n a_0}, \quad \text{其中 } a_0 = \frac{4\pi\varepsilon_0\hbar^2}{m e^2} \text{ 是玻爾半徑}$$

其中 $n$ 後來會出現為**主量子數**。代入後，徑向方程變為：

$$\frac{d^2u}{d\rho^2} + \left(-\frac{1}{4} + \frac{1}{\rho} - \frac{l(l+1)}{\rho^2}\right)u = 0$$

## (e) 大 $\rho$ 的行為

當 $\rho \to \infty$ （即 $r \to \infty$ ）時，項 $1/\rho$ 與 $1/\rho^2$ 歸零，方程退化為：

$$\frac{d^2u}{d\rho^2} - \frac{1}{4}u = 0$$

其解是 $u \sim e^{-\rho/2}$ （因為 $e^{+\rho/2}$ 會使能量發散，不符合條件）。所以我們寫：

$$u(\rho) \sim e^{-\rho/2} \quad (\rho \to \infty)$$

這表示波函數在大距離處**指數衰減**，對應束縛狀態。

## (f) 小 $\rho$ 的行為

當 $\rho \to 0$ （即 $r \to 0$ ）時， $1/\rho$ 與 $1/\rho^2$ 項主導。保留最關鍵項：

$$\frac{d^2u}{d\rho^2} - \frac{l(l+1)}{\rho^2}u \approx 0$$

此為柯西-楊勒方程，其解為 $u \sim \rho^{l+1}$ （正解）或 $u \sim \rho^{-l}$ （負解，因為 $r=0$ 時波函數必須歸零，所以取正解）。

所以 $u(\rho) \sim \rho^{l+1}$ ，對應 $R(r) \sim r^l$ 。

## (f) 解的形式

綜合大 $\rho$ 與小 $\rho$ 的行為，徑向函數的形式為：

$$R(r) = N\, r^l\, e^{-r/(n a_0)} \, L_{n-l-1}^{2l+1}\!\left(\frac{2r}{n a_0}\right)$$

其中 $L$ 是**拉盖尔多項式**， $n$ 是主量子數。

能階公式再次出現：

$$E_n = -\frac{m e^4}{8\varepsilon_0^2 h^2 n^2} = -\frac{13.6\ \text{eV}}{n^2}$$

## (f) 特殊情形：s、p、d 軌道

- $l=0$ （s 軌道）： $R(r) \sim e^{-r/(n a_0)}$ ，波函數 spherically 對稱（球對稱），無角節。
- $l=1$ （p 軌道）： $R(r) \sim r\, e^{-r/(n a_0)}$ ，波函數有沿著座標軸的 dumbbell（雙曲面）形狀。
- $l=2$ （d 軌道）： $R(r) \sim r^2\, e^{-r/(n a_0)}$ ，波函數有更複雜的四葉形狀。

## 本章小結

- 定態薛丁諤方程的完整推導過程：從三維薛丁諤方程出發，使用球坐標與分離變數
- 徑向方程與角向方程的分離，球諧函數的出現
- 能階公式 $E_n = -13.6/n^2$ eV 的推導，證實了玻爾模型的正確性，但理論基礎更扎實
- 徑向函數 $R(r)$ 的變數變換 $\rho = 2r/(n a_0)$ 與歸一化
