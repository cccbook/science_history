# 3.4 德布羅意的博士論文：讓電子也站在波的一邊

Louis de Broglie（路易·德布羅意，1892-1987），法國貴族世家，巴黎索邦大學，指導教授是保羅·朗之萬（Paul Langevin）。他原本讀的是歷史，後來轉物理——因為哥哥莫里斯·德布羅意（Maurice de Broglie）是 X 射線實驗物理學家，路易在哥哥的實驗室裡幫忙時接觸到 X 射線。

## 核心的兩難

- 光顯示粒子性（光電效應、康普頓效應），波動理論也成功（干涉、繞射）
- 邏輯出路只有一個：如果光既是波又是粒子，那麼**大自然可能是對稱的**——粒子（物質）也應該有波

德布羅意注意到**相對論**與量子論的深層聯繫。光子的能量 $E = h\nu$ 與相對論的 $E = mc^2$ 聯立，得到一個頻率 $\nu = mc^2/h$。對靜止的電子，這個頻率對應一個「內在的振動」。德布羅意提出：給電子配上一個「相波」（onde pilote / pilot wave），使得運動中的電子實際上是一個**相速度**與**群速度**不同的波包。

## 關鍵的相速度與群速度推導

這是本章數學的高潮。我們從兩個頻率相近的波開始。

### 推導：兩個頻率的波包

設波函數 $\psi = \cos(k_1x - \omega_1 t) + \cos(k_2x - \omega_2 t)$，用和差化積：

$$\psi = 2\cos\left(\frac{\Delta k\,x - \Delta\omega\,t}{2}\right)\cos(kx - \omega t)$$

其中：
- $\Delta k = k_1 - k_2$，$\Delta\omega = \omega_1 - \omega_2$
- 波包（包絡）$\cos\left(\frac{\Delta k\,x - \Delta\omega\,t}{2}\right)$ 以速度 $v_g = \Delta\omega/\Delta k$ 移動
-  carrier波 $\cos(kx - \omega t)$ 以速度 $v_p = \omega/k$ 移動

這是群速度與相速度的幾何定義。

### 相對론色散關係

相對論的能量-動量關係：$E^2 = p^2c^2 + m^2c^4$，即 $\hbar^2\omega^2 = \hbar^2k^2c^2 + m^2c^4$。

對 $\omega$ 微分：

$2\omega\,d\omega = 2kc^2\,dk$，所以

$$v_g = \frac{d\omega}{dk} = \frac{kc^2}{\omega} = \frac{pc^2}{E} = \frac{pc^2}{\gamma mc^2} = \frac{p}{\gamma m} = v$$

**群速度 = 粒子速度**。這是德布羅意最關鍵的數學結果。

### 相速度

$$v_p = \frac{\omega}{k} = \frac{E}{p} = \frac{\gamma mc^2}{\gamma mv} = \frac{c^2}{v}$$

**相速度永遠大於光速**（因為 $v < c$）——但這不違反相對論，因為相速度不攜帶資訊；資訊以群速度傳播。

### 德布羅意波長

$$\lambda = \frac{h}{p} = \frac{h}{\gamma mv}$$

非相對論極限下 $\lambda = h/(mv)$。

## 波長的數值估算

一定要算給讀者看：

- 54 eV 的電子：$\lambda = h/\sqrt{2m_eE} \approx 0.167$ nm（原子尺度！）
- 一顆 100 g 的棒球以 40 m/s 飛行：$\lambda = 6.626\times10^{-34}/(0.1\times40) \approx 1.7\times10^{-34}$ m——比質子小 $10^{19}$ 倍，永遠觀測不到。**這就是為什麼我們看不見巨觀物體的波動性。**

## 論文的戲劇性

1924 年 11 月 25 日答辯。朗之萬把論文寄給愛因斯坦，愛因斯坦回信說（大意）：他被論文中的數學結構所震動、覺得推導非常漂亮。愛因斯坦隨即在自己關於氣體統計的論文中引用了德布羅意，等於替這篇「沒有實驗證據」的論文背書。

答辯委員會的一個尷尬問題：有人問「你要怎麼用實驗驗證電子的波動性？」德布羅意回答（大意）：可以用電子束穿過很小的孔，應該會出現繞射條紋。三年後 Davisson 與 G.P. Thomson 都做到了。

諾貝爾獎：1929 年頒給德布羅意——他是第一位因博士論文得諾貝爾獎的人。

## 德布羅意波長的物質意義

- 電子顯微鏡（1931 年 Ruska 發明，1986 年得諾貝爾獎）——因為電子的波長遠小於可見光，解析度高出千倍
- 中子繞射（慢中子波長可達埃的量級），成為研究固體結構的主要工具
- 電子繞射成為材料科學的標準工具

諾貝爾獎的細節：1929 年頒給 de Broglie（純理論）；1937 年頒給 Davisson 與 G. P. Thomson（實驗）。

德布羅意的反諷結尾：他的波動理論被驗證了，但他自己的「導波」詮釋卻被主流冷落（1927 年索爾維會議上被玻爾學派反駁），直到 1952 年玻姆（David Bohm）重新提出才復興，至今仍是詮釋之戰的選項之一（詳見第 12、17 章）。

本章總結的數學閉環：$\lambda = h/p$ 是普朗克關係 $E = h\nu$ 與相對論能量動量關係 $E^2 = p^2c^2 + m^2c^4$ 的聯立結果。物質有波長，本質上源自物質是相對論性的。

## 本章小結

- 德布羅意的核心突破：粒子（電子）也有波動性，波長 $\lambda = h/p$
- 相速度 $v_p = c^2/v$，群速度 = 粒子速度 $v$——群速度才是實體速度
- 54 eV 電子波長 0.167 nm，與原子尺度相匹配——這是實驗可觀測的關鍵
- 1929 年諾貝爾獎頒給德布羅意——博士論文得獎的首例
- 自旋的物理來源至今仍是一個「黑箱」，但波動性已是實驗事實
