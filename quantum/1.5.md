# 1.5 推導：從玻爾茲曼因子到普朗克公式

這是全書第一個完整大推導。目標是把讀者從「溫度=能量均分」的直覺，一步步引到普朗克公式，並且在最後的閉環中，回頭得到維恩位移定律。

## (a) 設定

設定：N 個可區分的振子（頻率 ν），總能量 U。每個振子只能處在能量 0, hν, 2hν, ...，即 $E_n = n h\nu$ 。

每個振子的能量都離散化了，這是普朗克的大膽假說。這裡沒有連續的能量。

## (b) 狀態數

把 U 個能量量子（每個 hν）分配給 N 個振子的方法數。這是一個「星星和棒」的排列組合問題。

設 P = U / (hν) 是總能量量子的數量。所有的 N 個振子 + P 個量子，總共有 N + P 個物件，我們挑 P 個作為「棒」，其餘的 N 個作為「星」的排列方法數：

$$W = \frac{(N + P - 1)!}{P!\,(N-1)!}$$

這是全排列除去重複排列的結果。

## (c) 用斯特林公式

取對數：

$$\ln W \approx (N+P)\ln(N+P) - N\ln N - P\ln P$$

這是斯特林公式的近似，對於大量子數（N、P 極大）非常精準。

## (d) 熱平衡條件

對 P 微分並令為零（能量極大化 / 熱平衡）：

$$\frac{\partial \ln W}{\partial P} = \ln\frac{N+P}{P} = \frac{h\nu}{k_B T}$$

這裡使用了熱力學關係 $1/T = \partial S/\partial U = k_B\,\partial\ln W/\partial U$ ，以及 $U = P h\nu$ 。

## (e) 平均每個振子的能量

解出平均能量：

$$\bar{E} = \frac{U}{N} = \frac{h\nu}{e^{h\nu/k_B T} - 1}$$

對比：能量均分定理給 $\bar{E} = k_B T$ 。當 $h\nu \ll k_B T$ 時（低頻、高溫）， $e^{h\nu/k_BT} \approx 1 + h\nu/k_BT$ ，Planck 公式自動回到均分定理——這就是為什麼長波端實驗對得上。

## (f) 乘上模態密度

前一節推導的模態密度 $g(\nu) = 8\pi\nu^2/c^3$ ，得到普朗克公式：

$$u(\nu,T)\,d\nu = \frac{8\pi h \nu^3}{c^3}\cdot\frac{1}{e^{h\nu/k_B T} - 1}\,d\nu$$

## (g) 總輻射能量密度積分

把 ν 換成 x = hν/k_B T，算總輻射能量密度：

$$u = \int_0^\infty u(\nu,T)\,d\nu = \frac{8\pi h}{c^3}\left(\frac{k_B T}{h}\right)^4 \int_0^\infty \frac{x^3}{e^x - 1}\,dx$$

而 $\int_0^\infty \frac{x^3}{e^x-1}\,dx = \Gamma(4)\,\zeta(4) = 3!\cdot\frac{\pi^4}{90} = \frac{\pi^4}{15}$

→ $u = \frac{8\pi^5 k_B^4}{15 h^3 c^3}T^4$ → Stefan-Boltzmann 定律 $\sigma = 5.670×10^{-8}$ W·m^-2·K^-4 ✓

## (h) 閉環：回頭推維恩位移定律

對 $x^3/(e^x-1)$ 求極值：

$3(1-e^{-x}) = x$ ，解得 $x \approx 4.9651$

→ $\lambda_{max}T = \frac{hc}{4.9651\,k_B} = 2.898×10^{-3}$ m·K ✓（回頭得到 1.1 節的維恩位移定律）

## (i) 智識洞見

普朗克公式在高頻端回到維恩公式（ $e^x\gg1$ 時 $1/(e^x-1)\approx e^{-x}$ ），低頻端回到瑞利－金斯。**Planck 的公式是「兩個失敗理論的正確雜交」**。

結尾：正確答案可以來自完全錯誤的理由。Planck 對自己的推導信心極低，這一點直到 1910 歲 Nernst 的低溫實驗才讓他改觀。

## 本章小結

- 第一個完整的數學推導：玻爾茲曼因子 → 普朗克公式 → Stefan-Boltzmann 定律
- $\int_0^\infty x^3/(e^x-1)dx = \pi^4/15$ 利用了 $\Gamma(4)\zeta(4)$
- 維恩位移定律 $\lambda_{max}T = hc/(xk_B)$ 閉環回到 1.1 節
- Planck 公式在高頻端回到維恩，低頻端回到瑞利－金斯——兩個失敗理論的正確雜交
