# A.1 複數與波

複數是量子力學的語言。沒有它，薛丁諤方程、狄拉克的 bra-ket 記號，甚至都是無源之水。

## 複數的基本形式

一個複數 $z$ 可以表示為：

$$z = x + iy$$

其中 $x$ 是實部， $y$ 是虛部， $i$ 是單位虛，滿足 $i^2 = -1$ 。

## 極形式與歐拉公式

在複平面上，複數可以用極座標表示：

$$z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

其中 $r = |z| = \sqrt{x^2 + y^2}$ 是 modulus（模）， $\theta = \arg(z)$ 是 argument（參數）。

**歐拉公式**是複數最美麗的結果：

$$e^{i\theta} = \cos\theta + i\sin\theta$$

這讓我們可以將任何複數表示為模和參數的乘積，這在薛丁諤方程的解中無處不在。

## 複數的運算

- **加法**： $(x_1 + iy_1) + (x_2 + iy_2) = (x_1 + x_2) + i(y_1 + y_2)$
- **乘法**： $(x_1 + iy_1)(x_2 + iy_2) = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)$
- **共軛**： $z^* = x - iy$
- **模的平方**： $|z|^2 = zz^* = x^2 + y^2$

## 平面波

在量子力學中，最基本的解是**平面波**：

$$\psi(x,t) = Ae^{i(kx - \omega t)}$$

其中：
- $A$ 是振幅
- $k = 2\pi/\lambda$ 是波數
- $\omega = 2\pi\nu$ 是角頻率
- $\lambda = h/p$ 是德布羅意波長

平面波的機率密度 $|\psi|^2 = |A|^2$ 是常數，表示粒子在整個空間中均勻分佈的機率。這是自由粒子的理想化模型。

## 本章小結

- 複數 $z = x + iy$ 是量子力學的基石
- 極形式 $z = re^{i\theta}$ 與歐拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$ 是核心
- 平面波 $\psi = Ae^{i(kx-\omega t)}$ 是薛丁諤方程的基本解
- 機率密度 $|\psi|^2$ 決定了粒子位置的分佈
