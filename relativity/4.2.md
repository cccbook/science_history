# 4.2 洛倫茲增量：速度加法公式

在特別相對論中，我們不能直接使用經典的速度相加公式 $v_{total} = v_1 + v_2$ 。因為光速在所有參考系統中都是不變的，速度的加法必須遵循洛倫茲變換的規律。

## (a) 經典速度加法的失效

設想一輛以速度 $v_1 = 0.8c$ 運動的火車，車內有一位乘客向前走以速度 $v_2 = 0.8c$ 的速度。根據經典力學，觀察者會測得乘客相對地面的速度為：

$$v_{total} = v_1 + v_2 = 1.6c$$

這違反了光速不變的 postulate。事實上，無論我們如何加速，任何物體的速度都不能超過光速 $c$ 。

## (b) 洛倫茲速度加法公式

利用洛倫茲變換，我們可以推導出正確的 relativistic velocity addition formula。設參考系 S' 相對 S 以速度 $v$ 運動，一個物體在 S' 中的速度為 $u'$ ，則在 S 中的速度 $u$ 為：

$$u = \frac{u' + v}{1 + \frac{u'v}{c^2}}$$

### 推導過程（简要版）

1. 設在 S' 中，物體的位置為 $x'$ ，時間為 $t'$ ，速度 $u' = dx'/dt'$ 。
2. 利用洛倫茲變換：
   $$x' = \gamma(x - vt), \quad t' = \gamma\left(t - \frac{vx}{c^2}\right)$$
3. 計算 $u = dx/dt$ ：
   $$u = \frac{dx}{dt} = \frac{dx/dt'}{dt/dt'} = \frac{dx'/dt' \cdot dt'/dt}{dt/dt'} = \frac{u' + v}{1 + \frac{u'v}{c^2}}$$

其中我們使用了 $dt/dt' = \gamma(1 + u'v/c^2)$ 這一結果。

## (c) 極限情況驗證

1. **當 $u' = c$ 時**：
   $$u = \frac{c + v}{1 + \frac{cv}{c^2}} = \frac{c + v}{1 + v/c} = \frac{c + v}{(c + v)/c} = c$$
   這證明了無論以何種速度移動的參考系，光速始終為 $c$ 。

2. **當 $u', v \ll c$ 時**：
   $$u \approx \frac{u' + v}{1 + 0} = u' + v$$
   這顯示在低速區域（日常經驗），洛倫�克斯速度加法約退化為經典速度加法。

## (d) 對稱性

速度加法在相對論中也不再是交換律的。即 $(u' + v) \neq (v + u')$ 的形式雖然在數學上相同，但實際意義不同，因為底下的分母 $1 + u'v/c^2$ 取決於兩個速度的大小。

## 本章小結

- 洛倫茲速度加公式 $u = \frac{u' + v}{1 + u'v/c^2}$ 取代了經典的 $u = u' + v$ 。
- 這個公式確保了任何速度都不會超過光速 $c$ 。
- 在低速區域， $u \approx u' + v$ ，符合經典直覺。
- 這是特別相對論的核心數學工具，直接源自於光速不變性。
