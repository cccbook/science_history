# 2.2 四維動量：能量與動量的統一

在特別相對論中，我們不再把時間和空間分開對待，而是將其統合為四維時空。同樣地，能量和動量也被統合為**四維動量**。

## (a) 四維動量的定義

在三維空間中，經典動量是 $\mathbf{p} = m\mathbf{v}$ 。在相對論中，我們引入四維動量四ectors：

$$p^\mu = \left(\frac{E}{c}, p_x, p_y, p_z\right)$$

其中：
- $E$ 是能量
- $p_x, p_y, p_z$ 是空間動量分量
- $c$ 是光速，用於統一單位

## (b) 四維動量的幾何意義

四維動量可以看作是四維時空中的一個向量。其** norme（標準）** 定義為：

$$p^\mu p_\mu = -m^2c^2$$

這裡使用的是 metric $(-,+,+,+)$ ，即：

$$p^\mu p_\mu = -\left(\frac{E}{c}\right)^2 + p_x^2 + p_y^2 + p_z^2 = -m^2c^2$$

這是一個關鍵的不變量，類似於三維空間中 $\mathbf{p}^2 = p^2$ 。

## (c) 能量-動量不變量

從上式可以重新推導出能量-動量方程：

$$E^2 = (pc)^2 + (mc^2)^2$$

這是 $E=mc^2$ 的一般形式，當粒子靜止 ( $p=0)$ 時，簡化為 $E = mc^2$ ；當質量 $m=0$ （如光子）時，簡化為 $E = pc$ 。

## (d) 四維動量的加法

在相對論中，動量的加法遵循四維向量加法規律。若兩個粒子分別有四維動量 $p_1^\mu$ 和 $p_2^\mu$ ，則系統的總四維動量為：

$$P^\mu = p_1^\mu + p_2^\mu$$

這在粒子碰撞實驗中至關重要，因為總四維動量的不變量給出了系統的總質量。

## 本章小結

- 四維動量 $p^\mu = (E/c, \mathbf{p})$ 將能量和動量統一到時空中。
- 四維動量的不變量 $p^\mu p_\mu = -m^2c^2$ 直接導出了能量-動量方程 $E^2 = (pc)^2 + (mc^2)^2$ 。
- 當 $m=0$ 时，光子有 $E = pc$ ；當 $p=0$ 时，得到 $E=mc^2$ 。
- 這個框架讓我們能夠一致地處理質量為零和非零的粒子。
