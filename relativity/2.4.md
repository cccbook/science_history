# 2.4 動量守恆與粒子對撞

四維動量不僅僅是一個數學工具，它還提供了保守律的強大框架。在粒子物理學中，四維動量守恆是分析碰撞實驗的核心。

## (a) 四維動量守恆

在任何孤立系統中，總四維動量都是守恆的。這意味著：

$$\sum p_i^\mu = \text{常數}$$

或等價地，碎片前後的總四維動量相等：

$$\sum p_{\text{initial}}^\mu = \sum p_{\text{final}}^\mu$$

由於四維動量的不變量是不變的，我們可以從守恆定律中計算出難以直接測量的粒子質量。

## (b) 實際應用：粒子對撞實驗

在粒子加速器實驗中，我們通常無法直接測量產生的新粒子的能量和動量，但我們可以測量碎片的軌跡和入射束的能量。

以質子對撞為例：

1. 入射質子四維動量： $p_{\text{beam}}^\mu$
2. 靶質子四維動量（通常靜止）： $p_{\text{target}}^\mu = (m_p c, 0, 0, 0)$
3. 碰撞後，產生了若干粒子，其四維動量之和為 $P^\mu_{\text{final}}$

守恆定律給出：

$$P^\mu_{\text{beam}} + P^\mu_{\text{target}} = P^\mu_{\text{final}}$$

通過測量最終狀態的軌跡，可以得到每個粒子的能量和動量，從而驗證守恆定律，並計算出新粒子的質量。

## (c) 邊際情況：固定目標實驗 vs 対撞機

在固定目標實驗中，入射束撞擊靜止的靶粒子，總質量平方為：

$$s = (p_{\text{beam}} + p_{\text{target}})^2 = m_{\text{beam}}^2 + m_{\text{target}}^2 + 2E_{\text{beam}}m_{\text{target}}$$

在对撞機中，兩束束流以相同能量朝對方運動，總質量平方為：

$$s = (p_1 + p_2)^2 = 2m^2 + 2E_1E_2 - 2p_1\cdot p_2 = 4E^2 - 4p^2 = 4E^2(1 - v^2/c^2) = 4m^2\gamma^2$$

對撞機的有效質心能量遠高於固定目標實驗，這是為什麼現代高能物理實驗多選擇對撞機的原因。

## 本章小結

- 四維動量守恆是分析粒子碰撞的核心工具。
- 通過守恆定律，我們可以間接計算出難以直接測量的粒子質量。
- 固定目標實驗和对撞機的總質量平方 $s$ 有顯著差異，決定了實驗的探測極限。
- 這個框架是現代粒子物理的數學基石。
