# 3.3 推導：局等ivalence導出場方程的變項

本節從等ivalence原理出發，推導出廣義相對論的場方程中的關鍵變項——Christoffel 記號（或稱連接量），它描述了重力場如何影響時空的平行輸送。

## (a) 平行輸送的概念

在微分流形上，我們需要定義向量如何在曲面上「平行」輸送。在扁平的歐幾里得空間中，這很直觀：將向量沿著曲線移動，保持其方向和大小不變。

但在曲面（或曲折的時空）上，我們需要引入**平行輸送準則**。對於一個向量場 $V^\mu$ 沿著曲線 $x^\mu(\lambda)$ 平行輸送，其變化率必須滿足：

$$\frac{dV^\mu}{d\lambda} + \Gamma^\mu_{\nu\sigma} \frac{dx^\nu}{d\lambda} V^\sigma = 0$$

其中 $\Gamma^\mu_{\nu\sigma}$ 稱為**Christoffel 記號**（或廣義連接量）。這個項目描述了坐標變化對向量變化的貢獻。

## (b) Christoffel 記號的物理意義

Christoffel 記號並非張量（它們在座標變換下的變換規律不如張量那樣優雅），但它們描述了重力場的物理效應：

1. **重力作為幾何**：在廣義相對論中，我們不把重力視為一個向量場，而是視為時空曲率的結果。Christoffel 記號正是產生這種曲率的數學工具。

2. **局等ivalence的體現**：在局部慣性系中，我們可以通過坐標變換消去重力效應，這意味著在該系中 $\Gamma^\mu_{\nu\sigma} = 0$ 。這就是等ivalence原理的數學體現。

3. **曲率的來源**：Christoffel 記號的變化（它們的對易子）定義了黎曼曲率張量，它描述了時空的曲率。

## (c) 從度規到 Christoffel 記號

對於一個一般的度規 $g_{\mu\nu}$ ，Christoffel 記號定義為：

$$\Gamma^\mu_{\nu\sigma} = \frac{1}{2}g^{\mu\rho}\left(\frac{\partial g_{\rho\nu}}{\partial x^\sigma} + \frac{\partial g_{\rho\sigma}}{\partial x^\nu} - \frac{\partial g_{\nu\sigma}}{\partial x^\rho}\right)$$

這是**黎維維塔連接**（ Levi-Civita connection），它滿足兩個性質：
- 兼容性： $\nabla_\lambda g_{\mu\nu} = 0$ （度規在平行輸送下不變）
- 無虧度： $\Gamma^\mu_{\nu\sigma} = \Gamma^\mu_{\sigma\nu}$ （對稱性）

## (d) 對於施瓦西度規的具体計算

對於施瓦西度規：

$$ds^2 = -\left(1 - \frac{2GM}{rc^2}\right)c^2dt^2 + \left(1 - \frac{2GM}{rc^2}\right)^{-1}dr^2 + r^2(d\theta^2 + \sin^2\theta d\phi^2)$$

我們可以計算出非零的 Christoffel 記號。以 $\Gamma^t_{tr}$ 為例：

$$\Gamma^t_{tr} = \frac{1}{2}g^{tt}\left(\frac{\partial g_{tt}}{\partial r} + \frac{\partial g_{tr}}{\partial t} - \frac{\partial g_{tr}}{\partial t}\right) = \frac{1}{2}g^{tt}\frac{\partial g_{tt}}{\partial r}$$

由於 $g_{tt} = -\left(1 - \frac{2GM}{rc^2}\right)c^2$ 且 $g^{tt} = -\left(1 - \frac{2GM}{rc^2}\right)^{-1}$ ，我們得到：

$$\Gamma^t_{tr} = \frac{1}{2}\left(-\left(1 - \frac{2GM}{rc^2}\right)^{-1}\right)\frac{\partial}{\partial r}\left[-\left(1 - \frac{2GM}{rc^2}\right)c^2\right] = \frac{GM}{rc^2}\frac{1}{1 - \frac{2GM}{rc^2}}$$

類似地，我們可以計算出其他非零的 Christoffel 記號，它們描述了黑洞時空中的重力場強度和方向。

## (e) 曲率張量的預備

Christoffel 記號的對易子定義了黎曼曲率張量：

$$R^\rho_{\sigma\mu\nu} = \frac{\partial \Gamma^\rho_{\nu\sigma}}{\partial x^\mu} - \frac{\partial \Gamma^\rho_{\mu\sigma}}{\partial x^\nu} + \Gamma^\rho_{\mu\lambda}\Gamma^\lambda_{\nu\sigma} - \Gamma^\rho_{\nu\lambda}\Gamma^\lambda_{\mu\sigma}$$

對於施瓦西度規，計算曲率張量最終證實了 $R_{\mu\nu} = 0$ （外部場），即施瓦西解滿足愛因斯坦場方程。

## 本章小結

- Christoffel 記號 $\Gamma^\mu_{\nu\sigma}$ 描述向量在曲折時空中的平行輸送規律。
- 它們不是張量，但描述了重力場如何影響時空的幾何結構。
- 在局部慣性系中，可以消去 Christoffel 記號，這是等ivalence原理的數學體現。
- 對於施瓦西度規，Christoffel 記號的計算展示了黑洞時空中的重力場結構。
