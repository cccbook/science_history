# 《相對論：時空的幾何與能量的質量》大綱

## 書籍定位

**相對論科普教科書 × 數學推導的科普著作**。

一句話定位：**這是一本「用數幾何講述時空故事」的相對論入門**。每一章先拋出一個真實的謎題（實驗測量與理論預測的偏差、或邏輯悖論），再把打開它的幾何與代數一步一步寫出來，最後交代那些為此付出代價的人。

## 目標讀者

- 高中畢業到大學二年級，**會微積分基本概念**（導數、積分意義），**無需先修相對論**，本書會從愛因斯坦的思實驗開始講起
- 對「時空是如何被發現的」有好奇心的科普讀者
- 不需要先修廣義相對論，本書會從特別相對論一步步推導到廣義相對論

## 與既有相對論科普書的差異化

市面上多數「相對論科普書」是**編年體**：從愛因斯坦1905年提出廣義相對論到2015年LIGO引力波探測，一路線性鋪陳。本書刻意不做這件事。

| 面向 | 編年體相對論科普書 | 本書 |
|---|---|---|
| 組織方式 | 時間順序 | **問題驅動**：每章一個謎題，歷史為解謎服務 |
| 數學 | 幾乎沒有，或只有結論 | **推導是主線**，逐步寫出中間每一步 |
| 焦點 | 愛因斯坦個傳 | 物理實驗與幾何構造 |
| 收束 | 「相對論很神奇」 | 每章給出**這個結論解決了什麼新問題**，以及留下了什麼 |
| 貫穿主題 | 無 | **「光速極限」與「曲率極限」**兩條暗線 |

### 本書的三條暗線

1. **光速極限是宇宙的速限，也是因果關係的界線**：一切資訊傳遞都受限於光速，這不是工程限制，是時空幾何的本質。
2. **曲率是重力的幾何化**：愛因斯坦的優雅貢獻在於把「重力」從「力」轉化為「時空曲率」，這不僅僅是數學換義，更是物理觀點的根本轉移。
3. **實驗總是先於理論**：從米可波耳實驗到LIGO，每一次關鍵突破都始於實驗數據的異常，理論總是「事後」去適配觀測數據。

## 寫作風格規範

### 每節（每個 .md 檔）的結構

1. **標題**：`# N.M 節標題`
2. **開場白**：一到兩段具體的場景——某年某月某地，某個實驗、某個思實驗、某個天文觀測。**不要**以「相對論是二十世紀最重要的理論之一」這種概括句開場。
3. **正文**：敘事與幾何交錯。抽象的幾何概念要立刻用一個具體的比喻或座標系落地。
4. **數學**：必須給出公式；推導要寫出中間步驟，不能跳。
5. **收尾**：這個結論對後來的什麼物理問題有用。
6. `## 本章小結`：5–7 條要點
7. `## 想一想`：3 題開放式問題

### 數學格式

- 行內數學用 `$...$`，獨立成行用 `$$ ... $$`
- 推導過程用 `**推導**` 開頭的小節或段落，逐步列出
- 常數：光速 $c = 2.998 \times 10^8$ m/s、萬有引力常數 $G = 6.674 \times 10^{-11}$ N·m²/kg²
- 單位一律用 SI，並附上常用經驗值
- 首次出現的物理量給出符號 + 中文名 + 英文名 + SI 單位

### 長度

每個 .md 檔 5000–7000 bytes（約 1500–2500 字）。

### 表格與圖

- 概念對照、公式對照、年表 → 用 Markdown 表格
- 時空 diagram、軌跡圖 → 用 ```mermaid 程式碼塊
- 幾何構造、軌跡適合用 mermaid

### 語氣

- 用iseries 的方式：從現象出發，進入幾何，最後回到物理意義
- 可以有幽默，但要「物理學家的幽默」——精準、乾淨、不油膩
- 避免評論性語氣；用事實和幾何本身說話
- 引用名言要謹慎：除非有明確出處，否則用「大意是」而非引號精確引述
- **絕對不要編造**：實驗數據、頁碼、精確日期、通信原文。如果不確定某個細節，用模糊但誠實的寫法（「大約在 1905 年」），或直接略過
