# 12.1 宇宙學：相對論的宏觀視野

廣義相對論不僅僅解釋了黑洞和引力波，它也是現代宇宙學的數學基礎。愛因斯坦最初將方程應用於宇宙整體，試圖構建一個靜態的宇宙模型。

## (a) 引入宇宙常數

1917年，愛因斯坦為了獲得靜態解，在場方程中引入了一項新的項目——**宇宙常數 $\Lambda$**：

$$R_{\mu\nu} - \frac{1}{2}Rg_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4}T_{\mu\nu}$$

他認為 $\Lambda$ 可以調節引力，使得宇宙保持靜態（不拓展也不收縮）。

## (b) 哈伯的發現：宇宙拓展

1929年，哈伯通過觀測發現：遠處的星系都在遠離我們，且紅移與距離成正比。這意味著**宇宙正在拓展**。這打破了愛因斯坦對「靜態宇宙」的信念。

愛因斯坦事後稱引入 $\Lambda$ 為「他一生最大的錯誤」，但現代 cosmology 重新評價了宇宙常數的角色。

## (c) FLRW 度規

為了描述均質且各向各向相同的拓展宇宙，愛因斯坦和羅伯遷、弗萊德曼提出了**FLRW 度規**（Friedmann-Lemaître-Robertson-Walker）：

$$ds^2 = -c^2 dt^2 + a^2(t) \left[ \frac{dr^2}{1 - k r^2} + r^2 (d\theta^2 + \sin^2\theta d\phi^2) \right]$$

其中：
- $a(t)$ 是**拓展因子**，隨時間變化，描述宇宙的尺度變化。
- $k$ 是曲率參數：$k = +1$（閉宇宙）、$k = 0$（平坦宇宙）、$k = -1$（開放宇宙）。

### 勞勃遷方程

結合愛因斯坦場方程與 FLRW 度規，得出**勞勃遷方程**（Friedmann equations），描述宇宙拓展的動力學：

$$\left(\frac{\dot a}{a}\right)^2 = \frac{8\pi G}{3}\rho - \frac{kc^2}{a^2} + \frac{\Lambda}{3}$$

$$\frac{\ddot a}{a} = -\frac{4\pi G}{3}\left(\rho + \frac{3p}{c^2}\right) + \frac{\Lambda}{3}$$

其中 $\rho$ 是能量密度，$p$ 是壓力。

## (d) 三種宇宙模型

根據 $k$ 和 $\Lambda$ 的不同，宇宙有三種可能的命運：

1. **開放宇宙 ($k = -1, \Lambda = 0)$**：
   - 拓展永遠繼續，但速率遞減，最終趨於停止。
   - 密度低於臨界密度。

2. **平坦宇宙 ($k = 0, \Lambda = 0)$**：
   - 拓展永遠繼續，但速率趨於零。
   - 密度 exactly 於臨界密度。

3. **閉宇宙 ($k = +1, \Lambda = 0)$**：
   - 拓展會在某個時間點停止，然後收縮（大挫軟）。
   - 密度高於臨界密度。

現代觀測表明，我們的宇宙是**近乎平坦**的，且目前的拓展速率因**暗能量**（對應 $\Lambda > 0$）而加速。

## 本章小結

- 愛因斯坦引入宇宙常數試圖構建靜態宇宙，但哈伯的發現證實了宇宙拓展。
- FLRW 度規描述均質各向各向相同的拓展宇宙。
- 勞勃遷方程預測了宇宙的動態演化，取決於能量密度、壓力和宇宙常數。
- 三種宇宙模型（開放、平坦、閉）取決於曲率參數 $k$ 和臨界密度。
