# 2.3 量子不變量：參考系獨立的質量

四維動量不變量的最重要物理意義在於它**不隨參考系變化**。這是相對論最核心的概念之一。

## (a) 不變量的數學證明

我們已經在上一章看過洛倫�entz變換如何保持時空區間不變。同理，四維動量的不變量也可以證明不變。

設在參考系 S 中，四維動量為 $p^\mu = (E/c, \mathbf{p})$ 。在參考系 S'（以速度 $v$ 相對 S 運動）中，四維動量為 $p'^\mu = (E'/c, \mathbf{p}')$ 。

根據洛倫�entz變換：

$$E' = \gamma\left(E - v p_{\parallel}\right)$$
$$p'_{\parallel} = \gamma\left(p_{\parallel} - \frac{vE}{c^2}\right)$$
$$p_{\perp}' = p_{\perp}$$

其中 $p_{\parallel}$ 為沿著速度方向的動量分量， $p_{\perp}$ 為垂直於速度方向的分量。

現在計算兩邊的不變量：

$$p'^\mu p'_\mu = -\frac{E'^2}{c^2} + \mathbf{p}'^2 = -\frac{\gamma^2}{c^2}\left(E - v p_{\parallel}\right)^2 + \gamma^2\left(p_{\parallel} - \frac{vE}{c^2}\right)^2 + p_{\perp}^2$$

展開並整理：

$$= -\gamma^2\frac{E^2}{c^2} + 2\gamma^2\frac{E v p_{\parallel}}{c^2} - \gamma^2\frac{v^2 p_{\parallel}^2}{c^2} + \gamma^2 p_{\parallel}^2 - 2\gamma^2\frac{vE p_{\parallel}}{c^2} + \gamma^2\frac{v^2 E^2}{c^4} + p_{\perp}^2$$

整理項目：

$$= -\gamma^2\frac{E^2}{c^2} + \gamma^2 p_{\parallel}^2\left(1 - \frac{v^2}{c^2}\right) + \gamma^2\frac{v^2 E^2}{c^4} + p_{\perp}^2$$

利用 $\gamma^2 = \frac{1}{1-v^2/c^2}$ ，即 $\gamma^2(1-v^2/c^2) = 1$ ，我們得到：

$$= -\gamma^2\frac{E^2}{c^2} + \gamma^2\frac{v^2 E^2}{c^4} + p_{\perp}^2 + \gamma^2 p_{\parallel}^2\left(1 - \frac{v^2}{c^2}\right)$$

$$= -\gamma^2\frac{E^2}{c^2}\left(1 - \frac{v^2}{c^2}\right) + p_{\perp}^2 + \gamma^2 p_{\parallel}^2\left(1 - \frac{v^2}{c^2}\right)$$

$$= -\frac{E^2}{c^2} + p_{\perp}^2 + p_{\parallel}^2$$

$$= -\frac{E^2}{c^2} + p_x^2 + p_y^2 + p_z^2$$

$$= p^\mu p_\mu$$

證明完成：四維動量的不變量在所有慣性參考系中都是相同的。

## (b) 物理意義：質量的參考系獨立性

這個不變量的意義在於它等於粒子的**質量**（乘以 $c$ 的平方）：

$$p^\mu p_\mu = -m^2c^2$$

由於不變量在所有參考系中都相同，因此**質量也是參考系獨立的**。無論觀察者以何種速度運動，都會測量到相同的質量值。

這解釋了為什麼質量是一個基本的不變量，而能量和動量會隨觀察者速度而變化。

## (c) 零質量粒子

對於光子（質量為零的粒子），有：

$$p^\mu p_\mu = 0$$

這意味著 $E^2 = (pc)^2$ ，即 $E = pc$ 。這證明了光子雖然沒有靜止質量，卻擁有能量和動量，且能量與動量的比值恒等於光速 $c$ 。

## 本章小結

- 四維動量的不變量在所有參考系中都相同，這是相對論的數學堅實基石。
- 這個不變量等於粒子的質量（ $p^\mu p_\mu = -m^2c^2$ ），證明質量是相對系獨立的。
- 零質量粒子（光子）有 $E = pc$ ，質量粒子有 $E^2 = (pc)^2 + (mc^2)^2$ 。
- 這個不變量的獨立性，是相對論區別於經典力學的關鍵數學特徵。
