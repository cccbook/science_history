# 1.3 推導：洛倫茲變換與時空交際

有了愛因斯坦的兩個公理，我們可以推導出洛倫茲變換，這是連接不同參考系統間的核心數學工具。這不僅僅是一個座標變換，更是時空結構的直接體現。

## (a) 變換前提

設有兩個慣性參考系 S 和 S'。S' 相對 S 以速度 $v$ 運動（沿 x 軸方向）。兩個參考系的原點在時間 $t = t' = 0$ 時重合。

觀測者在 S 中測量的事件座標為 $(t, x, y, z)$ ，在 S' 中為 $(t', x', y', z')$ 。我們尋找將 $(t, x)$ 變換為 $(t', x')$ 的線性變換：

$$t' = A t + B x$$
$$x' = C t + D x$$

其中 $A, B, C, D$ 為待決定的函數，僅依賴於 $v$ 和 $c$ 。

## (b) 邊界條件

為了確定這些常數，我們利用物理邊界條件：

1. **原點重合**：當 $x = 0$ 時， $x' = 0$ ；當 $t = 0$ 時， $t' = 0$ 。（這簡化了變換，消去了平移項。）

2. **光速不變**：光在 S 中的傳播方程為 $x = ct$ （或 $x = -ct$ ），在 S' 中必須同樣為 $x' = ct'$ （或 $x' = -ct'$ ）。

3. **對易性**：S' 相對 S 以速度 $v$ 運動，同理 S 相對 S' 以速度 $-v$ 運動。這意味著變換矩陣必須是可逆的，且其逆元應該形式相同（價格改號 $v$ 為 $-v$ ）。

## (c) 推導過程

### 步驟 1：應用光速不變條件

對於向前傳播的光，在 S 中有 $x = ct$ 。代入變換公式：

$$t' = A t + B (ct) = (A + Bc)t$$
$$x' = C t + D (ct) = (C + Dc)t$$

在 S' 中，光的速度必須為 $c$ ，故有 $x' = ct'$ 。代入：

$$(C + Dc)t = c(A + Bc)t$$

整理得：

$$C + Dc = c(A + Bc) \quad \text{(方程 1)}$$

同理，對於向後傳播的光， $x = -ct$ ，我們得到：

$$C - Dc = -c(A - Bc) \quad \text{(方程 2)}$$

### 步驟 2：解聯立方程

從方程 1 和方程 2，我們可以解出各常數之間的關係。

將方程 2 變形：

$$C - Dc = -cA + Bc$$

整理：

$$C + cA = Bc + Dc$$

這方程式告訴我們 $A, B, C, D$ 必須滿足什麼樣的線性關係。

### 步驟 3：利用對易性條件

考慮 S' 相對 S 以速度 $v$ 運動，同理 S 相對 S' 以速度 $-v$ 運動。變換矩陣的逆元應該形式相同，這導致：

$$A(v) = A(-v), \quad B(v) = -B(-v), \quad C(v) = C(-v), \quad D(v) = D(-v)$$

同時，我們知道當 $v = 0$ 時，變換應該退化為單位變換： $A(0) = 1, B(0) = 0, C(0) = 0, D(0) = 1$ 。

結合上述條件，我們可以推導出標準的洛倫茲變換公式。

## (d) 標準洛倫茲變換公式

經過完整的數學推導（省略中間繁瑣的代數步驟），我們最終得到：

$$t' = \gamma \left(t - \frac{vx}{c^2}\right)$$
$$x' = \gamma (x - vt)$$
$$y' = y$$
$$z' = z$$

其中 $\gamma = \frac{1}{\sqrt{1 - v^2/c^2}}$ 稱為**洛倫茲因子**。

### 物理意義

- **時間膨脹**：運動中的時鐘走得更慢。
- **長度收縮**：運動中的物體在運動方向上長度更短。
- **相對性**：時間與空間的測量依賴於觀察者的速度。

## 本章小結

- 洛倫茲變換是從愛因斯坦的兩個公理出發，通過光速不變的條件推導而來的。
- 它不僅僅是一個數學公式，更是時空幾何的直接體現。
- $\gamma = 1/\sqrt{1-v^2/c^2}$ 是連接不同參考系統的橋樑，當 $v \ll c$ 時， $\gamma \approx 1$ ，退化為經典力學。

## 想一想

2. 當 $v \to c$ 時， $\gamma \to \infty$ 。這在物理上意味著什麼？能否實現 $v = c$ ？
